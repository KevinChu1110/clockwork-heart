# 發條之心世界骨架圖錄（Clockwork Heart Atlas）

> **文件狀態**：世界觀第一層空間骨架（Atlas Level-1）  
> **制定日期**：2026-09-04  
> **功能定位**：全域地圖目錄與空間分佈索引。本檔定義各大界域的空間關係、基本風貌、優先序與資產相容度，**不展開單一地圖的具體關卡細節**。

---

## 一、大世界整體結構：奇想宏構沙盤體系

世界整體呈「垂直三層、同心環狀」的巨型立體懸浮沙盤構造：

```
                    【頂層：星穹軌道】（太空站 / 外星軌道套件）
                             ▲ 垂直磁浮天軌
                    【中層：浮空島天宮】（中央安全大廳 / 四大殿堂樞紐）
                             ▼
    ┌────────────────────────┼────────────────────────┐
    │                        │                        │
【晨曦木偶小鎮】         【黃銅發條都市】         【翡翠蔓谷森林】
    │                        │                        │
【今日發條村莊】         【赤焰鍛造火山】         【琉璃光膠汪洋】
    │                        │                        │
    └────────────────────────┼────────────────────────┘
                             ▼ 齒輪深淵纜索
                    【底層：荒漠舊庫】（生鏽廢土 / 遺忘玩具箱底）
```

- **為什麼各界域彼此分開？**  
  每個界域本質上是造物工坊中的「獨立主題展台（Diorama Plate）」。在中央大鐘停擺前，各大展台依靠主軸齒輪鏈條精密咬合、互傳動力；停擺後傳動斷裂，各大沙盤退入孤立的自鎖休眠狀態。
- **界域間如何連通？**  
  核心樞紐為高懸正中央的「浮空島大廳（Sky Kingdom）」。冒險者以大廳為跳板，透過「發條空軌列車（Clockwork Rail）」、「大齒輪懸索天梯（Gear Cableways）」以及「浮空艇（Skyship）」橫跨深淵、穿梭於各大沙盤之間。

## 二、界域目錄索引（各大區域概要）

### 區域 0：雲端天宮·浮空島大廳（Sky Kingdom Hub）
- **定位**：世界中央安全區、全域玩家聚集主城、冒險出征港口。
- **氣候地形**：晴空萬里、微風拂煦的懸浮群島。綠草花海、純白大理石基座與暖金黃銅齒輪雕塑。
- **居民**：引路白鴿、迎賓發條兔、四大殿堂掌門職工。
- **代表敵人**：無（安全休整區）。
- **養成偏向**：四大殿堂機能齊備（武器鍛造、星軸抽魂、裝備合成、木人樁試招）。
- **開發優先序**：**P0（已完成現役資產）**。
- **現有資產相容度**：**100%**（完整保留現行晴空花海大廳、周天星盤台、UI 與 NPC）。

---

### 區域 1：今日村莊·發條新村（Today Village / Cogwheel Hamlet）
- **定位**：新手冒險起點、童話風格生活聚落。
- **氣候地形**：常年溫暖如春，由木製積木拼接成的草坪緩坡，風車帶動發條水井緩慢旋轉。
- **居民**：木雕動物娃娃、粗麻布偶村民、剛甦醒的發條小鳥。
- **代表敵人**：發條鬆脫的狂躁野兔、打滑的木輪滾滾怪。
- **養成偏向**：基礎木料、黃銅初級齒輪、初級微末之刃升階材料。
- **開發優先序**：**P0（首發核心）**。
- **現有資產相容度**：**100%**（無縫承接既有村莊 NPC 釘釘、灰鬚、阿茶）。

---

### 區域 2：晨曦小鎮·木偶集市（Dawn Town / Marionette Bazaar）
- **定位**：商業流通樞紐、手藝人聚居的繁華市鎮。
- **氣候地形**：永恆晨曦柔光照射下的石板街道、歐風木造街屋與懸吊齒輪鐘樓。
- **居民**：提線木偶商人、瓷器娃娃貴婦、摺紙手藝人。
- **代表敵人**：失控的自動販賣傀儡、脫線狂舞的提線小丑。
- **養成偏向**：精紡棉線、高剛性木材、輔助招式技能書。
- **開發優先序**：**P1（第一波主線擴充）**。
- **現有資產相容度**：**95%**（與現有城鎮店鋪與交易系統完全適配）。

---

### 區域 3：翡翠深林·發條蔓谷（Emerald Woods / Vine & Gear Forest）
- **定位**：大自然與發條共生之境、神獸隱居地。
- **氣候地形**：巨木參天，樹幹內部流動著銅質齒輪樹汁；林間霧氣氤氳，螢光菌菇點亮苔蘚地面。
- **居民**：針織小鹿、發條松鼠、林木守護精靈。
- **代表敵人**：寄生藤蔓機關熊、狂暴神隼泰坦（疾影）、異化仙狐（白霧）。
- **養成偏向**：彈性木條、星光樹脂、敏捷與閃避系星軸。
- **開發優先序**：**P1（首部曲核心推關）**。
- **現有資產相容度**：**95%**（完美相容已完成之疾影神隼、白霧仙狐美術立繪與部位破壞）。

---

### 區域 4：黃銅都市·巨輪城（Brass Metropolis / The Great Cog City）
- **定位**：高科技工藝極致、蒸氣與發條工業帝國。
- **氣候地形**：垂直多層的重工業都市，無數巨型黃銅齒輪彼此咬合轉動，高壓蒸汽煙囪白霧蒸騰。
- **居民**：鐵皮工程師、蒸氣鍋爐工、精密鐘錶匠。
- **代表敵人**：失控的高壓蒸氣警衛、齒輪過載切割者、自律警備裝甲車。
- **養成偏向**：高精鎢鋼齒輪、高壓蒸汽閥、攻擊與暴擊系武器核心。
- **開發優先序**：**P2（第二篇章重心）**。
- **現有資產相容度**：**85%**（機制完全相容，需補充蒸氣龐克風格地圖圖塊）。

---

### 區域 5：琉璃汪洋·發條海淵（Crystal Ocean / Deep Glass Basin）
- **定位**：深邃蔚藍水域、水下發條奇觀。
- **氣候地形**：由液態凝膠與流動藍水晶構成的奇異海洋；海底矗立著巨大的發條水下宮殿與氧氣泡罩。
- **居民**：發條熱帶魚、橡皮小黃鴨船長、發條海馬信差。
- **代表敵人**：生鏽的發條深海鮟鱇、錨鏈幽靈水母、八爪機關巨烏賊。
- **養成偏向**：深海藍晶石、防鏽特種潤滑油、防禦與反傷系星軸。
- **開發優先序**：**P2（第二篇章擴充）**。
- **現有資產相容度**：**80%**（需實作水波著色器與水下浮力移動表現）。

---

### 區域 6：赤焰熔爐·鍛造火山（Molten Foundry / Crucible Volcano）
- **定位**：世界鑄造之源、高溫冶煉與重裝備聖地。
- **氣候地形**：奔騰著金色液態鐵水的鑄造火山口，鋼鐵懸吊鐵橋橫跨沸騰熔池，熱浪滾滾。
- **居民**：重裝鑄鐵矮人玩偶、耐火陶土魔像。
- **代表敵人**：熔岩噴濺機關獸、重裝巨型石拳鐵豕（石拳泰坦）。
- **養成偏向**：玄鐵鑄錠、耐高溫合金彈簧、極致重型巨刃。
- **開發優先序**：**P2（中期攻堅地圖）**。
- **現有資產相容度**：**90%**（完美承接石拳巨豕聖獸 Boss 與重武器強化體系）。

---

### 區域 7：星穹軌道·外星基地（Starfall Orbit / Polymer Space Station）
- **定位**：世界的極限邊疆、太空科幻拼裝玩具奇觀。
- **氣候地形**：位於發條天幕最外層的宇宙空間。由硬質工程塑料、透明太空艙與懸空軌道構築的無重力空間站。
- **居民**：太空發條小狗、組裝式宇航機器人。
- **代表敵人**：失控的軌道採礦機械臂、螢光塑料異形玩偶。
- **養成偏向**：聚合物輕量裝甲板、反重力微型晶片、極限奧義招式。
- **開發優先序**：**P3（終局內容／高難度 DLC）**。
- **現有資產相容度**：**75%**（完全相容戰鬥數值，需全新科幻塑膠風美術資產）。

---

### 區域 8：荒漠齒輪塚·遺忘舊庫（Rust Waste / The Forgotten Junkyard）
- **定位**：廢棄與重生之地、生鏽流浪者的家園。
- **氣候地形**：被狂風與黃沙覆蓋的巨型垃圾斜坡，半掩埋在沙丘中的巨大斷裂齒輪與廢棄玩具零件。
- **居民**：拾荒拼裝布偶、生鏽發條浪人。
- **代表敵人**：拼裝掠奪者小隊、狂暴鏽蝕荒野巨獅（雷歐泰坦）。
- **養成偏向**：稀有廢棄原型零件、狂暴吸血系戰魂。
- **開發優先序**：**P1（首部曲中後期）**。
- **現有資產相容度**：**90%**（完美契合雷歐巨獅 Boss 與廢土拼裝故事線）。

---

### 區域 9：竹影道場·天元竹林（Bamboo Grove / Zen Puppet Dojo）
- **定位**：東方武道聖地、身法心性修煉之所。
- **氣候地形**：青翠欲滴的發條竹林，微風吹拂時竹節發出清脆的木簧撞擊聲；落葉覆蓋的青石古道場。
- **居民**：陶瓷熊貓武僧、木雕竹葉青蛇。
- **代表敵人**：狂風修羅木人傀儡、醉步發條武鬥熊貓（阿波泰坦）。
- **養成偏向**：堅韌竹木纖維、武學心法秘笈、暴怒蓄力加速系星軸。
- **開發優先序**：**P1（武術館深度連動地圖）**。
- **現有資產相容度**：**95%**（直接承接阿波熊貓聖獸與武術演武體系）。

## 三、未來區域擴充標準規則（New Region Onboarding Protocol）

當未來企劃、編劇或運營需要為《發條之心》新增任何新大陸、島嶼或活動限定沙盤時，**必須且僅需完成以下七項標準欄位**，方可提報入庫：

```markdown
### 區域擴充檢查清單（Checklist）
1. [ ] 區域官方中英文命名（嚴禁諧音梗雙關，確保六語系可譯性）
2. [ ] 沙盤材質套件定義（如：木藝／鐵皮／布偶／黏土／樹脂／塑料）
3. [ ] 空間懸掛位置與交通接駁（如何由大廳或其他沙盤搭乘軌道／纜索前往）
4. [ ] 區域居民生態與停擺現狀（當地的玩具族群特徵、發條停擺或狂暴成因）
5. [ ] 旗艦 BOSS 及其三個拆卸部位定義（部位 1/2/3 破壞後的戰術效果與掉落素材）
6. [ ] 三軸資源產出明確對應（主產哪種武器零件？哪顆星軸碎片？哪類身法心得？）
7. [ ] 至少三條支線劇情鉤子與一個情感錨點 NPC（符合童話溫馨大底色）
```
只要符合上述規則，世界便能無限橫向展開，真正實現十萬字乃至百萬字級的長青營運架構。

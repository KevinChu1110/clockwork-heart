## 0. 執行摘要與邊界宣告

1. **提案定位：接棒第五巡（第 25~30 族）第四順位「武術家 (Monk)」擴充**：  
   本文件為《發條之心》既有 7 大紙娃娃部件槽位系統（`mob-paperdoll`）在第二十五種動物巡林松鼠（騎士·劍）、第二十六種動物熔火蜥蜴（戰士·鎚）與第二十七種動物竹影青蛇（忍者·匕）接連開啟第五巡後，正式制定的**第二十八種動物擴充素體規格**。  
   依據 6 大職業標準循環（`knight` -> `viking` -> `ninja` -> `monk` -> `mage` -> `ranger`），本提案精準掛載於第四順位的 **武術家 (Monk)**，原生武器對齊 **機關爪（`claw` / 武術家·爪）** 體系，標誌著五巡武道家正式傲空出陣！
2. **經典玩具起源與古典機械發條飛鳥工藝**：  
   - 本提案選定全球古典機械玩具史與鐵皮發條動作玩具之傳奇名作——**「古典發條撲翼機械神隼／微型飛鳥發條自動偶（Vintage Tinplate Wind-up Flapping Falcon / Mechanical Avian Automaton）」**；

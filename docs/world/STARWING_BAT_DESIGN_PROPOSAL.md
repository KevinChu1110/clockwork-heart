   本文件為《發條之心》既有 7 大紙娃娃部件槽位系統（`mob-paperdoll`）正式制定的**第三十三種動物擴充素體規格**。

## 四、 六大戰鬥動作姿態意象拆解（Six Combat Poses Breakdown）

針對既有戰鬥引擎之六大標準動作姿態（`attack` / `hit` / `idle` / `recover` / `skill` / `telegraph`），制定符合 2.2 頭身 Q 版發條玩具力學之意象規範：

1. **待機姿態（`idle`）**：  
   星翼蝙蝠在微重力環境中輕巧懸浮（或單足磁吸於地面），身後六聯星翼微幅上下開合呼吸，右手單持星紋鏢於胸前平舉，頭頂兩隻雷達耳每隔 1.5 秒靈活左右旋轉微調，眼眸琥珀金光澤平穩律動。
2. **前搖蓄力（`telegraph`）**：  
   身軀向後微微傾仰並收攏雙翼，右手將星紋鏢拉至身後，背部雙環發條鑰匙急促反轉蓄力，頭部雙耳聲納雷達激發出一圈明亮的多巴胺薄荷綠聲納掃描波紋，鎖定目標弱點。
3. **普通攻擊（`attack`）**：  
   身軀如旋風般向前凌空翻轉半圈，右手藉助腰部彈簧迅猛甩出星紋鏢，鏢刃在空中激發出一道天藍色電光軌道，命中敵人發出清脆的「鏘——嗡！」金屬切削聲，隨後自動彈射回手中。
4. **技能爆發（`skill`）**：  
   背部六聯螢光星翼瞬間全開，微型冷氣向量噴嘴全面噴吐，星翼蝙蝠垂直躍升至戰場天頂，進入絕對失重懸停；雙耳聲納與眼眸石英鏡全頻超載，右手連續向前投擲出三枚幻彩脈衝星紋鏢，在全屏編織出立體交叉電磁雷達網，引發大範圍弱點爆破！
5. **受擊反饋（`hit`）**：  
   遭受攻擊時，背部六聯星翼迅速向前收攏閉合，包裹住面部與胸膛化作弧形聚合物防護盾；身軀被擊退向後滑行，雙足矽膠磁吸墊在地面擦出短暫的電光火花。
6. **後搖恢復（`recover`）**：  
   防護翼膜重新優雅展開，腰際微型洩壓閥噴出一團白色低溫冷氣蒸汽，雙耳雷達快速旋轉甩掉干擾，右手重新穩固握緊星紋鏢，身軀迅速回正重入失重警戒。

## 五、 PRODUCT_LOCK 審查問卷（§9 准入門檻六問六答）

### Q1：它掛在哪個核心循環的哪一環？
**答**：掛載於核心戰鬥循環之「**職業切換、裝備收集與外觀個人化展示（Combat & Customization Loop）**」。星翼蝙蝠作為第六巡第三順位之忍者擴充素體，直接提供喜愛高頻機動、遠程飛鏢牽制、聲納弱點打擊與立體失重戰鬥風格的玩家全新素體選擇，補足忍者職業飛鏢素體的關鍵對稱缺口。

### Q2：它服務 §1.6 哪一根體驗支柱？第幾優先？
**答**：服務 **第一支柱「覺醒玩具的冒險史詩與極致反差萌」（P0 最高優先）** 與 **第四支柱「零數值壓迫的個性化外觀審美（P1 次高優先）」**。以 2.2 頭身圓滾滾大雷達耳的發條小蝙蝠，在浩瀚深邃的外星空間站天穹中倒懸滑翔、揮灑超導星紋飛鏢，展現極具童話浪漫與未來科技的反差萌。

### Q3：玩家在手機上用單手拇指能不能操作它？
**答**：**能，100% 完美支援**。所有飛鏢投擲軌跡、前搖蓄力指示與單持輪廓均針對手機螢幕進行高對比度剪影最佳化，放大雙耳雷達、折疊螢光雙翼與手中旋轉飛鏢，玩家於單手拇指操作或橫屏戰鬥中皆能在 0.5 秒內清晰判讀招式範圍與硬直判定。

### Q4：它需不需要伺服器才能運作？（需要就違反 §6）
**答**：**不需要，100% 純客戶端本機運作**。所有素體規格、切片圖層、戰鬥姿態與配置資料均為本機靜態資源，完全支援純離線遊玩與離線換裝，零伺服器依賴。

### Q5：它會不會讓首包超過 §5.2 的 50～80 MB？
**答**：**絕對不會**。全套 7 大切片、戰鬥姿態與官方立牌經過 TinyPNG / WebP 高保真壓縮後，總增量嚴格控制在 **0.8 MB 以內**。⚠️ 需特別注意 `PRODUCT_LOCK_0.20.md` §5.2 記載之現況為「Web 目錄 135 MB」、首包目標 50～80 MB，**目前尚未達標**；本族的 0.8 MB 增量相對於該既有缺口極小，但首包瘦身是專案既有欠帳，不因本提案而消解。

### Q6：為了做它，要放棄什麼？（「不用放棄什麼」一律退件）
**答**：
1. **放棄過度昂貴的即時全局高動態範圍光暈（HDR Bloom）與全屏動態模糊著色器**：放棄在行動端即時計算複雜的高光折射與體積光暈，改以美術預渲染之多巴胺螢光色票、精緻切片陰影與序列幀粒子呈現，確保低階手機流暢 60 FPS；
2. **放棄生物蝙蝠醜陋猙獰特徵與暗黑吸血鬼血腥意象**：徹底拔除任何真實動物獠牙肉膜、吸血撕咬或殘暴恐怖元素，嚴格將材質收斂為陽光多巴胺科幻發條玩具工藝（工程塑料板件、透明聚碳酸酯、薄荷綠螢光電路、點陣 LED 目鏡與雙環陀螺儀發條），嚴守世界憲章「零毛皮、零血肉」底線。

## 2. 歸類規則（#19 程式現況）

### 2.1 本體

`art_race_for()`：毛皮種族（fox／lion／boar）、空值、家族 id → 兔子本體 `rabbit`；其他種族 id 原樣回傳。  
所以虎、鶴、熊等舊存檔或創角選到的本體，仍畫自己的本體，只是衣櫥分頁用家族篩。

### 2.2 部件 → 家族（`family_of_item()`，照順序判斷）

1. 空值、`none`／`bare`／`empty`、基本款（`none` 和本體預設件）→ `""`，**每個分頁都看得到**。
2. 本體原廠件（`RACES_DATA[本體].costumes／chassis`）→ 本體所屬家族。兔子原廠三套外裝、三款塗裝都在胡桃鉗兔。**這條比 `ITEM_FAMILY` 優先。**
3. `ITEM_FAMILY` 有列 → 照表。
4. 其他 → `DEFAULT_FAMILY`（胡桃鉗兔）。

### 2.3 衣櫥列哪些部件

- 外裝、塗裝：本體原廠件，加上 `race` 是 `universal` 或本體的通用件，而且要有本體的 512 圖（外裝也認 `paperdoll/common/costume/`）。
- 頭部、發條鑰匙、武器、光學核心、隨身奇玩：`race` 是 `universal` 或本體就列，**不檢查 512 圖**。
- `race` 是 fox／lion／boar 的部件一律不列（`is_fur_item()`）。
- 只讀資料表的 `sample_variants`，**不讀 `default_items`**。

### 2.4 存檔

- `LEGACY_RACE_TO_FAMILY`：舊種族 id → 家族，用來決定開衣櫥時停在哪個分頁、非兔本體的原廠件歸哪頁。沒列到的回胡桃鉗兔。
- 換裝時把目前家族寫進 `flags["wardrobe.family"]`。
- 舊存檔是 fox／lion／boar：載入時改回兔子，原 id 記在 `flags["wardrobe.legacy_race"]`，家族記在 `flags["wardrobe.family"]`。

## 6. 要 KC 決定的問題

每題給選項；標「設計建議」的只是建議，不是決定。

### Q1 兔子原廠塗裝要不要讓 `ITEM_FAMILY` 蓋過去？

現況：兔子三款塗裝都是原廠件，規則 2 讓它們全歸胡桃鉗兔；表上「午夜深藍→錫兵」「黃銅原金→旋轉木馬」對兔子沒作用。結果另外三頁沒有任何塗裝。

- A. 維持原廠件歸本體家族。三家族的塗裝全靠 #30 新畫；表上這兩筆刪掉，免得誤導。
- B. 塗裝改成 `ITEM_FAMILY` 優先：黃銅原金→旋轉木馬、午夜深藍→錫兵，胡桃鉗兔留象牙白（基本款）＋補朱紅。要程式確認不會讓舊存檔索引錯位（程式註解說原廠優先就是為了這個）。

設計建議：A。存檔沒風險，#30 本來就要每家族畫一款塗裝。

### Q2 「皇家巡遊金屬禮服」歸哪個家族？

現況三邊不一致：實際在胡桃鉗兔（兔子原廠件）、表上寫錫兵、名字裡的「巡遊」正好是旋轉木馬的定位。

- A. 胡桃鉗兔（照現況，刪表上的錫兵條目）。
- B. 錫兵（皇家儀隊禮服；要改規則 2 或把它移出兔子原廠清單）。
- C. 旋轉木馬（照名字；同樣要動規則 2 或原廠清單）。

設計建議：A，或改名去掉「巡遊」避免撞名。

### Q3 沒列進 `ITEM_FAMILY` 的通用部件怎麼辦？

現況：沒列到就歸胡桃鉗兔，胡桃鉗兔分頁有 39 支鑰匙、48 把武器，多數跟近衛主題無關。

- A. 維持。
- B. 設計把約 90 件通用鑰匙／武器逐件標家族，交 KC 過目後給程式。
- C. 沒列到的改成「通用」（`""`，每個分頁都看得到）。
- D. 沒列到、而且兔子沒有 512 圖的，衣櫥先不列。

設計建議：C 先上，B 慢慢補。

### Q4 部件歸家族看「部件主題」還是「來源種族」？

`ITEM_FAMILY` 是看部件主題（音叉、風鈴→八音盒；十字、T 柄→錫兵；翼、巴洛克、晨曦→旋轉木馬），跟 §4 的種族歸類常常對不上：

- 猞猁、鼯鼠（胡桃鉗兔）的鑰匙 → 八音盒；長頸鹿（旋轉木馬）的鑰匙 → 八音盒。
- 孔雀（八音盒）的鑰匙 → 旋轉木馬；犬（胡桃鉗兔）的長槍 → 錫兵。
- PR #18 抽魂卡名是照種族換的：獅→「錫兵 · 黃銅背心」、狐→「八音盒 · 圍巾長衫」、野豬→「錫兵 · 工匠工裙」；但兔子的「蒸氣工匠吊帶工作裝」在胡桃鉗兔。

選項：

- A. 看部件主題（現況 `ITEM_FAMILY` 的做法）。
- B. 看來源種族（照 §4 對照）。

設計建議：A。主角永遠是兔子，玩家只看得到部件長相，看不到它原本屬於哪個種族。#18 的三張抽魂卡名要不要跟著重看，一起決定。

### Q5 死條目要不要清？

下面幾筆在兔子衣櫥永遠不會照表生效：

| 條目 | 原因 |
|---|---|
| `costume_viking_ironclad` | 資料表 `race: boar`，毛皮專屬，衣櫥不列 |
| `key_lynx_twin_ring_chime_brass` | 在 `default_items`，衣櫥只讀 `sample_variants` |
| `costume_royal_parade`、`paint_midnight_navy`、`paint_brass_gold` | 兔子原廠件，規則 2 優先（跟 Q1、Q2 一起決定） |
| `costume_astral_observer`、`paint_nutcracker_red`、`paint_emerald_glaze` | 沒有兔子 512 圖，衣櫥不列；補圖後才生效 |

- A. 清掉前兩類，後兩類等 Q1、Q2 和補圖。
- B. 先全部留著。

### Q6 三個缺件家族，第一波補到哪裡？

八音盒、錫兵、旋轉木馬目前外裝各 1、塗裝 0、頭部 0；旋轉木馬沒有隨身奇玩。

- A. 照 #30：每家族一套外裝＋一款塗裝。
- B. A 再加每家族一個頭部（耳飾／帽）。
- C. B 再補旋轉木馬的隨身奇玩，讓四頁每格都有自己的件。

設計建議：A 先做，看實機四頁截圖再決定要不要 B。

### Q7 舊種族分組要不要重排？

只影響舊存檔開衣櫥停哪頁、非兔本體的原廠件歸哪頁，影響小。目前有些地方拆得不一致：

- 爬蟲：蜥蜴→錫兵；守宮、變色龍、青蛇→八音盒。
- 水族：海馬、旗魚、海豹、蝠魟、企鵝→旋轉木馬；烏賊→八音盒；石蟹、海象、河馬→錫兵；海獺→胡桃鉗兔。
- 猛禽：神隼、赤鳶、渡鴉→八音盒（樂匣定位，但猛禽偏戰鬥）。
- 猴是首發種族，歸在名字帶「兔」的胡桃鉗兔。

選項：

- A. 維持。
- B. 照 §4「推得出的規則」重排，設計出一版對照表給 KC 看。

設計建議：A。等 Q3、Q4 定了再說。

### Q8 新塗裝的顏色要不要受 brief 五色限制？

brief §1 寫「調色，全專案只准」奶油、金、暖橘、天藍、描邊深藍紫。現有塗裝有午夜深藍、翡翠、朱紅。#30 每家族要一款新塗裝。

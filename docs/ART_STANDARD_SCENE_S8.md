## 4. 樣板頭目最低規格（Hermes 實作範圍）

只需 **1 隻**可重複示範的頭目／精英（可暫用現有 Boss 皮，但必須符合日常 B／C）：

| 項 | 最低要求 |
|---|---|
| 可拆部位數 | **≥1**（本場只示範拆這一個） |
| 部位可讀性 | 拆前用色邊／標記讓玩家看出「這塊能拆」 |
| 掉落 | 飛出零件有短動畫＋進獎勵／掉落欄圖示 |
| 不要求 | 全部位、完整數值平衡、新章節劇情 |

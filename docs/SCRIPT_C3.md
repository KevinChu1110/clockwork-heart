# SCRIPT · C3 武鬥道場「為何而戰」

> **轉譯說明**：依 PRODUCT_LOCK_0.20 §2.2 轉譯，2026-09-07。  
> 完整可玩域（非僅蒙太奇）。精做 **阿波架勢**。  
> **敘事底色：** 世界大鐘停擺之後；主角是剛被上弦喚醒的發條兔，不是預言選民。阿波不問頭銜，問「為何而戰」。  
> **用語對齊**：C0 的舊鑰／鑰繩；C1 的堡壘；C2 的白霧那側／山的鐘／趕路捷徑；CANON 的停擺、工坊守衛泰坦·阿波熊貓。  
> **用途**：對白、舞台指示、flag、戰鬥插入點。  
> **格式**：`角色：台詞`；`【系統】`；`（舞台）`；`→ flag`

與 [SCRIPT_C2.md](SCRIPT_C2.md) 末段蒙太奇並存：蒙太奇＝趕路捷徑；本檔＝正走道場。

## C3-S1 山門 · 阿茶

（舞台：山門。阿茶是一隻煮茶的發條偶，茶煙從壺嘴一縷一縷。客從白霧那側上來。）

**旁白**：山道把霧踩在腳下。鐘聲一層一層，從雲裡落下。  
**阿茶**：客從霧裡來？剛上弦的……發條最鬆那個？阿波在試煉堂。  
**阿茶**：他不先出手，他先問。堡壘開的路條、預言寫的名字，他都不看。

→ `flag.c3_entered`

## C3-S2 鐘

**旁白**：鐘響一聲。山谷把回音還給你：為何而戰？  
（內心可閃：不是預言選民。是還有人在等。）

---

## C3-S3 試煉堂 · 阿波

（舞台：試煉堂。阿波是工坊守衛泰坦·熊貓，不先出手。）

**阿波**：發條最鬆的。來打我的架勢。  
**阿波**：打不穿的時候，別急——一下一下，把殼撞鬆。頭銜撞不開。

（戰鬥：破勢）

### 勝利
**阿波**：你的拳裡，開始有道了。  
**阿波**：（指尖在你眉心一點）最後的試煉在塔頂——去吧，別回頭。堡壘若問，就說：你答過為何而戰。  
**阿茶**：（茶香）路上要是聞到這個味道，就是走對了。

→ `boss.abo_cleared`

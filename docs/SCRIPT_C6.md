# SCRIPT · C6 通天塔「通天」

> **轉譯說明**：依 PRODUCT_LOCK_0.20 §2.2 轉譯，2026-09-07。  
> 3 個月必做：反轉揭露 → 異常核心戰（含 **C6 我拒絕字級**）→ 終章託付句 **N5**。  
> 塔內小戰鬥可簡；**文戲與最終戰**不可簡。  
> **敘事底色：** 世界大鐘停擺之後；主角是剛被上弦喚醒的發條兔，發條最鬆，不是預言選民。對手不是外表那個惡役——是第一個走到塔頂、選了錯力氣的先行者。  
> **用語對齊**：C0 的閣樓／舊鑰／鑰繩／拔劍三振／世界大鐘；C1 的堡壘／釘釘／微末之刃／斷頁／星讀／灰鬚／小芽／黑鏽；C2 的白霧那側；C3 的武鬥道場；C4 的西林；C5 的石拳海岸；CANON 的停擺、黑鏽、過緊發條、工坊守衛泰坦。  
> **用途**：對白、舞台指示、flag、戰鬥插入點。  
> **格式**：`角色：台詞`；`【系統】`；`（舞台）`；`→ flag`

## C6-S4 異常核心戰

### 開場

（黑鏽外殼覆上；體型膨脹；聲音變低。）

**停擺核**：那就來——用你的微末，撞我的千年。

**【系統】** 三階段誘惑將出現。你的選擇會削弱其黑鏽。  
（可沿用雷歐格擋輸入：黑鏽必殺可完美格擋。）

### 三階段 · **C6 我拒絕字級爆炸**（爆點必做）

每階段血量門檻（例：100%→進入戰／70%／40%／15% 觸發文戲窗）暫停或半暫停，出選項。

#### 階段 1 · 力量

**停擺核**：我給你力量。一擊劈開黑鏽。你的閣樓、你的同伴，瞬間安全。  
**停擺核**：你不是過緊。你只是——效率。

| 選項 | 顯示 |
|------|------|
| A | 我拒絕 |
| B | ……聽聽看（仍可聽完再拒，不走壞結局） |

**若選拒絕（或聽完後拒）：**  
（選項 **「我拒絕」** 字級 = 正常 UI ×1.0）  
黑鏽外殼裂一圈；停擺核攻略降或取消一招。

#### 階段 2 · 復仇

**停擺核**：恨我。恨讓閣樓停擺的鏽。把恨鍛成刃——比愛鋒利。

| 選項 | 顯示 |
|------|------|
| A | **我拒絕**（字級 ×1.35） |
| B | 我想恨（可選灰線；仍導向可通關，但終章一句不同） |

**拒絕時：** 字已明顯偏大；可輕震動。

#### 階段 3 · 安穩

**停擺核**：放下劍。我替你撐大鐘。你回閣樓。舊鑰會在。  
**停擺核**：永遠不上弦的安穩——這不就是「發條最鬆」嗎？

| 選項 | 顯示 |
|------|------|
| A | **我拒絕**（字級 ×1.8～2.0，幾乎搶畫面） |
| B | （若有）我想回家——選後停擺核冷笑「那就沉睡」強制接戰鬥傷害波，仍可打；或再跳回 A |

**第三次拒絕演出（必做）：**  
- 「我拒絕」可佔畫面中下部 40% 寬  
- 確認後：黑鏽大片剝落  
- 停擺核外形收束為「舊先行者」殘影（發條偶輪廓淡）  
- 進入終段血量

→ `flag.c6_refuse_power / revenge / peace` 分別記錄  
→ 成就「心不餵鏽」：三階段皆拒

### 終段

（可再放 1 次黑鏽必殺格擋，橫幅可仍用「微末一格」或「微末到底」。）

**停擺核（殘影）**：……輕。還是那麼輕。卻不退。

而那個曾經連劍都拔了三次才拔起的發條兔，站在晨光裡——

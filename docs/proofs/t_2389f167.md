# 驗收證明 · PowerStatDialog 戰力屬性總覽新增每日上發條委託進度卡片與前往委託快捷按鈕 (t_2389f167)

## 任務概述
依據任務規範，於《發條之心》戰力屬性總覽彈窗（`PowerStatDialog`，`power_stat_dialog.gd`）內容滾動列表中新增『冒險委託上發條』進度卡片（`WindupDailyCard`），動態顯示今日日常委託完成進度（如 0/4 -> 4/4）、委託狀態標籤膠囊（`待完成委託` / `今日已完成`）與今日領取膠囊（`今日未領取` / `可領取獎勵` / `今日已領取`），並於卡片右側提供『前往委託』(`BtnGoWindupDaily`) 立體果凍按鈕。點擊後安全關閉戰力總覽並連動大廳直通開啟每日委託彈窗（`MobileLobby.open_windup_daily()`），形成完整的日常委託與戰力屬性雙向快捷閉環。

---

## 實作規格與設計標準

1. **WindupDailyCard 卡片外觀與排版**：
   - 樣式底色：多巴胺奶油白底 `COLOR_CARD_WARM` (`#FFF8E7`)、深藍紫描邊 `COLOR_BORDER` (`#1F1A3A`)、邊框 2px、底邊厚底 4px、圓角 14px。
   - 標題列：橙色標題 `WindupCardTitleLabel` (`COLOR_TEXT_ORANGE` `#C2600A`)，字級 14px，加粗，零系統 Emoji。
   - 委託狀態標籤膠囊：`WindupStatusCapsule`（圓角 10px、邊框 1px、底邊 3px），內含 `WindupStatusLabel`（12px 加粗字）。未完成顯示「待完成委託」（金黃底色 `#FFF4D0`、橙色字），全部完成顯示「今日已完成」（薄荷綠底色 `#EAF9EE`、綠色字 `#1E8238`）。
   - 今日領取膠囊：`WindupClaimCapsule`（圓角 10px、邊框 1px、底邊 3px），內含 `WindupClaimLabel`（12px 加粗字）。未領取顯示「今日未領取」，可領取顯示「可領取獎勵」，已領取顯示「今日已領取」（天藍底色 `#F0F7FF`、深藍紫字）。
   - 委託進度標籤：`WindupProgressLabel`（字級 12px 加粗，深藍紫字 `#1F1A3A`），動態顯示今日委託完成進度（如「今日委託進度: 0/4 · 釘釘的風箱停了」->「今日委託進度: 4/4 · 釘釘的風箱停了」）。
   - 說明標籤：`WindupDescLabel`（字級 11px，次要文字顏色 `#6B6680`，文字「每天一件發條小事 · 完成日常委託領取星屑與金幣」）。

2. **BtnGoWindupDaily 前往委託快捷按鈕**：
   - 尺寸與熱區：寬度 `custom_minimum_size = Vector2(120, 48)`，高度 48px，熱區符合手機端規範（>= 48px）。
   - 多巴胺樣式：金黃色盤 `COLOR_GOLD` (`#FFD028`)，深藍紫加粗字 `COLOR_TEXT_DARK` (`#1F1A3A`)，果凍底厚 5px，圓角 18px，深藍紫描邊 `#1F1A3A`，零系統 Emoji。
   - 提供存取器：`get_go_windup_daily_button() -> Button`、`get_windup_daily_card() -> PanelContainer` 與 `scroll_to_windup_daily_card() -> void`。

3. **雙向連動與閉環**：
   - 點擊按鈕後發射 `windup_daily_requested` 訊號並觸發關閉 `_on_close_pressed()`。
   - `MobileLobby.open_power_stat_dialog()` 內監聽 `windup_daily_requested` 訊號並呼叫 `open_windup_daily()`，安全開啟 `WindupDailyDialog` 冒險委託上發條彈窗。
   - `WindupDailyDialog` 內已有 `BtnGoPowerStat` 前往戰力按鈕，與 `PowerStatDialog` 形成完整的雙向快捷閉環。

4. **六語系多國語言即時切換**：
   - 完整支援 `zh_TW`, `zh_CN`, `en`, `ja`, `ko`, `es` 六語系，無缺失字、無 fallback 失敗、無系統 Emoji。

# 驗收證明 · ForgeDialog 天宮鐵匠底欄新增『前往背包』快捷果凍按鈕聯動 MapleInventory (t_41201712)

## 1. 任務說明與驗收規範
在 `ForgeDialog`（天宮鐵匠裝備鍛造彈窗）底欄操作按鈕列 (`act_row`) 新增『前往背包』(`BtnGoInventory`) 快捷果凍按鈕，點擊直接切換開啟 `MapleInventory` 探索背包彈窗，讓玩家在鍛造裝備時能隨時一鍵前往背包檢視武器庫存、材料與剛鍛造出的詞條，與探索背包的前往鍛造功能達成雙向閉環。

- **按鈕規格樣式**：
  - 命名為 `BtnGoInventory`，位於底欄 `act_row` 按鈕列倒數第二位（前往商城與離開鐵匠鋪之間）。
  - 尺寸熱區 115x50px（寬度 >= 100px，高度 50px >= 48px），符合人體工學防誤觸標準。
  - 多巴胺天藍色盤 `COLOR_SKY` (`#38A0FF`)，立體果凍厚底 5px，圓角 18px，深藍紫描邊 `#1F1A3A`。
  - 16px 開源粉圓體字型，深藍紫字帶描邊，100% 徹底清除系統 Emoji。
- **點擊連動與雙向閉環**：
  - 提供 `inventory_requested` 與 `go_inventory` 雙訊號，以及 `get_go_inventory_button()` 存取器。
  - 點擊按鈕安全發射 `closed` 訊號並順暢關閉 ForgeDialog（無遮罩殘留）。
  - 大廳接收訊號連動開啟 `MapleInventory` 探索背包彈窗。
  - 探索背包中點擊『前往鍛造』(`BtnBagGoForge`) 順暢返回 `ForgeDialog`。
- **六語系即時切換**：
  - 繁中 `zh_TW`：`前往背包`
  - 簡中 `zh_CN`：`前往背包`
  - 英文 `en`：`Go to Inventory`
  - 日文 `ja`：`インベントリへ進む`
  - 韓文 `ko`：`인벤토리로 이동`
  - 西文 `es`：`Ir al Inventario`

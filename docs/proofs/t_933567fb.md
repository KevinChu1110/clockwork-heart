# WardrobeDialog 衣櫥換裝彈窗底欄新增『前往儲能庫』快捷果凍按鈕聯動 ClockworkVaultDialog 驗收證明 (t_933567fb)

## 1. 任務背景與驗收目標
依據任務規範，於《發條之心》角色換裝衣櫥彈窗（`WardrobeDialog`，`wardrobe_dialog.gd`）底欄操作列（`actions_hbox`）新增『前往儲能庫』立體果凍按鈕（`BtnGoVault`），支援六語系即時切換，點擊後觸發音效、發射 `vault_requested` 與 `go_vault` 信號並安全關閉彈窗，大廳接收後直通開啟發條儲能庫放置收益彈窗 `ClockworkVaultDialog`，形成流暢的快捷跳轉體驗。

### 功能特性與 UI 規範：
- **按鈕樣式與尺寸**：
  - 名稱：`BtnGoVault`
  - 樣式：多巴胺金黃色盤 `#FFD028`（`COLOR_GOLD`）、圓角 18px、厚底 5px、深藍紫描邊 `#1F1A3A`（`COLOR_BORDER` 2px）與深色字 `#1F1A3A`
  - 尺寸熱區：實裝 `105x50px`（熱區高 `>= 48px`，符合手遊人體工學規範）
  - 零系統 Emoji，採用開源粉圓體（Open-Huninn）
- **信號發射與大廳連動**：
  - 點擊發射 `vault_requested` 與 `go_vault` 信號
  - 安全發射 `closed` 信號並關閉 `WardrobeDialog`，無殘留遮罩
  - 大廳（`MobileLobby`）即時監聽並呼起發條儲能庫放置收益彈窗 `ClockworkVaultDialog`
- **六語系對齊**：
  - `wardrobe.btn_go_vault` / `wardrobe.go_vault`：
    - 繁體中文（zh_TW）：`前往儲能庫`
    - 簡體中文（zh_CN）：`前往储能库`
    - 英文（en）：`To Vault`
    - 日文（ja）：`貯蔵庫へ`
    - 韓文（ko）：`저장고로 이동`
    - 西班牙文（es）：`Ir a Bóveda`
- **存取器**：
  - 提供 `get_go_vault_button() -> Button` 與 `get_vault_button() -> Button`

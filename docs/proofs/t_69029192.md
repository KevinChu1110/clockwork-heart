## 1. 任務背景與驗收目標
依據任務規範，於《發條之心》木人樁試招結算數據卡（`DummySettlementDialog`，`dummy_settlement_dialog.gd`）底部按鈕列新增『前往背包』（`BtnGoInventory`）快捷果凍按鈕，打通玩家在木人樁試招結算後直通探索背包（`MapleInventory`）調配裝備與機芯的快捷跳轉連動：
1. **按鈕規格與樣式**：
   - 位於底部操作按鈕列（`ButtonHBox`），緊鄰『前往戰力』按鈕並列。
   - 多巴胺天藍色盤 `#38A0FF`，深藍紫描邊 2px `#1F1A3A`，文字深藍紫 `#1F1A3A`。
   - 尺寸 140x50px（高度 50px，熱區 >= 48px，寬度 >= 130px，符合手機端防誤觸人因規範）。
   - 果凍厚底 5px（`border_width_bottom = 5`），圓角 16px（符合 16~18px 規範），字級 18px 開源粉圓體（Open Huninn），100% 徹底清除系統 Emoji、零禁止符號。
2. **點擊連動與彈窗銷毀**：
   - 點擊後發出 `go_inventory` 與 `inventory_requested` 訊號，並執行 `setup` 傳入之 `on_inventory` 回調。
   - 安全銷毀結算彈窗（`queue_free`），無殘留遮罩、無介面卡死。
   - `BattleView` 或大廳接收後發射 `inventory_requested`，平滑直通開啟 `MapleInventory` 探索背包。
3. **存取器**：
   - 提供 `get_go_inventory_button() -> Button`。
   - 提供 `get_inventory_button() -> Button`（相容別名）。
   - 提供 `get_go_inventory_button_text() -> String`。
   - 提供 `get_go_inventory_text() -> String`。
4. **六語系在地化支援**：
   - 完整支援 `zh_TW`, `zh_CN`, `en`, `ja`, `ko`, `es` 六語系即時切換。
   - zh_TW：前往背包
   - zh_CN：前往背包
   - en：Go to Inventory（零 CJK 殘留）
   - ja：インベントリへ進む
   - ko：인벤토리로 이동
   - es：Ir al Inventario（零 CJK 殘留）
   - 全語系零系統 Emoji。
5. **合規與自動化測試**：
   - 遵守 review.md 與 AGENTS.md 規範，撰寫無頭測試 `test_dummy_settlement_inventory_shortcut.gd`。

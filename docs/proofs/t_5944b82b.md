# 驗收證明 · ColossusLimitDialog 停擺巨偶限制彈窗新增前往戰力與前往鍛造快捷果凍按鈕 (t_5944b82b)

## 1. 任務背景與驗收目標
依據任務規範，於《發條之心》停擺巨偶次數用盡/限制彈窗（`ColossusLimitDialog`，`mobile_lobby.gd`）底部確認按鈕旁新增『前往戰力』(`BtnGoPowerStat`) 與『前往鍛造』(`BtnGoForge`) 立體果凍按鈕，打通停擺巨偶直通戰力屬性總覽（`PowerStatDialog`）與天宮鐵匠（`ForgeDialog`）的雙向引導閉環：
1. **按鈕規格與樣式**：
   - 底部並列三顆果凍按鈕：`ConfirmButton`（確定）、`BtnGoPowerStat`（前往戰力）、`BtnGoForge`（前往鍛造）。
   - 按鈕尺寸 `160x52px`，滿足寬度 `>= 120px`、高度 `52px`（`>= 48px` 手機端熱區防誤觸）。
   - 金黃 `#FFD028`、天藍 `#38A0FF`、暖橘 `#FFA010` 多巴胺色彩體系，深藍紫描邊 `#1F1A3A`，果凍厚底 `5px`，圓角 `18px`，字級 `18px` 開源粉圓體（Open Huninn），100% 零系統 Emoji。
2. **點擊聯動與安全關閉**：
   - 點擊 `BtnGoPowerStat`：發射 `power_stat_requested` 與 `closed` 訊號，安全關閉 `ColossusLimitDialog`（`queue_free` 無遮罩殘留），連動開啟 `PowerStatDialog`。
   - 點擊 `BtnGoForge`：發射 `forge_requested` 與 `closed` 訊號，安全關閉 `ColossusLimitDialog`（`queue_free` 無遮罩殘留），連動開啟天宮鐵匠 `ForgeDialog`。
   - 點擊 `ConfirmButton`：發射 `confirmed` 與 `closed` 訊號，安全關閉 `ColossusLimitDialog`。
3. **存取器與訊號**：
   - 提供 `MobileLobby.show_colossus_limit_dialog() -> Control` 與 `get_colossus_limit_dialog() -> Control`。
   - `dlg` 動態掛載 `power_stat_requested`、`forge_requested`、`confirmed`、`closed` 訊號。
4. **六語系在地化支援**：
   - 完整支援 `zh_TW`, `zh_CN`, `en`, `ja`, `ko`, `es` 六語系即時切換。
   - 字典鍵值：
     - `colossus.btn_confirm`（繁中：確定，簡中：确定，en：OK，ja：確認，ko：확인，es：Aceptar）
     - `colossus.btn_go_power_stat`（繁中：前往戰力，簡中：前往战力，en：Go to Stats，ja：戦力詳細へ，ko：전투력으로 이동，es：Ir a Estadísticas）
     - `colossus.btn_go_forge`（繁中：前往鍛造，簡中：前往锻造，en：Go to Forge，ja：鍛造へ進む，ko：단조로 이동，es：Ir a Forja）

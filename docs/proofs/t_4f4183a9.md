## 1. 任務背景與驗收目標
依據任務規範，於《發條之心》木人樁試招結算數據卡（`DummySettlementDialog`，`dummy_settlement_dialog.gd`）底部按鈕列新增『前往戰力』（`BtnGoPowerStat`）快捷果凍按鈕，打通玩家在木人樁打出 DPS 與輪替統計後直通戰力屬性總覽（`PowerStatDialog`）的快捷跳轉連動：
1. **按鈕規格與樣式**：
   - 位於底部操作按鈕列（`ButtonHBox`），排列於再次試招、調整心法與完成試招之間。
   - 多巴胺天藍色盤 `#38A0FF`，深藍紫描邊 2px `#1F1A3A`，文字深藍紫 `#1F1A3A`。
   - 熱區尺寸 150x50px（高度 50px，熱區 >= 48px，符合手機端防誤觸人因規範）。
   - 果凍厚底 5px（`border_width_bottom = 5`，在 3~5px 規範內），圓角 14px（在 12~14px 規範內），字級 18px 開源粉圓體（Open Huninn），100% 徹底清除系統 Emoji、零禁止符號。
2. **點擊連動與彈窗銷毀**：
   - 點擊後發出 `go_power_stat` 與 `power_stat_requested` 訊號，並執行 `setup` 傳入之 `on_power_stat` 回調。
   - 安全銷毀結算彈窗（`queue_free`），無殘留遮罩、無介面卡死。
   - `BattleView` 接收後發射 `power_stat_requested`，平滑直通開啟 `PowerStatDialog` 戰力屬性總覽。
3. **存取器**：
   - 提供 `get_go_power_stat_button() -> Button`。
   - 提供 `get_power_stat_button() -> Button`（相容別名）。
   - 提供 `get_go_power_stat_button_text() -> String`。
   - 提供 `get_go_power_stat_text() -> String`。
4. **六語系在地化支援**：
   - 完整支援 `zh_TW`, `zh_CN`, `en`, `ja`, `ko`, `es` 六語系即時切換。
   - zh_TW：前往戰力
   - zh_CN：前往战力
   - en：View Power（零 CJK 殘留）
   - ja：戦力へ
   - ko：전투력 보기
   - es：Ver Poder（零 CJK 殘留）
   - 全語系零系統 Emoji。
5. **合規與自動化測試**：
   - 遵守 review.md 與 AGENTS.md 規範，撰寫無頭測試 `test_dummy_settlement_go_power_stat.gd`。

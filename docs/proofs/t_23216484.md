# TitleWallDialog 稱號牆底欄新增『前往工坊』快捷果凍按鈕驗收清單 (t_23216484)

## 驗收項目
- [x] 按鈕節點命名：`BtnGoWorkshop`，位於 `TitleWallDialog` 底部操作按鈕列 (`ButtonRow`)
- [x] 按鈕尺寸熱區合規：寬度 150px、高度 52px >= 48px，符合手遊人體工學觸控熱區規範
- [x] 多巴胺果凍厚底規範：薄荷綠底色 `#4ED86A`、底邊厚底 5px、圓角 18px、深藍紫描邊 `#1F1A3A`
- [x] 100% 零系統 Emoji：全介面與按鈕文字皆純文字開源粉圓體渲染，無廉價 Unicode Emoji
- [x] 點擊連動：點擊發射 `workshop_requested`、`go_workshop` 與 `closed` 訊號，安全關閉稱號牆彈窗（無遮罩殘留）並直通呼起 `GemWorkshopDialog`
- [x] 雙向閉環：關閉 `GemWorkshopDialog` 可順暢返回 `TitleWallDialog` 形成操作閉環
- [x] 存取器提供：提供 `get_go_workshop_button()` 與 `get_workshop_button()` 存取器
- [x] 六語系 i18n 完整支援：

  - 簡體中文 (zh_CN)：前往工坊
  - 英文 (en)：Go to Workshop
  - 日文 (ja)：工房へ進む
  - 韓文 (ko)：공방으로 이동
  - 西班牙文 (es)：Ir al Taller
- [x] 實機截圖完整存證，8 張真實 Framebuffer 截圖無黑屏、雜湊全部獨立唯一

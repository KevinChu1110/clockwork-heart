# 驗收證明 · BattleVictoryDialog 關卡勝利結算新增『前往背包』快捷果凍按鈕連動 MapleInventory (t_567d8611)

## 1. 任務背景與驗收目標
依據任務規範，於《發條之心》出征關卡勝利結算彈窗（`BattleVictoryDialog`，`battle_victory_dialog.gd`）底部按鈕列新增『前往背包』（`BtnGoInventory`）快捷果凍按鈕，打通關卡通關獲得戰利品與機芯掉落後直通探索背包（`MapleInventory`）的快捷跳轉連動：
1. **按鈕規格與樣式**：
   - 位於底部操作按鈕列（`btn_row`），排列於前往戰力與再次挑戰之間。
   - 多巴胺珊瑚粉色盤 `#FF5E8A`（`COLOR_PINK`），深藍紫描邊 `#1F1A3A`，文字深藍紫 `#1F1A3A`。
   - 熱區尺寸 130x50px（高度 50px，熱區 >= 48px，符合手機端防誤觸人因規範）。
   - 果凍厚底 5px（`border_width_bottom = 5`），圓角 16px（在 14~18px 規範內），字級 16px 開源粉圓體（Open Huninn），零系統 Emoji、零禁止符號。
2. **點擊聯動與彈窗銷毀**：
   - 點擊後發射 `inventory_requested` 與 `go_inventory` 訊號並執行 `setup` 傳入之 `on_inventory` 回調。
   - 安全銷毀結算彈窗（`queue_free`），無殘留遮罩、無介面卡死。
   - `BattleView` 接收後發射 `inventory_requested` 與 `battle_finished`（won=true），平滑開啟 `MapleInventory` 探索背包。
3. **存取器**：
   - 提供 `get_go_inventory_button() -> Button`。
   - 提供 `get_inventory_button() -> Button`（相容別名）。
   - 提供 `get_go_inventory_button_text() -> String`。
4. **六語系在地化支援**：
   - 完整支援 `zh_TW`, `zh_CN`, `en`, `ja`, `ko`, `es` 六語系即時切換。
   - 繁中：前往背包
   - 簡中：前往背包
   - 英文：Go to Inventory（零 CJK 殘留）
   - 日文：インベントリへ進む
   - 韓文：인벤토리로 이동
   - 西文：Ir al Inventario（零 CJK 殘留）
   - 全語系零系統 Emoji。
5. **合規與自動化測試**：
   - 遵守 review.md 與 AGENTS.md 規範，撰寫單元與整合測試 `test_battle_victory_inventory_shortcut.gd`。
   - 執行 `clock-check` 確保零警告，OpenGL3 真實渲染截圖存證完備。

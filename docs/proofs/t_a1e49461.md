# 驗收證明 · WardrobeDialog 衣櫥換裝彈窗底欄新增『前往背包』快捷果凍按鈕連動 MapleInventory (t_a1e49461)

## 1. 任務背景與驗收目標
依據任務規範，於《發條之心》角色換裝衣櫥彈窗（`WardrobeDialog`，`wardrobe_dialog.gd`）底欄動作區（`actions_hbox`）新增『前往背包』立體果凍按鈕（`BtnGoInventory`），打通衣櫥換裝直通探索背包彈窗（`MapleInventory`）的快捷閉環：
1. **按鈕規格與樣式**：
   - 位於底部操作按鈕列（`actions_hbox`），與『還原預設』、『隨機』、『前往戰力』、『前往商城』、『前往稱號』及『確認換裝』等並列。
   - 採用多巴胺暖橘色盤 `#FFA010` (COLOR_ORANGE)，深藍紫描邊 `#1F1A3A` (COLOR_BORDER)，文字深藍紫 `#1F1A3A`。
   - 熱區尺寸 105x50px（符合手機端熱區 >= 48px 與高度 >= 50px 規範）。
   - 果凍厚底 5px，圓角 18px，字級 16px 開源粉圓體（Open Huninn），100% 零系統 Emoji 與特殊符號。
2. **點擊連動與安全關閉**：
   - 點擊後發射 `go_inventory` 訊號與 `inventory_requested` 訊號，同時發射 `closed` 訊號。
   - 安全關閉 `WardrobeDialog`（無遮罩殘留）。
   - 大廳連動開啟 `MapleInventory`（`MobileLobby.open_maple_inventory()`）。
   - 流暢直通切換至探索背包介面。
3. **存取器與訊號**：
   - 提供 `get_go_inventory_button() -> Button` 與 `get_inventory_button() -> Button` 存取器。
   - 提供 `go_inventory()` 與 `inventory_requested()` 訊號。
4. **六語系在地化支援**：
   - 完整支援 `zh_TW`, `zh_CN`, `en`, `ja`, `ko`, `es` 六語系即時切換。
   - 字典鍵值：`wardrobe.btn_go_inventory`（繁中：前往背包，簡中：前往背包，en：To Bag，ja：バッグへ，ko：가방으로，es：A Mochila）。
   - 已同步更新 `game/data/i18n/*.json` 與 `game/data/i18n/content/*/ui.json` 共 12 處檔案。

# WardrobeDialog 衣櫥換裝彈窗底欄新增『前往工坊』快捷果凍按鈕聯動 GemWorkshopDialog 驗收證明 (t_ee1a4077)

## 1. 任務背景與驗收目標
依據任務規範，於《發條之心》角色換裝衣櫥彈窗（`WardrobeDialog`，`wardrobe_dialog.gd`）底欄操作列（`actions_hbox`）新增『前往工坊』立體果凍按鈕（`BtnGoWorkshop`），支援六語系即時切換，點擊後發射 `workshop_requested` 與 `go_workshop` 信號並安全關閉彈窗，大廳接收後直通開啟手藝工坊 `GemWorkshopDialog`，形成流暢的快捷跳轉體驗。

### 功能特性與 UI 規範：
- **按鈕樣式與尺寸**：
  - 名稱：`BtnGoWorkshop`
  - 樣式：多巴胺薄荷綠色盤 `#4ED86A`（`COLOR_MINT`）、圓角 16px、厚底 5px、深藍紫描邊 `#1F1A3A`（`COLOR_BORDER` 2px）與深色字 `#1F1A3A`
  - 尺寸熱區：實裝 `105x50px`（熱區高 `>= 48px`，符合手遊人體工學規範）
  - 零系統 Emoji，採用開源粉圓體（Open-Huninn）
- **信號發射與大廳連動**：
  - 點擊發射 `workshop_requested` 與 `go_workshop` 信號
  - 安全發射 `closed` 信號並關閉 `WardrobeDialog`，無殘留遮罩
  - 大廳（`MobileLobby`）即時監聽並呼起手藝工坊 `GemWorkshopDialog`
- **六語系對齊**：
  - `wardrobe.btn_go_workshop` / `wardrobe.go_workshop`：
    - 繁體中文（zh_TW）：`前往工坊`
    - 簡體中文（zh_CN）：`前往工坊`
    - 英文（en）：`Go to Workshop`
    - 日文（ja）：`工房へ進む`
    - 韓文（ko）：`공방으로 이동`
    - 西班牙文（es）：`Ir al Taller`
- **存取器**：
  - 提供 `get_go_workshop_button() -> Button` 與 `get_workshop_button() -> Button`

# 驗收證明 · ForgeDialog 天宮鐵匠底欄新增『前往戰力』快捷果凍按鈕聯動 PowerStatDialog (t_a7b67508)

## 1. 任務背景與驗收目標
依據任務規範，於《發條之心》天宮鐵匠鍛造彈窗（`ForgeDialog`，`forge_dialog.gd`）底部操作按鈕列（`act_row`）新增『前往戰力』立體果凍按鈕（`BtnGoPowerStat`），打通天宮鐵匠直通戰力屬性總覽（`PowerStatDialog`）的雙向閉環：
1. **按鈕規格與樣式**：
   - 位於底部操作按鈕列，與『前往工坊』及『離開鐵匠鋪』並列。
   - 金黃色盤 `#FFD028`，深藍紫描邊 `#1F1A3A`，文字深藍紫 `#1F1A3A`。
   - 熱區尺寸 140x50px（>= 48px 手機端防誤觸人體工學規範）。
   - 果凍厚底 5px，圓角 18px，字級 16px 開源粉圓體（Open Huninn），零系統 Emoji。
2. **點擊聯動與安全關閉**：
   - 點擊後發射 `power_stat_requested` 訊號與 `closed` 訊號。
   - 安全關閉 `ForgeDialog`（無遮罩殘留）。
   - 大廳連動開啟 `PowerStatDialog`（`MobileLobby.open_power_stat_dialog()`）。
   - 與 `PowerStatDialog` 內『前往鍛造』形成完整雙向閉環。
3. **存取器與訊號**：
   - 提供 `get_go_power_stat_button() -> Button` 存取器。
   - 提供 `power_stat_requested` 訊號。
4. **六語系在地化支援**：
   - 完整支援 `zh_TW`, `zh_CN`, `en`, `ja`, `ko`, `es` 六語系即時切換。
   - 字典鍵值：`forge.btn_go_power_stat`（繁中：前往戰力，簡中：前往战力，en：Go to Stats，ja：戦力詳細へ，ko：전투력으로 이동，es：Ir a Estadísticas）。

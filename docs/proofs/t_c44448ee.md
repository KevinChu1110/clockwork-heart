# 驗收證明 · PowerStatDialog 戰力屬性總覽新增發條儲能庫放置進度卡片與前往儲能快捷按鈕 (t_c44448ee)

## 任務概述
依據任務規範，於《發條之心》戰力屬性總覽彈窗（`PowerStatDialog`，`power_stat_dialog.gd`）內容捲軸中新增『發條儲能庫』放置收益卡片（`ClockworkVaultCard` / `VaultCard`），顯示目前累積放置能量值、上限（8小時）與當前產能效率膠囊，並於右側提供『前往儲能』(`BtnGoVault`) 快捷立體果凍按鈕。點擊後關閉戰力總覽並連動大廳直通開啟發條儲能庫彈窗（`MobileLobby.open_clockwork_vault()`），形成完整的放置收益與戰力檢視雙向快捷閉環。

---

## 實作規格與設計標準

1. **ClockworkVaultCard 卡片外觀與排版**：
   - 樣式底色：多巴胺奶油白底 `COLOR_CARD_WARM` (`#FFF8E7`)、深藍紫描邊 `COLOR_BORDER` (`#1F1A3A`)、邊框 2px、底邊厚底 4px、圓角 14px。
   - 標題列：橙色標題 `VaultCardTitleLabel` (`COLOR_TEXT_ORANGE` `#C2600A`)，字級 14px，加粗，零系統 Emoji。
   - 產能效率膠囊：`VaultRateCapsule`（金黃柔和卡片底 `#FFF4D0`、深藍紫描邊、底邊 3px、圓角 10px），內含 `VaultRateLabel`（深藍紫加粗字 12px），顯示當前基礎產能「產能: 150金·3鐵/h」（每小時150金幣、3鐵屑）。
   - 累積能量值與上限：`VaultEnergyLabel`，依 `IdleClockworkVault.get_status()` 動態顯示累積能量時間與百分比（如「累積能量: 00:00 / 08:00 (0%)」、「累積能量: 04:00 / 08:00 (50%)」，若達8小時上限則顯示「累積能量: 08:00 / 08:00 [已蓄滿 (8小時)]」）。
   - 說明標籤：`VaultDescLabel`（字級 11px，次要文字顏色 `#6B6680`，文字「放置收益隨時間蓄能 · 離線最高累計8小時」）。

2. **BtnGoVault 前往儲能快捷按鈕**：
   - 尺寸與熱區：寬度 `custom_minimum_size = Vector2(120, 48)`，高度 48px，熱區符合手機端規範（>= 48px）。
   - 多巴胺樣式：金黃色盤 `COLOR_GOLD` (`#FFD028`)，深藍紫加粗字 `COLOR_TEXT_DARK` (`#1F1A3A`)，果凍底厚 5px，圓角 18px，深藍紫描邊 `#1F1A3A`，零系統 Emoji。
   - 提供存取器：`get_go_vault_button() -> Button`、`get_clockwork_vault_card() -> PanelContainer` 與 `get_vault_card() -> PanelContainer`。

3. **雙向連動與閉環**：
   - 點擊按鈕後發射 `vault_requested` 訊號並觸發關閉 `_on_close_pressed()`。
   - `MobileLobby.open_power_stat_dialog()` 內監聽 `vault_requested` 訊號並呼叫 `open_clockwork_vault()`，安全開啟 `ClockworkVaultDialog` 放置收益彈窗。
   - `ClockworkVaultDialog` 內已有 `BtnGoPowerStat` 前往戰力按鈕，與 `PowerStatDialog` 形成完整的雙向快捷閉環。

4. **六語系多國語言即時切換**：
   - 完整支援 `zh_TW`, `zh_CN`, `en`, `ja`, `ko`, `es` 六語系，無缺失字、無 fallback 失敗、無系統 Emoji。

# 全面回歸驗收證明 · ForgeDialog 機芯一鍵校準分支合進主線後的全站回歸驗收 (t_1028c4a6)

## 1. 任務背景與驗收目標
針對已通過測試審查（測試小婷 `sideqa` 完成審查驗收並簽核通過）之重要功能分支：
- **`forge-core-auto-calibrate`（t_4f136f47）**：分支 `agent/20261012-forge-core-auto-calibrate-t_4f136f47`
  - 天宮鐵匠（`game/scripts/ui/forge_dialog.gd`）機芯五槽部位面板標題列新增『一鍵校準』果凍按鈕（`BtnAutoCalibrateCore`，130x48px，熱區 >= 48px，多巴胺金黃果凍厚底 5px，圓角 14px，深藍紫描邊，零 Emoji）
  - 連動 CoreSystem：點擊後檢查鐵屑（`GameState.iron_scrap` / `CoreSystem.has_enough_scrap_to_calibrate()`），依序循環校準已裝備機芯至鐵屑不足或滿色階
  - 即時反饋：五槽色階光暈與剩餘次數即時刷新、頂部戰力（`TopPowerLabel`）即時增長、彈出獨立 Toast 提示「一鍵校準完成！共校準 X 次 · 戰力提升 +XX · 消耗 XX 鐵屑」
  - 完整安全防護：無鐵屑時彈出提示並阻擋、未裝備機芯時安全阻擋、全部滿階/達上限時安全阻擋
  - 六語系（zh_TW, zh_CN, en, ja, ko, es）在地化即時切換支援，歐美語系零 CJK 殘留

由工程師阿翔（`sideworker2`）在 `main` 主線執行分支乾淨合併（Merge commit: `6da71b1dc`），解決潛在衝突，執行全套無頭冒煙測試、全套單元測試、官網 live 檢測與素材檢查，並透過 `project_status.py` 同步將 `forge-core-auto-calibrate` 更新為『已上線』（commit `1fce92e91`），並推向 `origin/main`。

# WardrobeDialog 衣櫥換裝彈窗底欄新增『前往心法』快捷果凍按鈕聯動 SkillDialog 驗收證明 (t_d81cf274)

## 1. 任務背景與驗收目標
依據任務規範，於《發條之心》角色換裝衣櫥彈窗（`WardrobeDialog`，`wardrobe_dialog.gd`）底欄操作列（`actions_hbox`）新增『前往心法』立體果凍按鈕（`BtnGoSkill`），支援六語系即時切換，點擊後發射 `skill_requested` 與 `go_skill` 信號並安全關閉彈窗，大廳接收後直通開啟招式心法彈窗 `SkillDialog`，形成流暢的快捷跳轉體驗。

### 功能特性與 UI 規範：
- **按鈕樣式與尺寸**：
  - 名稱：`BtnGoSkill`
  - 樣式：多巴胺珊瑚粉色盤 `#FF5E8A`（`COLOR_CORAL` / `COLOR_PINK`）、圓角 16px、厚底 5px、深藍紫描邊 `#1F1A3A`（`COLOR_BORDER` 2px）與深色字 `#1F1A3A`
  - 尺寸熱區：實裝 `105x52px`（熱區高 `>= 48px`，符合手遊人體工學規範）
  - 零系統 Emoji，採用開源粉圓體（Open-Huninn）
- **信號發射與大廳連動**：
  - 點擊發射 `skill_requested` 與 `go_skill` 信號
  - 安全發射 `closed` 信號並關閉 `WardrobeDialog`，無殘留遮罩
  - 大廳（`MobileLobby`）即時監聽並呼起心法招式彈窗 `SkillDialog`
- **六語系對齊**：
  - `wardrobe.btn_go_skill` / `wardrobe.go_skill`：
    - 繁體中文（zh_TW）：`前往心法`
    - 簡體中文（zh_CN）：`前往心法`
    - 英文（en）：`Go to Skills`
    - 日文（ja）：`心法へ進む`
    - 韓文（ko）：`심법으로 이동`
    - 西班牙文（es）：`Ir a Habilidades`
- **存取器**：
  - 提供 `get_go_skill_button() -> Button` 與 `get_skill_button() -> Button`

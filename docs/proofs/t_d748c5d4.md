   - 位於底部按鈕列 `BottomBar`，與前往背包、前往鍛造、前往商城等按鈕並列。
   - 採用多巴胺薄荷綠色盤 `COLOR_MINT` (`#4ED86A`)，深藍紫描邊 `#1F1A3A`，文字深藍紫 `#1F1A3A`。

2. **點擊連動與安全關閉**：

   - 安全關閉 `SkillDialog`（發射 `closed` 訊號，無殘留遮罩）。
   - 大廳連動開啟 `GemWorkshopDialog`（`MobileLobby.open_gem_workshop()`）。
   - 關閉手藝工坊彈窗可順暢返回心法招式介面（`CONNECT_ONE_SHOT` 回跳連動）。
3. **存取器與訊號**：

   - 宣告 `go_workshop()` 與 `workshop_requested()` 訊號。

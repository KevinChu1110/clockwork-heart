# 驗收證明 · MapleInventory 探索背包底欄新增『前往稱號』快捷果凍按鈕連動 TitleWallDialog (t_a9010a31)

## 1. 任務背景與驗收目標
依據任務規範，於《發條之心》探索背包視窗（`MapleInventory`，`maple_inventory.gd`）底欄快捷按鈕列（`GridBottomBar`）新增『前往稱號』立體果凍按鈕（`BtnGoTitleWall`），打通探索背包直通稱號牆彈窗（`TitleWallDialog`）的快捷連動與雙向閉環：
1. **按鈕規格與樣式**：
   - 位於底欄快捷按鈕列 `GridBottomBar`，與容量進度膠囊、一鍵整理及前往戰力按鈕並列。
   - 採用多巴胺天藍色盤 `#38A0FF`，深藍紫描邊 `#1F1A3A`，文字深藍紫 `#1F1A3A`。
   - 熱區尺寸 120x48px（符合手機端熱區 >= 48px 規範）。
   - 果凍厚底 5px，圓角 18px，字級 16px 開源粉圓體（Open Huninn），100% 零系統 Emoji 與特殊符號（符合 0-UI1 規範）。
2. **點擊連動與安全關閉**：
   - 點擊後發射 `go_title_wall` 與 `title_wall_requested` 訊號，同時發射 `closed` 訊號。
   - 安全關閉 `MapleInventory`（無殘留遮罩）。
   - 大廳連動開啟 `TitleWallDialog`（`MobileLobby.open_title_wall()` / `MobileLobby.open_title_wall_dialog()`）。
   - 流暢切換至稱號牆彈窗介面。
3. **存取器與訊號**：
   - 提供 `get_go_title_wall_button() -> Button`、`get_bag_go_title_wall_button() -> Button` 與 `get_title_wall_button() -> Button` 存取器。
   - 宣告 `go_title_wall()` 與 `title_wall_requested()` 訊號。
4. **六語系在地化支援**：
   - 完整支援 `zh_TW`, `zh_CN`, `en`, `ja`, `ko`, `es` 六語系即時切換。
   - 字典鍵值：`inventory.btn_go_title_wall`（繁中：前往稱號，簡中：前往称号，en：To Titles，ja：称号へ，ko：칭호로，es：A Títulos）。
   - 同步更新 `game/data/i18n/*.json` 與 `game/data/i18n/content/*/ui.json` 共 12 處字典。
   - 歐美語系（en, es）零 CJK 殘留（符合 0-QA28 規範）。

# 驗收證明 · PowerStatDialog 戰力屬性總覽新增停擺巨偶挑戰進度卡片與前往挑戰快捷按鈕 (t_72c395b0)

## 任務概述
依據任務規範，於《發條之心》戰力屬性總覽彈窗（`PowerStatDialog`，`power_stat_dialog.gd`）內容捲軸中新增『停擺巨偶』挑戰進度卡片（`ColossusCard`），顯示今日剩餘挑戰次數（x/3）與推薦巨偶目標，並附『前往挑戰』(`BtnGoColossus`) 快捷立體果凍按鈕。點擊後關閉戰力總覽並連動大廳切換至出征/停擺巨偶介面（`MobileLobby.go_to_colossus()`），形成完整的玩法與戰力雙向快捷閉環。

---

## 實作規格與設計標準

1. **ColossusCard 卡片外觀與排版**：
   - 樣式底色：多巴胺奶油白底 `COLOR_CARD_WARM` (`#FFF8E7`)、深藍紫描邊 `COLOR_BORDER` (`#1F1A3A`)、邊框 2px、底邊厚底 4px、圓角 14px。
   - 標題列：橙色標題 `ColossusCardTitleLabel` (`COLOR_TEXT_ORANGE` `#C2600A`)，字級 14px，加粗，零系統 Emoji。
   - 次數膠囊：`ColossusEntriesCapsule`（金黃柔和卡片底 `#FFF4D0`、深藍紫描邊、底邊 3px、圓角 10px），內含 `ColossusEntriesLabel`（深藍紫加粗字 13px），即時顯示今日剩餘挑戰次數（預設 3/3，支援動態刷新）。
   - 推薦巨偶目標：`ColossusTargetLabel`，依玩家等級動態推薦適合的巨偶（Lv.1~9 推薦「失控發條獅 (Lv.12)」，Lv.10~17 推薦「霧鐘提線人偶 (Lv.20)」，Lv.18+ 推薦「黑鏽蒸氣巨象 (Lv.28)」）。
   - 說明標籤：`ColossusDescLabel`（字級 11px，次要文字顏色 `#6B6680`）。

2. **BtnGoColossus 前往挑戰快捷按鈕**：
   - 尺寸與熱區：寬度 `custom_minimum_size = Vector2(120, 48)`，高度 48px，熱區符合手機端標準（>= 48px）。
   - 多巴胺樣式：金黃色盤 `COLOR_GOLD` (`#FFD028`)，深藍紫加粗字 `COLOR_TEXT_DARK` (`#1F1A3A`)，果凍底厚 5px，圓角 18px，深藍紫描邊 `#1F1A3A`，零系統 Emoji。
   - 提供存取器：`get_go_colossus_button() -> Button` 與 `get_colossus_card() -> PanelContainer`。

3. **雙向連動與閉環**：
   - 點擊按鈕後發射 `colossus_requested` 訊號並觸發關閉 `_on_close_pressed()`。
   - `MobileLobby.open_power_stat_dialog()` 內監聽 `colossus_requested` 訊號並呼叫 `go_to_colossus()`，切換至 `Tab.ADVENTURE` (2) 與 `AdventureSubMode.COLOSSUS` (1)。

4. **六語系多國語言即時切換**：
   - 完整支援 `zh_TW`, `zh_CN`, `en`, `ja`, `ko`, `es` 六語系，無缺失字、無 fallback 失敗、無 Emoji。

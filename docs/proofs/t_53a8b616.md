# 驗收證明 · ShopDialog 商城彈窗底欄新增『前往儲能庫』快捷果凍按鈕連動 ClockworkVaultDialog (t_53a8b616)

## 1. 任務背景與驗收目標
依據任務規範，於《發條之心》道具商城彈窗（`ShopDialog`，`shop_dialog.gd`）底部操作快捷列（`FooterBar`）新增『前往儲能庫』多巴胺立體果凍按鈕（`BtnGoVault`），與已上線的發條儲能庫『前往商城』形成完整雙向閉環：
1. **按鈕規格與樣式**：
   - 位於底部操作按鈕列（`FooterBar`），外層具備 `FooterScroll` 橫向滑動支援，確保 9 顆快捷按鈕在手遊與窄螢幕下皆可流暢操作且不撐破 740~760px 彈窗卡片規範。
   - 多巴胺金黃色盤 `#FFD028`，深藍紫描邊 `#1F1A3A`，文字深藍紫 `#1F1A3A`。
   - 熱區尺寸 140x50px（高度 `>= 50px`，滿足手機端防誤觸人體工學規範 `>= 48px`）。
   - 果凍厚底 5px，圓角 18px，字級 16px 開源粉圓體（Open Huninn），100% 零系統 Emoji。
2. **點擊聯動與雙向閉環**：
   - 點擊後發射 `vault_requested` 訊號與 `go_vault` 訊號。
   - 安全關閉 `ShopDialog`（無遮罩殘留）。
   - 大廳連動開啟 `ClockworkVaultDialog`（`MobileLobby.open_clockwork_vault()`）。
   - 於 `ClockworkVaultDialog` 點擊 `BtnGoShop` 可流暢返回 `ShopDialog` 商城彈窗，達成完整無縫雙向跳轉閉環。
3. **存取器與訊號**：
   - 提供 `get_go_vault_button() -> Button` 與 `get_vault_button() -> Button` 存取器。
   - 提供 `vault_requested` 與 `go_vault` 訊號。
   - 提供 `get_footer_scroll()`、`scroll_footer_to_button()`、`scroll_footer_to_end()`。
4. **六語系在地化支援**：
   - 完整支援 `zh_TW`, `zh_CN`, `en`, `ja`, `ko`, `es` 六語系即時切換。
   - 字典鍵值：`shop.btn_go_vault`（繁中：前往儲能庫，簡中：前往储能库，en：To Vault，ja：貯蔵庫へ，ko：저장고로 이동，es：Ir a Bóveda）。
   - 已同步更新 `game/data/i18n/*.json` 與 `game/data/i18n/content/*/ui.json` 共 12 處檔案。

# 驗收證明 · SkillDialog 心法招式底欄新增『前往商城』快捷果凍按鈕連動 ShopDialog (t_e424b86c)

## 1. 任務背景與驗收目標
依據任務規範，於《發條之心》招式與心法視窗（`SkillDialog`，`skill_dialog.gd`）底部操作按鈕列（`BottomBar`）新增『前往商城』立體果凍按鈕（`BtnGoShop`），打通心法招式直通商城彈窗（`ShopDialog`）的快捷閉環：
1. **按鈕規格與樣式**：
   - 位於底部按鈕列 `BottomBar`，與『前往木人樁試招』、『前往戰力』、『前往背包』及『關閉』按鈕並列。
   - 採用多巴胺暖橘色盤 `#FFA010`，深藍紫描邊 `#1F1A3A`，文字深藍紫 `#1F1A3A`。
   - 熱區尺寸 135x50px（符合手機端熱區 >= 48px、按鈕高 >= 50px 規範）。
   - 果凍厚底 5px，圓角 18px，字級 16px 開源粉圓體（Open Huninn），100% 零系統 Emoji 與特殊符號（符合 0-UI1 規範）。
2. **點擊連動與安全關閉**：
   - 點擊後發射 `go_shop` 與 `shop_requested` 訊號。
   - 安全關閉 `SkillDialog`（發射 `closed` 訊號，無殘留遮罩）。
   - 大廳連動開啟 `ShopDialog`（`MobileLobby.open_shop()`）。
   - 關閉商城可順暢返回心法招式介面（`CONNECT_ONE_SHOT` 回跳連動）。
3. **存取器與訊號**：
   - 提供 `get_go_shop_button() -> Button` 與 `get_shop_button() -> Button` 存取器。
   - 宣告 `go_shop()` 與 `shop_requested()` 訊號。
4. **六語系在地化支援**：
   - 完整支援 `zh_TW`, `zh_CN`, `en`, `ja`, `ko`, `es` 六語系即時切換。
   - 字典鍵值：`skill.btn_go_shop`（繁中：前往商城，簡中：前往商城，en：Go to Shop，ja：ショップへ，ko：상점으로，es：Ir a la tienda）。
   - 同步更新 `game/data/i18n/*.json` 與 `game/data/i18n/content/*/ui.json` 共 12 處字典。
   - 歐美語系（en, es）零 CJK 殘留與零 Emoji（符合 0-QA28 規範）。

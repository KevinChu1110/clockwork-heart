# 驗收證明 · ShopDialog 商城彈窗底欄新增『前往心法』快捷果凍按鈕聯動 SkillDialog (t_4116f7d6)

## 1. 任務背景與驗收目標
依據任務規範，於《發條之心》道具商城彈窗（`ShopDialog`，`shop_dialog.gd`）底部操作快捷列（`FooterBar`）新增『前往心法』多巴胺立體果凍按鈕（`BtnGoSkill`），建立商城與招式心法（`SkillDialog`）的雙向無縫跳轉閉環：
1. **按鈕規格與樣式**：
   - 位於底部操作按鈕列（`FooterBar`），與『前往背包』、『前往聚魂』、『前往鍛造』、『前往戰力』、『前往衣櫥』、『前往稱號』與『前往工坊』並列。
   - 多巴胺天藍色盤 `#38A0FF`，深藍紫描邊 `#1F1A3A`，文字深藍紫 `#1F1A3A`。
   - 熱區尺寸 140x50px（高度 `>= 50px`，滿足手機端防誤觸人體工學規範 `>= 48px`）。
   - 果凍厚底 5px，圓角 18px，字級 16px 開源粉圓體（Open Huninn），100% 零系統 Emoji。
2. **點擊聯動與安全關閉**：
   - 點擊後發射 `skill_requested` 訊號與 `go_skill` 訊號。
   - 安全關閉 `ShopDialog`（無遮罩殘留）。
   - 大廳連動開啟 `SkillDialog`（`MobileLobby.open_skill_dialog()`）。
   - 關閉心法招式彈窗後可流暢返回商城介面。
3. **存取器與訊號**：
   - 提供 `get_go_skill_button() -> Button` 與 `get_skill_button() -> Button` 存取器。
   - 提供 `skill_requested` 與 `go_skill` 訊號。
4. **六語系在地化支援**：
   - 完整支援 `zh_TW`, `zh_CN`, `en`, `ja`, `ko`, `es` 六語系即時切換。
   - 字典鍵值：`shop.btn_go_skill`（繁中：前往心法，簡中：前往心法，en：To Skills，ja：心法へ，ko：심법으로，es：A Habilidades）。
   - 已同步更新 `game/data/i18n/*.json` 與 `game/data/i18n/content/*/ui.json` 共 12 處檔案。

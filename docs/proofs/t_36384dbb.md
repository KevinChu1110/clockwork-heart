# 驗收證明 · PowerStatDialog 戰力屬性總覽新增木人樁試招紀錄卡片與前往試招快捷按鈕 (t_36384dbb)

## 任務概述
依據任務規範，於《發條之心》戰力屬性總覽彈窗（`PowerStatDialog`，`power_stat_dialog.gd`）內容捲軸中新增木人樁試招紀錄卡片（`DummyTrialCard`），顯示玩家在木人樁打出的歷史最佳 DPS、最高單擊傷害與出招記錄，並提供多巴胺立體厚底果凍按鈕『前往試招』(`BtnGoDummyPractice`)。點擊後觸發 `go_dummy_practice` 訊號連動大廳發射 `request_battle("training_dummy")` 進入木人樁試招場景，形成戰力檢視與傷害實測的雙向閉環。

---

## 實作規格與設計標準

1. **DummyTrialCard 卡片外觀與排版**：
   - 樣式底色：多巴胺溫暖米黃底 `COLOR_CARD_WARM` (`#FFF8E7`)、深藍紫描邊 `COLOR_BORDER` (`#1F1A3A`)、邊框 2px、底邊厚底 4px、圓角 14px。
   - 標題列：橙色標題 `DummyTrialCardTitleLabel` (`COLOR_TEXT_ORANGE` `#C2600A`)，字級 14px，加粗，零系統 Emoji。
   - 歷史最佳 DPS 紀錄徽章：`DpsBadgeCapsule`（金黃/柔和天藍多巴胺底、深藍紫描邊、底邊 3px、圓角 10px），內含 `BestDpsLabel`（深藍紫加粗字 13px），無紀錄時顯示「尚未試招」或預設徽章，有紀錄時動態顯示最佳 DPS（如「158.4 DPS」）。
   - 數值詳情列：包含最高單擊標籤 `MaxHitLabel`、出招記錄標籤 `HitCountLabel` 與玩法說明 `DummyDescLabel`。
   - 未試招引導：無紀錄時顯示 `NoRecordGuideLabel`（『尚未進行試招，快前往木人樁測試最高傷害！』，字級 12px，次要文字顏色 `#6B6680`）。

2. **BtnGoDummyPractice 前往試招快捷按鈕**：
   - 尺寸與熱區：寬度 `custom_minimum_size = Vector2(120, 48)`，高度 48px，熱區符合手機端標準（>= 48px）。
   - 多巴胺樣式：天藍色盤 `COLOR_SKY` (`#38A0FF`)，奶油白高亮加粗字 `COLOR_TEXT_LIGHT` (`#FFFDF8`)，果凍底厚 5px，圓角 18px，深藍紫描邊 `#1F1A3A`，零系統 Emoji。
   - 提供存取器：`get_go_dummy_practice_button() -> Button` 與 `get_dummy_trial_card() -> PanelContainer`。

3. **雙向連動與閉環**：
   - 點擊按鈕後發射 `go_dummy_practice` 訊號並觸發關閉 `_on_close_pressed()`。
   - `MobileLobby.open_power_stat_dialog()` 內監聽 `go_dummy_practice` 訊號並轉發 `request_battle.emit("training_dummy")` 進入木人樁試招場景。

4. **六語系多國語言即時切換**：
   - 完整支援 `zh_TW`, `zh_CN`, `en`, `ja`, `ko`, `es` 六語系，無缺失字、無 fallback 失敗、無 Emoji。
   - 各語系標題與按鈕對齊驗收要求：
     - zh_TW: 木人樁試招 / 前往試招
     - zh_CN: 木人桩试招 / 前往试招
     - en: Dummy Trial / Practice
     - ja: 木人試練 / 試練へ
     - ko: 목인 시험 / 시험장 이동
     - es: Prueba de Muñeco / Ir a Prueba

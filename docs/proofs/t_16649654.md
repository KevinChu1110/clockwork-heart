   - 連動：點擊前往衣櫥快捷按鈕發射 `wardrobe_requested` 訊號並平滑開啟衣櫥換裝介面
   - 六語系支援：`power_stat.wardrobe_card`, `power_stat.go_wardrobe`, `power_stat.wardrobe_desc` 等全語系字典齊全
3. **`weapon-swap-power-stat-shortcut`（t_d19df961）**：分支 `agent/20261015-weapon-swap-power-stat-shortcut-t_d19df961`
   - `WeaponSwapDialog` 武器更換彈窗底欄新增『前往戰力』(`BtnGoPowerStat`) 快捷果凍按鈕
   - 規格：天藍色盤 `#38A0FF`、立體厚底 5px、圓角 18px、高 48px、深暖褐描邊 `#1F1A3A`、粉圓體字型
   - 連動：點擊發射 `power_stat_requested` 訊號並關閉武器更換彈窗，大廳平滑開啟 `PowerStatDialog`
   - 六語系支援：`weapon_swap.btn_go_power_stat` 等六語系完整對齊
4. **`power-stat-weapon-swap-shortcut`（t_4fbba577）**：分支 `agent/20261015-power-stat-weapon-swap-shortcut-t_4fbba577`
   - `PowerStatDialog` 戰力屬性總覽三槽武器卡片（`WeaponCard0`, `WeaponCard1`, `WeaponCard2`）支援點擊更換連動 `WeaponSwapDialog`
   - 規格：主手/副手/重武三欄獨立『更換』按鈕，熱區 >= 48px，金黃果凍質感
   - 連動：點擊對應武器欄之更換按鈕發射 `weapon_swap_requested(slot_idx)`，大廳接收並攜帶槽位索引直接開啟該槽位的 `WeaponSwapDialog`
   - 六語系支援：六語系即時切換無缺詞
5. **`skill-inventory-shortcut`（t_ffc46ec7）**：分支 `agent/20261015-skill-dialog-inventory-shortcut-t_ffc46ec7`
   - `SkillDialog` 心法招式底欄操作區新增『前往背包』(`BtnGoInventory`) 快捷果凍按鈕
   - 規格：薄荷綠多巴胺色盤 `#4ED86A`、立體厚底 5px、圓角 18px、高 48px、粉圓體字型
   - 連動：點擊發射 `inventory_requested` 訊號並關閉招式介面，大廳平滑切換至 `MapleInventory` 探索背包並自動選中消耗品（`consumable`）頁籤
   - 六語系支援：`skill.btn_go_inventory` 等六語系完整無遺漏

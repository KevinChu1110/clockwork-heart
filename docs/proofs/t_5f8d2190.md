## 1. 任務背景與規格實作

依據看板任務 `t_5f8d2190` 需求，在 `ClockworkVaultDialog`（發條儲能庫放置收益彈窗）底欄快捷欄位新增『前往衣櫥』多巴胺亮色盤果凍按鈕（`BtnGoWardrobe`），並與 `WardrobeDialog`（衣櫥換裝彈窗）達成平滑互通連動。

### 規格重點與設計標準：
1. **按鈕規格與樣式**：
   - 按鈕名稱：`BtnGoWardrobe`，位於底欄 `foot_box` 操作區。
   - 尺寸與熱區：`Vector2(105, 52)`，高度 52px（>= 48px），完全符合手遊雙拇指人體工學。
   - 多巴胺色盤：底色暖橘 `#FFA010`（`COLOR_ORANGE`）、hover `#FFB030`、深藍紫描邊 `#1F1A3A`（`COLOR_BORDER` 2px）、立體果凍厚底 5px（`border_width_bottom = 5`）、超大圓角 18px（`corner_radius = 18`）、深藍紫文字 `#1F1A3A`（`COLOR_TEXT_DARK` 16px）。
   - 零系統 Emoji：100% 清除 Emoji，採用開源粉圓體（Open-Huninn）。
2. **彈窗版面拓寬適配**：
   - 彈窗主卡片寬度拓寬至 920px（`Vector2(920, 460)`，置中 offset_left -460, offset_right 460），8 顆按鈕（普通領取、雙倍領取、前往委託、前往鍛造、前往背包、前往戰力、前往商城、前往衣櫥）均勻並列、間距 6px，無溢出、無擠壓、無穿框。
3. **點擊連動與音效**：
   - 點擊播放 UI 點擊音效（`AudioManager.play_ui()`）。
   - 同步發射 `wardrobe_requested` 與 `go_wardrobe` 訊號，發射 `closed` 訊號並關閉儲能庫彈窗（`queue_free()`），無遮罩殘留。
   - 大廳 `MobileLobby` 監聽訊號直通開啟 `WardrobeDialog`（`open_wardrobe()` / `open_wardrobe_dialog()`），並提供安全回退邏輯。
4. **六語系 i18n 完整對齊**：
   - 補齊 12 個語系字典檔案之 key（`vault.go_wardrobe` 與 `vault.btn_go_wardrobe`）：
     - 繁體中文 (`zh_TW`): `前往衣櫥`
     - 簡體中文 (`zh_CN`): `前往衣橱`
     - 英文 (`en`): `To Wardrobe`
     - 日文 (`ja`): `衣装部屋へ`
     - 韓文 (`ko`): `의상실로`
     - 西班牙文 (`es`): `Al Armario`
   - 提供防呆回退方法 `_get_go_wardrobe_text()`，支援語系即時平滑切換。
5. **程式碼存取器**：
   - 提供 `get_go_wardrobe_button()` 與別名 `get_wardrobe_button()`。

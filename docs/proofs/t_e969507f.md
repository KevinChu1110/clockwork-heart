   - 狀態流轉：今日上發條次數 (0/3 ~ 3/3)、發條能量累積、完成進度獎勵提示；直通大廳 `open_windup_daily()` 冒險委託介面
   - 六語系支援：完整六語系 key (`power_stat.windup_card`、`power_stat.btn_go_windup`、`power_stat.windup_progress`、`power_stat.windup_completed` 等)
3. **`energy-lack-power-stat-shortcut`（t_fba28e4a）**：分支 `agent/20261014-energy-lack-power-stat-t_fba28e4a`
   - `EnergyLackDialog` 能量不足彈窗底欄操作列新增『前往戰力』(`BtnGoPowerStat`) 快捷果凍按鈕
   - 規格：天藍色盤 `#38A0FF`、立體厚底 5px、圓角 18px、高 48px，與原有關閉/前往商城等按鈕並列排版
   - 連動：點擊後發射 `power_stat_requested` 訊號並銷毀自身，大廳平滑連動開啟 `PowerStatDialog`
   - 六語系支援：支援六語系切換

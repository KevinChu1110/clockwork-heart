### 功能特性與 UI 規範：
- **ForgeDialog 前往背包**：
  - 樣式：多巴胺天藍色盤 `#38A0FF`、圓角 18px、底厚 5px、深藍紫描邊 `#1F1A3A`
  - 尺寸：115x50px（熱區 >= 48px）
  - 連動：點擊發射 `inventory_requested` / `go_inventory` / `closed` 訊號，順暢關閉天宮鐵匠並開啟探索背包 `MapleInventory`，與背包前往鐵匠形成雙向閉環
- **聚魂殿堂前往商城**：
  - 樣式：多巴胺暖橘色盤 `#FFA010`、圓角 18px、底厚 5px、深藍紫描邊 `#1F1A3A`
  - 尺寸：140x52px（熱區 >= 48px）
  - 連動：點擊開啟 `ShopDialog` 商城彈窗，與商城底部前往聚魂形成雙向閉環
- **六語系對齊**：
  - `forge.btn_go_inventory`：繁中 `前往背包`、簡中 `前往背包`、英文 `Go to Inventory`、日文 `インベントリへ進む`、韓文 `인벤토리로 이동`、西文 `Ir al Inventario`
  - `soul_hall.btn_go_shop`：繁中 `前往商城`、簡中 `前往商城`、英文 `To Shop`、日文 `ショップへ`、韓文 `상점으로`、西文 `A Tienda`
- **100% 零系統 Emoji**，完全遵循手遊人體工學與設計規範。

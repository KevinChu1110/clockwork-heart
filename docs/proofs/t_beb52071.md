2. **t_6dfb17d2**：`ForgeDialog` 天宮鐵匠底欄新增『前往心法』快捷果凍按鈕聯動心法招式 `SkillDialog`（分支 `agent/20261017-forge-dialog-skill-shortcut-t_6dfb17d2`）

### 功能特性與 UI 規範：
- **SkillDialog 前往鍛造 (`BtnGoForge`)**：
  - 樣式：多巴胺金黃色盤 `#FFD028`、圓角 18px、底厚 5px、深藍紫描邊 `#1F1A3A`
  - 尺寸：140x50px（熱區 >= 140x48px，高度 >= 50px）
  - 連動：點擊發射 `forge_requested` 與 `go_forge` 信號，順暢關閉心法彈窗並呼起 `ForgeDialog`
- **ForgeDialog 前往心法 (`BtnGoSkill`)**：
  - 樣式：多巴胺天藍色盤 `#38A0FF`、圓角 18px、底厚 5px、深藍紫描邊 `#1F1A3A`
  - 尺寸：140x50px（熱區 >= 140x48px，高度 >= 50px）
  - 連動：點擊發射 `skill_requested` 與 `go_skill` 信號，順暢關閉天宮鐵匠彈窗並呼起 `SkillDialog`
- **雙向閉環流轉**：
  - 心法招式點擊『前往鍛造』直通天宮鐵匠，天宮鐵匠點擊『前往心法』即刻返回心法招式，形成流暢的雙向閉環操作。
- **六語系對齊**：
  - `skill.btn_go_forge` / `ui.btn_go_forge`：繁中 `前往鍛造`、簡中 `前往锻造`、英文 `Go to Forge`、日文 `鍛造へ進む`、韓文 `단조로 이동`、西文 `Ir a Forja`
  - `forge.btn_go_skill` / `ui.btn_go_skill`：繁中 `前往心法`、簡中 `前往心法`、英文 `Go to Skills`、日文 `心法へ進む`、韓文 `심법으로 이동`、西文 `Ir a Habilidades`
- **100% 零系統 Emoji**，完全遵循手遊人體工學與設計規範。

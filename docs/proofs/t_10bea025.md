# SkillDialog 心法招式底欄新增『前往衣櫥』快捷果凍按鈕聯動 WardrobeDialog 驗收證明 (t_10bea025)

## 1. 任務背景與驗收目標
依據任務規範，於《發條之心》心法招式彈窗（`SkillDialog`，`skill_dialog.gd`）底欄操作列（`BottomBar`）新增『前往衣櫥』立體果凍按鈕（`BtnGoWardrobe`），支援六語系即時切換，點擊後發射 `wardrobe_requested` 與 `go_wardrobe` 信號並安全關閉彈窗，大廳接收後直通開啟衣櫥換裝彈窗 `WardrobeDialog`，形成流暢的快捷跳轉體驗。

### 功能特性與 UI 規範：
- **按鈕樣式與尺寸**：
  - 名稱：`BtnGoWardrobe`
  - 樣式：多巴胺金黃色盤 `#FFD028`（`COLOR_GOLD`）、圓角 16px、厚底 5px、深藍紫描邊 `#1F1A3A`（`COLOR_BORDER` 2px）與深色字 `#1F1A3A`
  - 尺寸熱區：實裝 `140x50px`（熱區高 `>= 48px`，符合手遊人體工學規範）
  - 零系統 Emoji，採用開源粉圓體（Open-Huninn）
- **信號發射與大廳連動**：
  - 點擊發射 `wardrobe_requested` 與 `go_wardrobe` 信號
  - 安全發射 `closed` 信號並關閉 `SkillDialog`，無殘留遮罩
  - 大廳（`MobileLobby`）即時監聽並呼起衣櫥彈窗 `WardrobeDialog`
- **六語系對齊**：
  - `skill.btn_go_wardrobe`：
    - 繁體中文（zh_TW）：`前往衣櫥`
    - 簡體中文（zh_CN）：`前往衣橱`
    - 英文（en）：`Go to Wardrobe`
    - 日文（ja）：`衣装部屋へ`
    - 韓文（ko）：`의상실로 이동`
    - 西班牙文（es）：`Ir al Armario`
- **存取器**：
  - 提供 `get_go_wardrobe_button() -> Button` 與 `get_wardrobe_button() -> Button`

# 驗收證明 · TitleWallDialog 稱號牆新增『前往商城』快捷果凍按鈕連動 ShopDialog (t_584613ea)

## 1. 任務背景與驗收目標
依據任務規範，於《發條之心》成就稱號牆視窗（`TitleWallDialog`，`title_wall_dialog.gd`）底部操作按鈕列（`ButtonRow`）新增『前往商城』立體果凍按鈕（`BtnGoShop`），打通稱號牆直通道具商城彈窗（`ShopDialog`）的雙向快捷閉環：
1. **按鈕規格與樣式**：
   - 位於底部操作按鈕列，與『前往戰力』、『前往衣櫥』及『卸下稱號』等並列。
   - 採用多巴胺暖橘色盤 `#FFA010`，深藍紫描邊 `#1F1A3A`，文字白色 `#FFFFFF`（深藍紫描邊 2px）。
   - 熱區尺寸 150x52px（符合手機端熱區 >= 48px 與高度 >= 50px 規範）。
   - 果凍厚底 5px，圓角 18px，字級 18px 開源粉圓體（Open Huninn），100% 零系統 Emoji。
2. **點擊連動與安全關閉**：
   - 點擊後發射 `shop_requested` 訊號與 `closed` 訊號。
   - 安全關閉 `TitleWallDialog`（無遮罩殘留）。
   - 大廳連動開啟 `ShopDialog`（`MobileLobby.open_shop()`）。
   - 流暢切換至商城介面。
3. **存取器與訊號**：
   - 提供 `get_go_shop_button() -> Button` 存取器。
   - 提供 `shop_requested()` 訊號。
4. **六語系在地化支援**：
   - 完整支援 `zh_TW`, `zh_CN`, `en`, `ja`, `ko`, `es` 六語系即時切換。
   - 字典鍵值：`title_wall.btn_go_shop`（繁中：前往商城，簡中：前往商城，en：To Shop，ja：ショップへ，ko：상점으로 이동，es：Ir a Tienda）。
   - 已同步更新 `game/data/i18n/*.json` 與 `game/data/i18n/content/*/ui.json` 共 12 處檔案。

### 功能特性與 UI 規範：
- **WardrobeDialog 前往鍛造 (`BtnGoForge`)**：
  - 樣式：多巴胺天藍色盤 `#38A0FF`、圓角 18px、底厚 5px、深藍紫描邊 `#1F1A3A`
  - 尺寸：105x50px（熱區 >= 105x48px，高度 >= 50px）
  - 連動：點擊發射 `forge_requested` 與 `go_forge` 信號，順暢關閉衣櫥換裝彈窗並呼起 `ForgeDialog`
- **ForgeDialog 前往衣櫥 (`BtnGoWardrobe`)**：
  - 樣式：多巴胺金黃色盤 `#FFD028`、圓角 18px、底厚 5px、深藍紫描邊 `#1F1A3A`
  - 尺寸：140x50px（熱區 >= 115x48px，高度 >= 50px）
  - 連動：點擊發射 `wardrobe_requested` 與 `go_wardrobe` 信號，順暢關閉天宮鐵匠彈窗並呼起 `WardrobeDialog`
- **雙向閉環流轉**：
  - 天宮鐵匠點擊『前往衣櫥』直通衣櫥換裝彈窗，衣櫥換裝點擊『前往鍛造』即刻返回天宮鐵匠，形成流暢的雙向閉環操作。
- **六語系對齊**：
  - `wardrobe.btn_go_forge` / `wardrobe.go_forge`：繁中 `前往鍛造`、簡中 `前往锻造`、英文 `Go to Forge`、日文 `鍛造へ進む`、韓文 `단조로 이동`、西文 `Ir a Forja`
  - `forge.btn_go_wardrobe` / `ui.btn_go_wardrobe`：繁中 `前往衣櫥`、簡中 `前往衣橱`、英文 `Go to Wardrobe`、日文 `衣装部屋へ`、韓文 `의상실로 이동`、西文 `Ir al Armario`
- **100% 零系統 Emoji**，完全遵循手遊人體工學與設計規範。

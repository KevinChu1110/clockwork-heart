# 驗收證明 · MapleInventory 探索背包底欄新增『前往商城』快捷果凍按鈕連動 ShopDialog (t_82713b8f)

## 1. 任務背景與驗收目標
依據任務規範，於《發條之心》探索背包視窗（`MapleInventory`，`maple_inventory.gd`）底欄快捷按鈕列（`GridBottomBar`）新增『前往商城』立體果凍按鈕（`BtnGoShop`），打通探索背包直通商城彈窗（`ShopDialog`）的快捷閉環：
1. **按鈕規格與樣式**：
   - 位於底欄快捷按鈕列 `GridBottomBar`，與容量進度膠囊、一鍵整理及前往戰力按鈕並列。
   - 採用多巴胺薄荷綠色盤 `#4ED86A`，深藍紫描邊 `#1F1A3A`，文字深藍紫 `#1F1A3A`。
   - 熱區尺寸 120x48px（符合手機端熱區 >= 48px 規範）。
   - 果凍厚底 5px，圓角 18px，字級 16px 開源粉圓體（Open Huninn），100% 零系統 Emoji 與特殊符號（符合 0-UI1 規範）。
2. **點擊連動與安全關閉**：
   - 點擊後發射 `go_shop` 與 `shop_requested` 訊號。
   - 安全關閉 `MapleInventory`（無殘留遮罩）。
   - 大廳連動開啟 `ShopDialog`（`MobileLobby.open_shop()` / `MobileLobby.open_shop_dialog()`）。
   - 流暢切換至商城彈窗介面。
3. **存取器與訊號**：
   - 提供 `get_go_shop_button() -> Button`、`get_bag_go_shop_button() -> Button` 與 `get_shop_button() -> Button` 存取器。
   - 宣告 `go_shop()` 與 `shop_requested()` 訊號。
4. **六語系在地化支援**：
   - 完整支援 `zh_TW`, `zh_CN`, `en`, `ja`, `ko`, `es` 六語系即時切換。
   - 字典鍵值：`inventory.btn_go_shop`（繁中：前往商城，簡中：前往商城，en：To Shop，ja：ショップへ，ko：상점으로，es：A Tienda）。
   - 同步更新 `game/data/i18n/*.json` 與 `game/data/i18n/content/*/ui.json` 共 12 處字典。
   - 歐美語系（en, es）零 CJK 殘留（符合 0-QA28 規範）。

# 驗收證明 · ClockworkVaultDialog 發條儲能庫放置收益新增『前往戰力』快捷果凍按鈕聯動 PowerStatDialog (t_9509b047)

## 1. 任務背景與驗收目標
依據任務規範，於《發條之心》發條儲能庫放置收益彈窗（`ClockworkVaultDialog`，`clockwork_vault_dialog.gd`）底欄按鈕列（`foot_box`）新增『前往戰力』立體果凍按鈕（`BtnGoPowerStat`），打通放置收益領取直通戰力屬性總覽（`PowerStatDialog`）的快捷跳轉閉環：
1. **按鈕規格與樣式**：
   - 位於底欄 `ClaimButton`（普通領取）、`DoubleClaimButton`（雙倍領取）、`BtnGoForge`（前往鍛造）、`BtnGoInventory`（前往背包）旁。
   - 天藍色盤 `#38A0FF`，深藍紫描邊 `#1F1A3A`，文字深藍紫 `#1F1A3A`。
   - 熱區尺寸 136x52px（高度 52px >= 50px，熱區 >= 48px 符合手機端防誤觸人體工學規範）。
   - 果凍厚底 5px，圓角 18px，字級 17px 開源粉圓體（Open Huninn），零系統 Emoji。
2. **點擊聯動與安全關閉**：
   - 點擊後發射 `power_stat_requested` 與 `go_power_stat` 訊號與 `closed` 訊號。
   - 安全關閉 `ClockworkVaultDialog`（無遮罩殘留）。
   - 大廳連動開啟 `PowerStatDialog`（`MobileLobby.open_power_stat_dialog()`）。
3. **存取器與訊號**：
   - 提供 `get_go_power_stat_button() -> Button` 存取器。
   - 提供 `power_stat_requested` 與 `go_power_stat` 訊號。
4. **六語系在地化支援**：
   - 完整支援 `zh_TW`, `zh_CN`, `en`, `ja`, `ko`, `es` 六語系即時切換。
   - 字典鍵值：`vault.btn_go_power_stat`（繁中：前往戰力，簡中：前往战力，en：Go to Stats，ja：戦力詳細へ，ko：전투력으로 이동，es：Ir a Estadísticas）。

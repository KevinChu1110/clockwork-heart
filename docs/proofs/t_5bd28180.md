# 驗收證明 · BattleVictoryDialog 關卡勝利結算新增『前往戰力』快捷果凍按鈕連動 PowerStatDialog (t_5bd28180)

## 1. 任務背景與驗收目標
依據任務規範，於《發條之心》出征關卡勝利結算彈窗（`BattleVictoryDialog`，`battle_victory_dialog.gd`）底部按鈕列新增『前往戰力』（`BtnGoPowerStat`）快捷果凍按鈕，打通關卡通關獲得戰利品機芯後直通大廳戰力屬性總覽（`PowerStatDialog`）的快捷跳轉連動：
1. **按鈕規格與樣式**：
   - 位於底部操作按鈕列（`btn_row`），排列於立即裝備、收下完成、前往整頓之後。
   - 多巴胺天藍色盤 `#38A0FF`，深藍紫描邊 `#1F1A3A`，文字深藍紫 `#1F1A3A`。
   - 熱區尺寸 130x50px（高度 50px，熱區 >= 48px，符合手機端防誤觸人因規範）。
   - 果凍厚底 5px（`border_width_bottom = 5`），圓角 16px（在 14~18px 規範內），字級 16px 開源粉圓體（Open Huninn），零系統 Emoji、零禁止符號。
2. **點擊聯動與彈窗銷毀**：
   - 點擊後發射 `power_stat_requested` 訊號並執行 `setup` 傳入之 `on_power_stat` 回調。
   - 安全銷毀結算彈窗（`queue_free`），無殘留遮罩、無介面卡死。
   - `BattleView` 接收後發射 `power_stat_requested` 與 `battle_finished`（won=true），平滑切換回大廳並調起 `PowerStatDialog` 戰力屬性總覽。
3. **存取器**：
   - 提供 `get_go_power_stat_button() -> Button`。
   - 提供 `get_power_stat_button() -> Button`（相容別名）。
   - 提供 `get_go_power_stat_button_text() -> String`。
4. **六語系在地化支援**：
   - 完整支援 `zh_TW`, `zh_CN`, `en`, `ja`, `ko`, `es` 六語系即時切換。
   - 繁中：前往戰力
   - 簡中：前往战力
   - 英文：Go to Stats（零 CJK 殘留）
   - 日文：戦力詳細へ
   - 韓文：전투력으로 이동
   - 西文：Ir a Estadísticas（零 CJK 殘留）
   - 全語系零系統 Emoji。
5. **合規與自動化測試**：
   - 遵守 review.md 與 AGENTS.md 規範，撰寫單元與整合測試 `test_battle_victory_power_stat.gd`。
   - 執行 `clock-check` 確保零警告，OpenGL3 真實渲染截圖存證完備。

# 日常視覺憲法 · ART Daily Constitution（v1）

> **位階**：遊戲內日常畫面（探索／戰鬥／HUD／商店實機截圖）的**唯一標準**。  
> **制定**：2026-09-11（產品／美術總監建議定稿，Kevin 採納執行）。  
> **衝突處理**：與 `ART_DIRECTION.md` v2「Worn／破舊」衝突時，**日常層以本檔為準**；磨損只留給鏽蝕敵。  
> **品牌 KV／片頭／標題／世界大鐘儀式**可走神殿黑金電影層，見下方分層。

## 0. 一句話

**同一組金屬發條玩具，兩種燈光：儀式可以黑金，玩家每天玩的必須是多巴胺 Q 版。**

商店截圖必須來自日常層，不能只放 KV。

## 1. 分層（不准平均成「半黑半粉」）

| 層 | 用在哪 | 燈光／色 | 角色 |
|---|---|---|---|
| **A 品牌儀式** | KV、預告片、標題、世界大鐘儀式 | 神殿、黑金、電影光 OK | 同一套 2.2 頭身金屬小隊 |
| **B 日常遊玩（產品真相）** | 探索、選單、一般戰鬥、**商店實機圖** | 亮色賽璐璐＋多巴胺五色 | 同剪影／同青綠之心／同黃銅鑰匙；**乾淨烤漆** |
| **C Boss 舞台** | 大頭目戰 | 可比 B 暗半档，仍是賽璐璐，⛔ 寫實暗黑／恐怖谷 | 同上 |

**硬規則**：A 可以比較「貴」；B 才是產品臉。官網可黑曜石底＋奶油卡；**遊戲內 HUD 禁止官網黑曜石皮**。

---

## 2. 角色鐵則（每天看到的）

1. **可玩主角只有小白**：2.2 頭身、米白金屬板件發條兔、立耳、背上黃銅鑰匙、胸口青綠發條之心、單手長劍。  
2. **讀卡四件永遠在**：米白大色塊｜立耳剪影｜背後鑰匙｜青綠之心——縮到小圖也要認得出。  
3. **獅／狐／豬**：主視覺同框配角，**不是可選英雄**；頭身帶與小白同（約 2.2～2.5），只靠武器剪影分職。  
4. **材質**：乾淨烤漆金屬玩具；可見接縫／螺絲 OK。⛔ 絨毛、⛔ 主角生鏽暗黑、⛔ 恐怖谷縫合怪。  
5. **磨損歸敵人**：鏽蝕、裂漆、掉零件只給敵對玩具，當對比。  
6. **全角色統一**：深色描邊（outline）＋腳底軟影；表情至少 4～6 張循環（驚／喜／認真／受傷）。

## 3. 多巴胺色字典（UI／場景點綴共用）

| 色 | 用途 |
|---|---|
| **金黃** | 貨幣、稀有、高光 |
| **暖橘** | 主確認鈕、鍛造成功 |
| **薄荷綠** | 發條體力、治癒、聚魂正面 |
| **天藍** | 資訊、次要、系統說明 |
| **珊瑚粉** | 警告、受擊強調、限時提示（勿當主底） |

- 字體方向：**粉圓體**；控件：**果凍厚底按鈕**；面板：**奶油資訊卡**。  
- ⛔ **禁止系統 Emoji**；用自繪幾何圖示（發條鑰、齒輪、心、封靈罐）。  
- 字級只留 **3 級**：標題／內文／輔助；輔助不准再縮去塞字。

## 4. 場景（日常 B）

1. 默認＝**亮色玩具劇場／閣樓王國**，不是黑神殿滿版。  
2. 石柱當**象牙／淺石玩具積木柱**＋暖金線；神殿黑金只留給 A／最終儀式。  
3. **畫面中央約 40% 留走路淨空**；地標放邊緣。  
4. 每域 **1 主色＋1 點綴**（例：鍛造暖橘＋金；聚魂 mint＋天藍）。  
5. 齒輪是裝飾，**單顆佔比 ≲ 畫面 15%**。

---

## 5. 戰鬥（日常 B／Boss C）

1. 背景**零角色**；下 1/3 淨空給站位腳底。  
2. 受擊主特效＝**糖果色碎屑＋黃銅齒輪片**，非黑血／寫實焊花。  
3. **部位破壞樣板**：部位閃邊 → 裂縫 → 零件飛出 → 獎勵欄圖示。  
4. 發條體力＝**胸口光芒＋外圈刻度**（15 點），⛔ 再做醜藍條。  
5. 預告用彩色地面圈＋簡字（閃／擋／拆），拇指距離可讀。

---

## 6. UI（遊戲內）

1. 整包：**奶油底＋果凍鈕＋粉圓方向**；⛔ 黑曜石神殿 HUD。  
2. 按鈕色嚴格走 §3 字典。  
3. 可點控件高度夠**單手拇指**；橫屏也要能打完一場。  
4. 先換皮優先序：主城／選單／戰鬥 HUD → 再支線面板。  
5. 手機 Safe Area＋可縮放；⛔ 再以 1280×720 當唯一設計基準。

## 8. 先做這 5 件事（優先序）

1. **鎖本憲法**為日常唯一標準（本檔）。  
2. **一組可上架截圖標準場**：探索半屏 → 進戰鬥 → 拆掉一個部位。  
3. **全局 outline＋腳底影＋飽和調色**一次套齊。  
4. **UI 換皮**：奶油卡＋果凍鈕，先主城／選單／戰鬥 HUD。  
5. **一隻樣板頭目**把部位破壞演出做滿。

## 9. 口味 vs 轉換／留存

| 項目 | 類型 |
|---|---|
| 日常亮色、KV 保留神殿夜景（分層） | 品牌／口味；做错才伤转换 |
| 主角乾淨烤漆、鏽只給敵 | 口味（但必須鎖死，否則產圖來回退） |
| 商店截圖＝日常 B | **轉換關鍵** |
| 描邊＋果凍 UI＋三級字 | 執行；混亂伤留存觀感 |
| 部位破壞樣板頭目 | **留存／短影音素材關鍵** |
| 拇指可打完一場 | **留存關鍵** |

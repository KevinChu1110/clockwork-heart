> **轉譯說明**：依 PRODUCT_LOCK_0.20 §2.2 轉譯，2026-09-07。  
> **用途**：對白、舞台指示、flag、戰鬥插入點。

## 開場·黑屏旁白

**【旁白】**  
世界的大鐘停止了走時——那不知是多少年前的事。  
齒輪咬死，指針凝結。無數玩具在沉寂的灰塵裡，緩緩閉上了眼睛。

**【旁白】**  
你不是堅固的發條衛兵，也不是櫥窗裡的展示偶。  
今夜，閣樓角落的黑暗中，你背後的發條鑰匙突然發出清脆的「喀嗒」聲——自行旋轉了十五圈。  
青綠色的玻璃眼第一次映出微光：動起來吧，小傢伙。

→ 淡入 C0-S1

## C0-S1 閣樓·夜

（舞台：巨型閣樓的一角。月光透過斑駁天窗灑下；四周堆滿老舊木箱與靜止的玩具。空氣中浮動著微塵；遠方傳來大鐘停擺引發的低頻震顫餘波。）

### 強制事件：麥穗

**麥穗**：（齒輪摩擦的微響）別愣著——！快往外，往天窗的光亮處跑！

**主角**：（……）

**選項 A**「你呢？」  
**選項 B**「我去扳回齒輪——」  
**選項 C**（沉默，上前扶住她鬆脫的發條柄）

| 選項 | 反應 | flag |
|------|------|------|
| A | 麥穗：我的彈簧還能撐一會兒。別回頭。 | `c0_care = true` |
| B | 麥穗：停擺不是卡榫滑脫，你扳不動的。走！ | `c0_stubborn = true` |
| C | 麥穗：……傻瓜。省下你的發條，先走。 | `c0_care = true` |

**麥穗**：世界的異常不是生鏽那麼簡單。你越是用蠻力去轉它，軸承崩得越快。  
**麥穗**：所以跑。跑去能看見世界大鐘的地方。

（舞台：上方積木堆傾倒，沉重的木梁砸落；通往閣樓深處的通道被封死。）

**【系統】** 唯一的通路是向前逃往玩具堆邊緣。

### 調查：地面的劍 · **M1 拔劍三振**（爆點必做）

（若玩家靠近反光物——半截金屬劍身埋在積木灰塵裡，長度比兔子的金屬身軀還長一截。）

**【系統】** 一柄鏽蝕的玩具長劍。金屬握柄冰冷沉重。

（操作：互動鍵拔劍。允許跳過長演出的設定可「長按跳過」，預設播完。）

| 次 | 演出 | 音效建議 |
|----|------|----------|
| 1 | 小金屬爪用力抓緊劍柄向外拔；長劍紋絲不動；金屬後足打滑，小白往後仰坐倒 | 悶金屬撞擊音 |
| 2 | 咬緊牙關、背部小發條微轉；劍身鬆動一寸；小白整隻被慣性拽得向前傾倒 | 齒輪摩擦尖銳音 |
| 3 | 彈簧全力後蹬拉扯；**長劍脫離木縫的瞬間小白微微離地**再跌回地面；積木揚起一圈微塵 | 沉重金屬鈍響＋短暫靜音 |

（落地後：長劍斜靠在小白的金屬肩甲上，冰冷刃尖拖在木板上劃出一道刮痕。）

**【系統】** 撿起了鏽蝕長劍。小小的機械手掌幾乎握不穩。

**主角內心**：（獨白框）總得有玩具……站起來一下。

（可選：若此時麥穗仍在視野邊緣）  
**麥穗**：（喊）別逞能——你連發條都才剛轉動……算了，帶上它防身！

→ `item.rusty_sword = true`  
→ `flag.c0_sword_triple_pull = true`  
→ 裝備：鏽蝕長劍 T1（攻極低）  
→ 教學提示：這就是你的武器。日後工坊的鐵匠會替你重鍛。  
→ **成就鉤**：全程可截圖；預告片素材 H1 強化版

### 離開閣樓 · 麥穗的麥（N4 伏筆物）

（觸發通往玩具堆外緣前：強制或自動）

**麥穗**：（將一根乾癟卻泛著金黃的編織麥穗塞進小白的胸口夾層）拿著。不是什麼神奇零件。——是舊閣樓的氣味。  
**麥穗**：（遠處招手）記住走出去的路！  
（若 `c0_care`）**麥穗**：……我會等世界重新走時的那天。

→ `item.wheat_stalk = true`  
→ `flag.c0_village_left = true`  
→ 切 C0-S2

## C0-S2 玩具堆邊緣·黎明

（舞台：閣樓天窗透進清冷的黎明微光；背景是堆積如山的沉睡舊玩具；光波在空氣中泛起微弱的波紋，有些玩具齒輪抽搐了一下隨後寂靜，有些則完全停擺。）

### 可選調查

| 物件 | 文本 |
|------|------|
| 停擺鐘擺 | 巨型座鐘的擺錘卡在傾斜角度。銅軸上凝結著不自然的深暗結晶。 |
| 積木路標 | 「外向——世界大鐘｜內向——閣樓箱底」向內的字跡已被厚厚灰塵遮蔽。 |
| 泛黃便簽 | 幼童筆跡寫著：別讓發條「轉得太緊」。 |

### 強制：雜亂的齒輪聲

**【旁白】** 玩具箱的陰影後傳來粗糙的齒輪轉動聲。那不是安寧的走時節奏。

→ 進入 C0-S3 教學戰（不可逃）

## C0-S3 教學戰「失控的銹蝕玩具」

### 戰前

（一隻由殘破鐵皮與生鏽齒輪拼湊的玩具狼從陰影中竄出，眼部玻璃珠泛著過熱的赤紅微光。）

**【系統·提示 1】** 戰鬥會自動進行。點選敵人可鎖定目標。  
**【系統·提示 2】** 受擊會累積彈力動能；動能滿時會使出招式——金屬關節剛甦醒，先施展「橫斬」。

→ 開戰：1v1，失控的銹蝕玩具狼，血量低、攻擊低。

### 戰中（第一次動能滿）

**【系統】** 彈力動能滿！自動使出【橫斬】。  
（若尚未習得，戰中「齒輪記憶」臨時給予 Lv1 橫斬 → 戰後保留）

### 戰中 · **N4 麥穗桿擋致命**（每場限一次）

（當即將受到致死打擊且 `item.wheat_stalk`：）

（時間微緩；胸前金屬夾層裡的乾麥穗微泛起一抹溫暖金光。）

**【系統】** 麥穗給予的麥稈碎裂了。替你化解了致命的金屬衝擊。  
（HP 保留 1 或回復少量；麥稈自背包移除並轉化為「碎麥稈」紀念物件）

**主角內心**：……還在啊。那股溫暖的氣味。

→ `flag.c0_wheat_saved = true`  
→ `item.wheat_stalk = false`（或 `item.wheat_stalk_broken = true`）

### 勝利後

**【旁白】** 玩具狼體內卡死的發條脫扣彈開，過熱的赤紅光芒熄滅。它倒在積木堆旁，只是一隻被遺忘太久、生了鏽的舊鐵皮玩具。

**主角內心**：這就是停擺與過熱嗎。連玩具都會變成這樣……

→ 經驗、金屬碎屑、黃銅墊圈少許  
→ `flag.c0_first_battle = true`  
→ 技能：橫斬 Lv1（若未有）

### 若敗北（未觸發麥稈 or 已碎仍死）

**【系統】** 再次睜開眼時躺在木箱旁。有誰悄悄替你上了一圈應急發條——周圍已無蹤影。  
（殘血、物品保留；失控玩具狼弱化 20% 可再戰）  
→ `flag.c0_helped_by_stranger = true`（星讀伏筆）

## C0-S4 望見遠方的世界大鐘

（舞台：小白爬上閣樓頂部的破裂天窗外沿，眼前豁然開朗——巨大的創想界域沙盤在晨光中展現。浮空島嶼、交錯的發條軌道天橋，以及視野正中央、懸浮在雲海頂端的超巨型黃銅「世界大鐘」。）

**主角內心**：那就是世界大鐘。整個世界齒輪的起點。  
**主角內心**：麥穗說，不要讓自己的發條崩斷。  
**主角內心**：我只是一隻被遺落的發條兔子……但胸膛裡的這顆心，為什麼停不下來？

（若有鏽蝕長劍）拖曳在木梁上的金屬劍尖碰在黃銅鉚釘上，發出清脆的「叮」一聲。

**【系統】** 主線更新：朝著世界大鐘前行，探尋世界停擺的真相。

→ 淡出  
→ `flag.chapter = "C1"`  
→ 抵達世界大鐘可視範圍（進入 C1 新手區域）

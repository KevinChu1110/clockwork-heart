## 0. 手機優先（v2 新增，最高原則）

**手機才是第一級平台，PC 是放大版。** 不是「PC 畫面是標準，手機只是縮小版」。

這條會反過來管住底下所有規則：任何在手機小螢幕上看不清楚的設計，不管在 4K 上多好看，都是錯的。

### 三層辨識系統

角色身上不能什麼細節都塞——齒輪、螺絲、鏽斑、刮痕、布料、武器、發條、核心全部堆上去，遠看會變成一團。
設計時要分層，每一層只負責讓觀者看懂一件事：

| 距離 | 這個距離要看得出來 | 靠什麼 |
|---|---|---|
| **30 公尺**（縮圖、Banner、戰鬥小圖） | 這是兔／獅／狐／野豬 | **輪廓**與頭部剪影 |
| **10 公尺**（角色列表、隊伍畫面） | 誰拿劍／長槍／法杖／巨錘 | **武器剪影**與大色塊 |
| **3 公尺**（立繪、放大檢視） | 發條、螺絲、刮痕、鏽蝕 | **材質細節** |

**優先序**：輪廓 > 顏色區塊 > 武器 > 發條 > 材質細節。
細節只能加在不破壞前一層的前提下。

## 1. 一句話定調

**從廢墟裡甦醒的、破舊的機械發條玩具。**

核心關鍵詞：**Mechanical Toy / Worn / Charming**

三個詞缺一不可：

| 詞 | 意思 | 反例（會被退） |
|---|---|---|
| **機械** | 由齒輪、螺絲、金屬板件構成，動力來自背後的發條 | 絨毛玩偶、真實動物、有機生物 |
| **破舊** | 漆面剝落、鏽斑、刮痕、蒙塵，像在閣樓被遺忘很久 | 全新光滑、鏡面反射、剛出廠 |
| **玩具** | 尺寸感是**可以被一隻手拿起來**的，親切、能當看板娘 | 真人尺寸機甲、軍武、寫實機器人 |

**對標**：瓦力（WALL·E）、閃電麥坤——**磨損感與人格感**是重點。
鋼鐵人的**形象骨架**可以參考（人形、有核心），但**表面風格不對**：太新、太光滑、太科技。

⛔ **太寫實一律退。** 這是 Kevin 退版次數最多的原因。

### ⚠️ 「機械玩具」不是「小型機器人」（v2 新增）

`瓦力 + 鋼鐵人 + 玩具` 這個組合有個危險：做著做著會變成 **Cute Robot**，那不是我們要的。

判準是「這東西是被**做出來給小孩玩**的，還是被**製造出來執行任務**的」：

| 要有（玩具感） | ⛔ 不要（機器人感） |
|---|---|
| 不完全對稱、手工製造感 | 精密工業對稱 |
| 外露的螺絲與接縫 | 隱藏式無縫外殼 |
| 油漆剝落、掉漆露出底材 | 完好烤漆或裸金屬 |
| 簡單的關節（球窩、鉚接） | 大型液壓關節、複雜機械骨架 |
| 玩具比例（大頭、短手短腳） | 寫實人體比例 |
| 有點笨拙、不完美 | 高科技、高效率外觀 |
| 小型金屬零件 | 軍用機甲部件 |
| 上漆金屬的霧面質感 | 鏡面金屬、鉻 |

## 2. 角色

### 2.1 通則（四隻都適用）

- **擬人化**：站立、有手、能持武器，但保留該動物的辨識特徵
- **動物特徵本身要機械化**——這條最常被做錯：
  - 豬鼻、豬牙、狐耳、兔耳、尾巴，**都要是金屬件**，不是肉、不是毛
  - 耳朵是**立耳**，金屬結構不會軟垂
  - 尾巴是分節金屬或彈簧結構
  - 獅子的鬃毛也是金屬片，不是毛
- **每一隻背後都要有發條鑰匙**，而且**看得到**。發條是世界觀與角色身份的視覺符號
- **Q 版比例 2.2～2.8 頭身**，頭部與輪廓優先於表面細節
- **輪廓用清楚的深色描邊 + 柔和腳底陰影**，確保手機小尺寸下的辨識度
- 「還是太生物了」= 沒做到上面這幾條，重產

### 2.2 四位角色

| 角色 | 職業 | 武器與服裝 | 特別注意 |
|---|---|---|---|
| **兔（小白 / Whitey）** | 劍士 | **單手長劍一把** | ⛔ 不要一次拿兩把武器。牠是看板娘，但**不是唯一主角** |
| **獅** | 騎士 | 騎士長槍、皇家守衛裝束 | ⛔ **身高不要太高**——退過兩次。要站立、要持武器 |
| **狐** | 法師 | 法袍、法杖 | 狐耳與尾巴要金屬化；服裝要像**微縮舞台戲服**貼在金屬玩具身上，不是真實布料 |
| **野豬** | 戰士 | 維京裝束、巨錘 | 豬鼻豬牙要金屬件 |

封面／主視覺**可以四隻同框**，不必只放兔子。

> **世界觀補充**：世界由發條、齒輪、**布料**、鐵皮構成，所以布偶類角色（如針織棉線小羊「軟軟」）
> 是合法存在的。但**四位主角一律是金屬機械玩具**，這條沒有例外。

### 2.3 配色

- 主體走**胡桃鉗（Nutcracker）**的配色感——飽和的紅、深藍、暖金那種舞台玩具感
- 質地是**斑駁黃銅、米白金屬、深藍漆面**與螺絲感；輕度磨損、刮痕、氧化與灰塵
- **磨損不可以髒到失去角色辨識度**——是「被珍惜過的舊」，不是「髒」
- 胸口／核心是**青綠**發光玻璃，眼睛青綠玻璃，內耳鏽紅——這是角色的視覺焦點
- 光線用**溫暖舞台燈 + 柔和環境光**
- ⛔ 不要做成鋼鐵人的紅金光滑烤漆

> 配色像胡桃鉗，外型的螺絲感像機械版——這兩件事同時成立，不是二選一。

## 3. 背景與構圖

- **齒輪只作為結構與裝飾元素，不可佔據畫面主體**，而且不要太大
- 中央是「齒輪之心（Gear Heart）」——概念類似反應爐，**立體懸浮**效果比平貼好，尺寸適中
- 場景基調：**被遺忘的玩具世界**——木馬、錫兵、八音盒、陀螺、積木、舊書、玩具零件
- 整體是**古典玩具劇場**，不是工業工廠
- 神殿石柱、希臘風、黃金與金色的搭配
- 主視覺最後面要有一個**神秘人物在操縱發條之心**
- 主視覺要有**遊戲標題**

**場景圖要為玩法服務**：前景與中景要有明確可行走區域，中央留乾淨的玩法空間，
地標放在邊緣，⛔ 不要有巨大物件擋住可玩區域。

⛔ **不放瓷娃娃、空白眼人偶，或任何恐怖片元素**（2026-09-05 退稿）。
⛔ 不要恐怖、陰暗、寫實機器人、軍武機甲、科幻工業風、絨毛玩偶。

## 4. 遊戲內畫面（不只是行銷圖）

Kevin 09-03 明講過而且一直沒被處理：

> 整個遊戲風格一直想叫你重構、重新設計，符合現代手機遊戲，但你都還是用原本的色調跟原本的設計。

具體的：

- **拿掉像素量化**。這不是調色能補的，要換皮
- 角色加**粗描邊**（outline shader）＋腳底軟影，貼近插畫感
- 全螢幕調色走**飽和 +、對比 +**
- UI：⛔ **字太小、字體不漂亮、像傳統 PPT** 是明確退稿理由。改亮底深描邊、字加描邊
- 據點鏡頭跟人走，角色佔比要接近主視覺的比例感
- **UI 不可以再拿 1280×720 當設計基準**，要用 Safe Area + Anchors + 可縮放 UI，
  至少測 16:9、19.5:9、20:9、平板、PC

## 6. 產圖提示詞（v2 新增，可直接使用）

**這幾組刻意寫得很硬，不依賴參考圖**——實測 `--ref` 壓不過提示詞的文字描述，
所以材質、比例、武器、negative 都必須寫進文字裡。

用法：

```bash
python3 /root/gen_media.py image "<下面的 prompt>" 輸出.png --aspect 16:9
```

`--ref /opt/side/bravesoul-game/branding/key_visual_main.png` 可以加，但**不能取代文字描述**。

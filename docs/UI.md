### 0.1 文本

| 聲音 | 句長 | 禁用 | 好 | 壞 |
|------|------|------|----|----|
| 旁白 | ≤20 字／句，段最多 2 句 | 踏上命運、傳說的開始、你終將 | 勇者滅魔王——二十年前的事。 | 命運今夜伸手。 |

| 系統 | ≤14 字 | 恭喜、溫馨提示、強大的 | 撿起鏽劍。幾乎握不穩。 | 恭喜踏上英雄的第一步！ |
| 選單 | 鈕 2–6 字 | 新的冒險、轉蛋牆、星途之旅 | 今日村莊／抽魂 | 開啟星途之旅 |

別名：今日村莊、演武場、抽魂／聚魂殿、四地區、能量、器階。器階 ≠ 強化+N。

口吻：麥穗祈使帶刺；灰鬚斷句、認腳步；釘釘先鐵後人，魂推聚魂殿。

### 0.2 介面

層級：世界 → 對話 → 店面板 → Esc。說話／開面板／暫停時藏 HUD。Esc 打開時關對話。

色：只准 `ui_style.gd`（`WOOD_DARK`、`KEY`、`CAPTION`）。字：狀態 11–13、對話 15–18、鈕 14。

- 標題：開始遊戲／設置／成就／結束遊戲。
- Esc：繼續、背包、設置、存檔、回標題。零養成入口。
- 對話：不透明；有人就立繪＋名；選項 ≤3。
- 狀態板：名、Lv、HP、金；目標一句。

## 1. 原則

- **人話優先**：任務追蹤寫「去找鐵匠」，不寫內部 id。  
- **三軸分離**：鍛造／聚魂／技能分屬不同空間或分頁，避免「全是升級按鈕」。  
- **戰鬥可讀**：血條、鎖敵、技能名 > 華麗遮擋。  
- **可跳過**：已讀對話、長演出可 skip（BOSS 初見第一次不可 skip 可選）。

## 2. 畫面層級

```
[世界場景：走、對話、調查]
    ↔ [節點地圖]
    ↔ [戰鬥場景]
    ↔ [全屏 UI：選單／工坊／聚魂／圖鑑]
```

### 常駐 HUD（世界）
- 左上：角色小頭、HP、等級  
- 左：任務一條「下一句人話」  
- 右下：選單  

### 常駐 HUD（戰鬥）
- 底：大血條、怒氣、快捷道具  
- 敵：頭上血、鎖敵框  
- 右：技能圖示（CD／怒氣條件）  
- 上：波次 1/2

## 3. 選單結構

Esc 管進程，養成管場景。

```
Esc
├── 繼續
├── 背包
├── 設置（顯示／語言／連線／備份）
├── 存檔
└── 回標題

標題
├── 開始遊戲（繼續／新的旅途／今日村莊／旅途紀錄）
├── 設置
├── 成就
└── 結束遊戲
```

抽魂→聚魂殿；鍛造→鐵匠鋪；演武→廣場演武場。**不**把這些再塞進 Esc。

**不**把聚魂深埋在裝備裡第三層；裝備頁魂槽點進去是「嵌／拆」，**抽**在聚魂殿場景。

## 4. 關鍵流程 UI

### 4.1 鍛造（釘釘）
1. 選裝備  
2. 看下一階屬性差、成功率、耗材  
3. 確認 → 錘擊演出 → 成功／失敗（失敗也演出，不降階）  

### 4.2 聚魂（星讀／殿）
1. 看葫蘆目前階色  
2. 聚魂 x1（x10 6m）  
3. 點亮演出 → 結果卡  
4. 可「前往嵌魂」捷徑  

### 4.3 入魂
1. 選有空槽裝備  
2. 選背包戰魂  
3. 對比數值 → 確認  

### 4.4 技能
- 列表：名、Lv、熟練條、簡述  
- 詳：下級預覽「Lv3：橫斬附帶波及」  

### 4.5 對話
- 半身立繪 + 名 + 文本  
- 選項最多 3  
- 日誌自動摘

## 5. 用詞表（統一）

| 用 | 不用 |
|----|------|
| 器階 | 強化+N、裝備等級（易混角色等級） |
| 戰魂／入魂 | 寶石、卡片（可內部叫 soul） |
| 抽魂／聚魂／點亮／星屑（暫） | 轉蛋牆、付費保底、逼肝才能過主線（原作詞「抽魂／聚魂」可用） |
| 足跡 | 抽卡機率提升（勿對玩家這樣解釋） |
| 技能等級／熟練 | 技能強化（和器階混） |
| 星途旅人 | 其他玩家、用戶 |

# W4-B1 · §8 煙測對白潤色（UI／UX）

> Owner：Bingo｜交 @Kevin → @Frank 換 `s8.*`  
> 目標：首局 **60 秒內摸到拆零件**；提示短、可發現、不說「藍條」  
> 對齊：Ken HUD（胸口光＋外圈）、Alice 糖果屑、`DropId` 圖鑑短卡

---

## 潤色原則

1. 小白口吻：短句、好奇、不長篇說教  
2. 系統提示：只在「第一次」出現，可略過／不擋操作  
3. 引導拆零件：B03／B05／D01 要讓玩家知道「下一步點哪」  
4. 用語：發條／胸口那圈／接縫／零件｜⛔ mana／能量條／翠嶺

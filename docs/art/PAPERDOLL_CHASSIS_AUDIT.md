## 1. 稽核規範與量化指標定義（依 0-ART19 與 0-QA8）

為杜絕前版報告「僅憑 Vision 對 128×128 小圖概括描述導致誤判」之嚴重缺陷，本次複驗嚴格執行以下雙軌標準：

### 1.1 三大量化指標（PIL + numpy 演算法可複算）
1. **`flat%`（平塗四鄰居同色率）**：
   - 定義：不透明像素（Alpha > 0）中，上下左右四鄰居顏色皆完全相同的像素占比。
   - 門檻：手繪厚塗正常值為 **0% ~ 3%**（至多 <10%）；**>25% 判定為平塗占位圖**。
2. **`topcol%`（最高頻單色占比）**：
   - 定義：不透明像素中，出現次數最多之單一顏色（RGB）所占的比例。
   - 門檻：手繪厚塗正常值為 **<20%**；若 >28% 需深入檢查是否為大面積平塗或單純為全身閉合描邊色（如標準深藍紫描邊 `#1F1A3A`）。
3. **`maxrect`（最高頻色最大實心矩形面積）**：
   - 定義：以最高頻顏色構建之二值矩陣中，最大軸對齊實心矩形（Solid Axis-aligned Rectangle）的像素面積。
   - 門檻：正常手繪像素結構為 **<100**；**>300 判定為大面積未完稿幾何平塗方塊**。

### 1.2 Chassis 圖層架構判準（0-QA8）
- 依據 `paperdoll_renderer.gd` 定義之七槽位渲染架構：
  - `chassis` (Z10)：**僅負責軀幹機身與四肢外殼塗裝**。
  - `head_unit` (Z20)：負責頭部外殼與耳部天線零件。
  - `optic_core` (Z30)：負責面甲與光學核心。
  - `costume` (Z40)：負責胸甲與外裝。
- **重要判準**：Chassis 單圖頂端無頭部、呈平切或留空為**規格內之正常分層設計**，⛔ **嚴禁將「無頭／頭部平切／頭部缺失」判定為破圖**。若要排查該族頭部有無缺件，應檢視 `head_unit/` 與 `optic_core/`，而非 Chassis。

## 4. 11 檔重點重驗個案詳細分析與覆核證據

### 4.1 野豬族（Boar 3 檔：`brass_gold`, `ivory_stock`, `molten_crimson`）—— 撤銷破圖誤判
- **前版報告誤判理由**：宣稱「頭面、胸部、腹部被純白與深灰色無光影幾何方塊嚴重遮擋，軀幹斷裂」。
- **量化數據證偽**：
  - `paint_brass_gold.png`：`flat%` 9.0%，`maxrect` 80。
  - `paint_ivory_stock.png`：`flat%` 4.8%，`maxrect` 105。
  - `paint_molten_crimson.png`：`flat%` 0.2%，`maxrect` 6。
  - 全三檔之 `flat%` 與 `maxrect` 遠在合格安全區內，完全不存在占位圖的大塊平塗特徵（>25% / >300）。
- **8x 放大與圖層架構覆核**：
  - 前版檢驗時將帶 Alpha 通道之 PNG 直接丟入 Vision，透明區域在預設白底渲染下顯現為白色背景。野豬 chassis 配合胸腹重裝與外裝槽位，於接口處本即留空，被前版誤判為「大面積直角白色方塊」。
  - 檢視紙娃娃完整合成圖 `proof_paperdoll_boar_composite.png` 及對照圖 `proof_boar_chassis_comparison.png`，各槽位（Z10 底盤、Z20 耳部防護罩、Z30 獠牙面罩、Z40 戰士重甲）組裝後結構無縫密合，立體厚塗質感完整，完全無白塊破圖。
- **結論**：**撤銷嚴重破圖判定，全 3 檔改判 ✅ 合格**。

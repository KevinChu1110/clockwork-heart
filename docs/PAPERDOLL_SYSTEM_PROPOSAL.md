## 1. 提案背景與總體設計目標

### 1.1 背景與問題痛點
當前《發條之心》雖然具備完整的 2D 紙娃娃貼圖覆蓋架構（`game/scripts/art/sprite_db.gd` 已支援 weapon/armor/accessory 三層疊合），但現狀存在三大結構性限制：
1. **角色固定無客製化**：遊戲以固定白兔形象出發，玩家缺乏「親手創造屬於自己的玩具」的情感投射與代入感。
2. **商業化外觀變現空白**：現有營利點主要依賴聚魂殿（抽魂）與裝備鍛造材料，欠缺現代長青手遊最賺錢、口碑最健康、且「完全不破壞平衡（Zero Pay-to-Win）」的外觀造型收費體系。
3. **單機封閉感**：遊戲現有玩法偏向單機單刷，玩家即使更換了武器或時裝，也缺乏展示舞台與社交互動反饋，導致長線留存與每日上線動機不足。

### 1.2 設計總目標
1. **創角自由度（Avatar Identity）**：借鑒《新楓之谷（MapleStory）》經典紙娃娃哲學，首發提供 5 種截然不同性格與外型的機械動物玩具素體，搭配豐富的外殼、耳型、發條與服飾組合，讓每位玩家的玩具皆獨一無二。
2. **零數值壓迫的長青變現（Ethical Monetization）**：建立外觀盲盒、直購商城與部位破壞免費合成三軌並行的時裝變現體系，嚴守 `docs/BUSINESS.md` 的「不做 pay-to-win」護欄。
3. **輕量高反饋的社交網絡（Lightweight Social Loop）**：以浮空島大廳動態展示、點擊互讚與非即時好友助戰為突破口，用極低的伺服器成本創造極高的社交炫耀與陪伴價值。

## 2. 初始 5 種動物玩具定位與現有四英雄的關係處理

### 2.1 現有四英雄（兔/獅/狐/野豬）的重構定位
現有四位英雄（小白/兔、皇家騎士/獅、秘術師/狐、維京戰士/野豬）擁有優秀的辨識度與世界觀底蘊，本提案主張：**「不替換、不廢棄，而是全面升格為前 4 種動物的初始經典素體原型（Class Archetypes & Default Chassis）」**。

具體轉化邏輯：
- **概念升格**：原本固定的「四英雄」轉化為「世界中甦醒的四大發條玩具族系」。
- **看板主角「小白（Whitey）」的敘事銜接**：
  - 小白在主線故事中依然是「傳奇先行者（The First Awakened）」——在序章 C0 中，正是小白啟動了停擺工坊中的主發條，引導玩家所創建的發條玩具甦醒。
  - 玩家若在創角時選擇「發條兔」，即可自由選用小白的經典米白漆面與長耳組件，亦可自由染成胡桃鉗紅、午夜藍或更換天線耳。這既完美保住了已有的行銷主視覺（Key Visual）與 C0 劇本文案，又徹底解放了全體玩家的角色自訂義權限。

## 3. 紙娃娃部件槽位設計與機械美學憲章

### 3.1 7 大模組化外觀槽位（Slot Architecture）
為兼顧手機小螢幕視覺辨識度與足夠的混搭商業變現深度，規劃 **7 大獨立外觀槽位**：

```
                    ┌─────────────────────────┐
                    │ Slot 3: 發條鑰匙 (Key)  │ (背部核心動態符號)
                    └────────────┬────────────┘
                                 ▼
┌──────────────────────────┐   ┌───┐   ┌──────────────────────────┐
│ Slot 2: 頭部/耳朵機關     │──▶│角 │◀──│ Slot 5: 面部光學/表情    │
│ (Head / Ear Unit)        │   │   │   │ (Optic Core / Faceplate) │
└──────────────────────────┘   │色 │   └──────────────────────────┘
┌──────────────────────────┐   │   │   ┌──────────────────────────┐
│ Slot 1: 外殼材質與塗裝    │──▶│紙 │◀──│ Slot 4: 玩具外裝/服飾    │
│ (Chassis & Paint Shell)  │   │   │   │ (Costume / Toy Armor)    │
└──────────────────────────┘   │娃 │   └──────────────────────────┘
┌──────────────────────────┐   │   │   ┌──────────────────────────┐
│ Slot 6: 武器外裝         │──▶│娃 │◀──│ Slot 7: 隨身奇玩/背飾    │
│ (Handheld Weapon Skin)   │   └───┘   │ (Back Curio & Floating)  │
└──────────────────────────┘           └──────────────────────────┘
```

1. **Slot 1: 軀體外殼與塗裝（Chassis & Paint Shell）**
   - **定義**：底層金屬本體之塗裝與材質。
   - **款式範例**：原廠斑駁象牙白、胡桃鉗皇家朱紅、午夜深藍烤漆、黃銅原金、復古鏽蝕黑鐵、翡翠螢光釉面。
   - **機械細節**：邊角帶有輕度掉漆露出底材黃銅、外露螺絲釘與沖壓拼接縫。
2. **Slot 2: 頭部機關與耳朵造型（Head Unit & Ear Mechanism）**
   - **定義**：動物最具辨識度的頭部特徵部件。
   - **款式範例**：
     - *兔*：摺疊鋼板長耳、螺旋彈簧感應天線、飛行員護目鏡頭盔耳。
     - *狐*：雷達折疊天線耳、古雅青銅雕花尖耳、連擊受話器。
     - *熊貓*：黑鐵球窩耳罩、竹葉鍛鐵髮簪、螺紋散熱圓耳。
3. **Slot 3: 背部發條鑰匙（Wind-up Key）——【全遊戲靈魂焦點】**
   - **定義**：角色背部最核心的機械身分標誌，待機與行動時持續旋轉。
   - **款式範例**：
     - *經典級*：雙環古銅鑰匙、八音盒T型蝶形鑰匙。
     - *華麗級*：星芒齒輪鑰匙、皇家十字冠冕發條、展翼天使雙發條、微縮指針懷錶鑰匙。
     - *動態特效*：發條轉動時帶有微弱蒸汽噴霧、金黃火花粒子或微型齒輪音效。
4. **Slot 4: 玩具外裝與服飾（Costume & Toy Armor）**
   - **定義**：套在金屬素體外的舞台戲服或外掛裝甲。
   - **款式範例**：胡桃鉗近衛軍裝、蒸氣工匠吊帶皮褲、見習占星法袍、維京粗獷護胸鐵扣帶、甜點工坊圍裙。
   - **憲章規範**：布料呈現微縮玩偶舞台服裝質感，帶有明顯粗縫線與黃銅暗扣，不可做成寫實現代長袍。
5. **Slot 5: 面部光學與表情核心（Optic Core & Faceplate）**
   - **定義**：面部眼珠寶石、刻度面板與嘴部沖壓件。
   - **款式範例**：
     - *眼珠*：透亮青綠發光玻璃、琥珀金寶石、電壓紅光寶石、藍寶石微裂紋。
     - *表情*：自信微笑沖壓槽、嚴肅金屬擋板、護目鏡面罩。
6. **Slot 6: 武器外觀（Weapon Skin）**
   - **定義**：12 大武器手持外裝，覆蓋劍、槍、杖、斧、鎚、匕、弓、銃、拳等。
   - **款式範例**：破舊發條劍、晨曦皇家長刺槍、齒輪過載巨錘、星辰晶核法杖。
7. **Slot 7: 隨身奇玩與懸浮背飾（Back Curio & Floating Toy）**
   - **定義**：懸浮於身側或背負的微縮機械玩具玩物。
   - **款式範例**：自走發條小信鴿、迷你蒸氣排氣管背包、懸浮八音盒鐘、微型星盤儀。

### 3.2 嚴格對照《世界憲章》與《美術風格定義 v2》的美術鐵則

為確保紙娃娃不管如何排列組合都不會「跑偏破格」，必須強制套用以下 5 大守則：
1. **零毛皮、全金屬憲章**：
   - 嚴禁真動物毛皮、絨毛、棉絮露出。所有動物皮毛特徵必須以金屬板件、雕花鎢鋼、金屬薄片呈現。
2. **拒絕鏡面高科技機器人（瓦力/胡桃鉗原則）**：
   - 拒絕鋼鐵人式的無縫流線平滑烤漆。所有時裝部件必須保留「玩具感」：可見的球窩關節、外露螺栓、鉚釘接縫、手工不對稱感與「被珍惜過的輕微磨損刮痕」。
3. **手機小螢幕三層辨識度原則**：
   - **30 公尺（縮圖/戰鬥）**：動物頭部輪廓與立耳剪影絕對清晰，不被帽子過度遮蔽。
   - **10 公尺（大廳/隊伍）**：主外殼大色塊與武器剪影分明。
   - **3 公尺（立繪/特寫）**：金屬拉絲紋理、螺絲十字槽、青綠玻璃光芒與掉漆細節。
4. **色彩體系**：
   - 以胡桃鉗舞台色彩為底色：溫暖金黃、胡桃鉗紅、午夜深藍、象牙白金。嚴禁髒黑泥土暗沉濾鏡。
5. **2.2～2.8 頭身比例鎖定**：
   - 所有部件依照 2.5 頭身 Chibi 骨架對位切片，保證橫向跨種族裝備時無縫對齊、絕不穿模拉伸。

## 4. 部件取得與商業變現路徑（符合 BUSINESS.md 護欄）

### 4.1 三軌並行取得架構

```
┌─────────────────────────────────────────────────────────────┐
│                   紙娃娃部件取得與變現途徑                    │
├───────────────┬─────────────────────────────┬───────────────┤
│ ① 奇想工坊盲盒 │ ② 外觀精品店直購            │ ③ 遊戲內鍛造/掉落│
│  (Cosmetic    │  (Direct Boutique)          │  (F2P In-game)│
│   Gacha)      │                             │               │
├───────────────┼─────────────────────────────┼───────────────┤
│ • 主題季外觀箱 │ • 明碼標價熱門外觀/散件      │ • Boss 部位破壞掉落 │
│ • 10 抽保底紫 │ • 外殼改色噴漆罐            │ • 鐵匠鋪鍛造專屬時裝│
│ • 30 抽保底金 │ • 「一次性去廣告」聯名禮包   │ • 主線/成就探索贈送 │
│ • 重複轉齒輪幣 │ • 零數值壓力，純為顏值買單  │ • 免費玩家全套畢業  │
└───────────────┴─────────────────────────────┴───────────────┘
```

#### 軌道 1：奇想工坊·外觀盲盒（Toybox Cosmetic Gacha）
- **定位**：限時主題季外觀扭蛋（如：S1 晨曦胡桃鉗皇家慶典、S2 蒸汽都市工匠系列）。
- **抽取資源**：消耗「奇想鑰匙（Cosmetic Key）」，可透過付費鑽石購買，或透過遊戲內活動/通行證累積。
- **透明保底機制（Pity System）**：
  - 每 10 抽必得卓越（紫）以上時裝部位。
  - 每 30 抽必得當期傳奇（金）主題發條鑰匙或主外觀。
- **重抽轉化「齒輪代幣（Cog Tokens）」**：
  - 玩家抽中重複部位時，自動無損轉化為「齒輪代幣」。
  - 齒輪代幣可在兌換商店以固定價格 1:1 兌換當期所有金/紫部件，徹底杜絕無上限抽卡詐欺。

#### 軌道 2：外觀精品店直購（Direct Boutique）
- **定位**：明碼標價、所見即所得，服務討厭抽卡的不確定性玩家。
- **販售品項**：
  - **外殼噴漆罐**（單件 30~60 元台幣等值點數）：快速為喜愛的玩具換上胡桃鉗黑金、馬卡龍粉、薄荷綠等新色彩。
  - **常駐時裝散件**：耳飾、面罩、背飾眼鏡、吊帶工作褲。
  - **首發禮包**：創角限時超值「發條新秀啟程箱」（含專屬發條鑰匙＋全套外裝）。

#### 軌道 3：遊戲內免費鍛造與部位破壞（F2P In-game Progression）
- **與既有「鍛造殿堂（鐵匠釘釘）」深度聯動**：
  - 擊破 BOSS 泰坦的部位（如：石拳巨豕的獠牙護甲、疾影神隼的精鋼羽翼），掉落「特種金屬外殼碎片」。
  - 玩家將碎片攜回鍛造殿堂，無需付費，消耗金幣與零件即可打造「泰坦征服者」全套高階外觀！
  - 免費玩家只要技術好、破壞部位精準，同樣能在浮空島大廳穿上最霸氣的 BOSS 主題時裝。

#### 軌道 4：獎勵型廣告（Rewarded Ads）自然融入
- 每日提供 1 次觀看廣告機會，可隨機獲得「時裝試用染色券（24小時）」或「奇想鑰匙碎片（10 片合成 1 抽）」。
- 購買「一次性去廣告（Remove Ads）」的尊榮玩家，每日上線一鍵直接領取，體驗拉滿。

### 4.2 嚴守變現護欄（Guardrails Compliance）
本方案嚴格貫徹 `docs/BUSINESS.md` 四大護欄：
1. **絕對零數值（Zero Pay-to-Win）**：
   - 所有紙娃娃部件**100% 不增加任何攻擊力、生命值、防禦力、暴擊率等戰鬥數值**！
   - 僅提供帳號級的「微量舒適性/榮譽性加成」（例如：收集整套時裝解鎖稱號、大廳步行移動速度 +3%、通關結算金幣 +2%）。
2. **免費玩家主線順暢通關**：
   - 戰力只與「裝備器階」與「聚魂殿戰魂」掛鉤，時裝純屬個性化裝扮，非付費玩家在數值推關上毫無劣勢。
3. **無插屏突發廣告**：
   - 時裝獲取與試穿介面完全由玩家自主點擊，絕不彈出干擾式全螢幕廣告。

## 5. 社交系統設計：打破單機，建立長線炫耀舞台

### 5.1 為什麼紙娃娃系統必須綁定社交？
「穿上了最華麗的星芒發條鑰匙與金色鬃毛，如果全世界只有自己看到，購買慾望就會腰斬。」  
外觀系統的本質是**自我表達與社交認同**。建立低門檻、高反饋的社交體系，是讓玩家每天主動登入、彼此炫耀、帶動外觀銷量的核心發動機。

### 5.2 社交系統優先序排定（P0 / P1 / P2 階梯規劃）

```
【P0：首發必做（低成本·強外觀反饋·無伺服器負載）】
  ├─ 1. 浮空島大廳「非即時虛擬同屏展示（Hub Phantom Walkers）」
  ├─ 2. 大廳點擊戳碰與互讚（Poke & Wind-up Praise）
  └─ 3. 好友助戰援護系統（Support Pawn Loop）

【P1：第一波更新（社群凝聚·團隊目標）】
  ├─ 4. 發條玩具公會（Toy Guilds & Grand Clock Project）
  └─ 5. 無盡迴廊與外觀人氣雙榜（Leaderboards）

【P2：長期長線營運（深度自訂與盛典）】
  └─ 6. 浮空展台私宅互訪（Diorama Home Showcase）與外觀穿搭大賽
```

### 5.3 P0 核心社交方案詳解（推薦立即實作）

#### 功能 1：浮空島大廳「虛擬投影遊客（Hub Phantom Walkers）」
- **運作機制**：
  - 玩家連線登入時，本地將自身的紙娃娃造型與名字上傳至後端（極小 JSON，僅 2KB）。
  - 當玩家進入「雲端天宮·浮空島大廳」時，系統隨機載入 5～8 位最近活躍真實玩家的紙娃娃數據，在大廳花海與噴泉旁漫步、發呆、做待機動作（如轉動發條、揮舞武器）。
- **巨大優勢**：
  - **零即時連線同步壓力**：本質是讀取靜態外觀配置的本機 NPC，完全不依賴昂貴且複雜的即時長連線伺服器（Socket / Photon），無卡頓、無掉線問題。
  - **滿滿人氣感**：大廳不再冷清，玩家隨時看到滿街不同動物、不同發條與塗裝的同好。

#### 功能 2：大廳點擊戳碰與互讚（Poke & Wind-up Praise）
- **互動反饋**：
  - 點擊大廳中的其他玩家玩具，鏡頭特寫拉近，彈出其自訂名片、動物種類與全身部件清單（附帶「我也想買」一鍵試穿跳轉按鈕，直接帶動時裝銷售！）。
  - 提供**「為發條充能（上弦點讚）」**按鈕：點擊後播放專屬金色發條上弦音效與彩糖星芒特效。
  - **獎勵互惠**：
    - 每日給予他人充能點讚前 3 次，可獲得少許金幣與齒輪零件。
    - 被充能的玩家累計「人氣熱度」，解鎖專屬大廳待機光環與「最受歡迎玩具」徽章。

#### 功能 3：好友與助戰援護（Support Pawn）
- **戰鬥連動**：
  - 玩家可在出征戰鬥前，挑選 1 位好友的發條玩具作為「助戰援護」。
  - 戰鬥中能量蓄滿時，點擊援護頭像，好友的玩具颯爽空降進場，施展一次華麗的「發條過載合體技」並造成巨額削韌，隨後帥氣退場。
  - **自豪感與拉新**：擁有頂級時裝與強力流派的玩家成為熱門「助戰大老」，被借用次數每日結算為友情點數，進一步推動大老在外觀與練度上的付費自豪感。

## 6. 六域劇情與世界觀（docs/world/CANON.md）深度相容性

### 6.1 創想宏構沙盤體系（Diorama Cosmology）之天生契合
`docs/world/CANON.md` 第三章確立的「奇想宏構沙盤體系」為多動物種族的合法性提供了完美的宇宙學根基：
- 本作世界並非單一自然大陸，而是遠古工匠巨匠的「宏構創想工坊（The Grand Wonderbox）」。
- 各大界域本質上就是造物主工匠打造的**「不同主題玩具套件（Playset Themes）」**。在工坊停擺前，各展台本身就運行著不同材質、不同外型特徵的發條動物！

### 6.2 初始 5 大動物種族在六大界域的生態定位

```
【頂層：星穹軌道】───────────────────────────（預留未來太空犬/機械鳥）
          ▲
【中層：浮空天宮】─────── 全域玩具甦醒集結地（各大種族在此交流重組）
          │
          ├─► 今日村莊 (R01)：白兔族（時間守護、零件調校）
          │
          ├─► 晨曦小鎮 (R02)：玄軸熊貓族（武術演武、鐘樓守備）
          │
          ├─► 翡翠蔓谷 (R03)：靈尾狐族（星軸秘術、自然共生）
          │
          ├─► 黃銅都市 (R04)：烈鬃獅族（皇家衛隊、發條樞紐守護）
          │
          └─► 赤焰熔爐 (R06)：鋼牙豕族（重裝工兵、高溫鍛造）
```

1. **白兔族（The Clockwork Rabbits / 靈源地：今日村莊）**：
   - 誕生於中央大鐘底座的精細鐘錶展台。體內擁有微型雙子擒縱機構，天生對時間走時與齒輪咬合極度敏感，扮演著吹響甦醒號角的時間指引者。
2. **烈鬃獅族（The Gilded Lions / 靈源地：黃銅都市）**：
   - 誕生於重工業蒸氣大都市的核心樞紐。原本是負責守衛城市主動力發條箱的儀隊衛士，以堅定不拔的黃銅外殼與厚重裝甲聞名。
3. **靈尾狐族（The Astral Foxes / 靈源地：翡翠蔓谷）**：
   - 誕生於星象觀測台與發條藤蔓深林。尾部的多節連桿是天然的星光諧波接收器，專門探索十四主星軸的共鳴秘術。
4. **鋼牙豕族（The Forge Boars / 靈源地：赤焰熔爐）**：
   - 誕生於熔火鍛爐與耐熱工坊。外殼經過千萬次高溫錘打，獠牙是拆解卡死軸承的專用槓桿，性格豪邁不屈。
5. **玄軸熊貓族（The Iron Pandas / 靈源地：晨曦小鎮·武術道場）**：
   - 誕生於晨曦市鎮的古雅木偶機關坊。其關節採用特殊的雙重抗震阻尼機構，外柔內剛，將機械慣性化為精妙的拳術化勁。

### 6.3 劇情導入事件：星火破曉（The Sparkfall）
- **玩家角色甦醒序幕**：
  在中央大鐘崩落停擺的「大停擺之夜」，十四枚原初星軸爆散出的微光如流星雨灑落在世界各地的廢棄玩具箱中。
- 玩家所扮演的玩具，在不同的角落被微光激活核心發條盒。在引路前輩「小白」與引路白鴿的指引下，搭乘第一班啟動的齒輪升降天梯抵達浮空島大廳，登錄為「重啟世界大鐘的發條冒險者」。
- **邏輯自洽**：無論玩家選擇哪種動物、何種外殼，皆完全符合「大停擺後甦醒的奇蹟玩具」世界觀底層，敘事上絕不割裂。

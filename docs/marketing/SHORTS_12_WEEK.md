## 一、30 秒通用模板

### 1. 時間軸（秒）

| 秒 | 區塊 | 畫面 | 聲音／字幕 |
|----|------|------|------------|
| **0–3** | **鉤子 HOOK** | 最強一幀（Boss 招／小白背影／部位炸裂） | 大字幕 1 句，禁止自我介紹 |
| **3–10** | **情境** | 世界／角色／問題 | 「當世界大鐘停擺」或「給心上弦」類 |
| **10–22** | **賣點 DEMO** | 系統 or 實機 1 招 | 2～3 個短句，一句一事 |
| **22–27** | **情緒收** | 勝利／鍛成／星屑 | 一句金句或進度 |
| **27–30** | **CTA** | 官網／下載畫面 or logo | 「連結在簡介 · 發條之心」 |

### 2. 字幕腳本骨架（可複製填空）

```
【0–3】{一句鉤子，≤12 字}
【3–10】{世界／角色一句}
【10–18】{賣點 1}
【18–24】{賣點 2 或實機一句}
【24–27】{情緒／本週進度}
【27–30】官網連結在簡介 · 發條之心
```

### 3. 口播（可選）

- 有旁白：語速中慢，**只唸鉤子 + 賣點 + CTA**，其餘給字幕  
- 無口播：BGM 輕快蒸氣機械管弦／溫暖童話；**字幕必上**（靜音滑也看得懂）

### 4. 畫面來源優先序

1. 實機錄（大廳戳碰／戰鬥部位破壞／四大殿堂 UI）  
2. 既有宣傳素材（`web/media/promo/trailer_*.mp4`、`scene_*.jpg`）  
3. 主視覺／Keyart（`branding/key_visual_main.png`、`web/media/gemini/keyart_*.png`）  
4. 紙娃娃 5 層混搭／裝備預覽幀  

### 5. 技術規格（匯出）

| 項目 | 建議 |
|------|------|
| 比例 | **9:16**（1080×1920） |
| 格式 | H.264 mp4 · 高於 8Mbps 即可 |
| 安全區 | 上下各留 ~15% 給 UI（標題／按讚） |
| 字幕 | 畫面中下 1/3，深色厚描邊，一句不超過 2 行 |
| 封面 | 第 0 秒或最炸一幀 + 大字鉤子 |

### 6. 簡介固定文案（貼上即可）

```
🐇 發條之心 Clockwork Heart
發條玩具冒險手遊 · 四大職業 · 器／魂／招

▶️ 官網：https://KevinChu1110.github.io/clockwork-heart/
⬇️ 下載：https://KevinChu1110.github.io/clockwork-heart/pages/download.html

#發條之心 #ClockworkHeart #手遊推薦 #發條玩具 #動作手遊 #Shorts
```

### 7. 週產線（約 45～70 分鐘）— **定案：實機錄製為主，Grok 15s 為輔**

> 實機錄製優先（`/root/gameplay_capture.sh`）；輔助概念鏡頭改用 Grok Imagine 網頁 15s。  
> Veo 8s×N 硬接當備援。

#### 7.1 標準流程（連貫優先）

| 步 | 時間 | 做什麼 |
|----|------|--------|
| 1 | 5 min | 選本週題（下表）· 開對應實機截圖／場景 |
| 2 | 15～25 min | 實機錄影（`/root/gameplay_capture.sh`）或 Grok.com 影片 15s（9:16，以 `branding/key_visual_main.png` 為 ref） |
| 3 | 10～15 min | 可選第 2 段 15s 或片尾 3～5s 定格 CTA |
| 4 | 15 min | 剪映：接片／溶解 · **上字幕** · BGM · 匯出 1080×1920 |
| 5 | 5 min | 存入 `web/media/shorts/wXX_*.mp4` · YT Shorts + FB · 貼固定簡介 |

#### 7.2 Grok 網頁設定（對照截圖）

- 模式：**影片**（非圖片）  
- 時長：**15s**（要整段感就選這個；6／10 當草稿）  
- 畫質：先 720p 試構圖，定稿可 1080p  
- 參考圖：`branding/key_visual_main.png` 或實機截圖  
- 提示詞：**一句場景 + continuous single shot + 2.2 head ratio chibi clockwork toy style + no text**

#### 7.3 檔名規範

```
web/media/shorts/w01_c0_clockwork_heart_30s.mp4   # 成片
web/media/shorts/w02_weapons_switch_a15.mp4       # 單段原料
web/media/shorts/w02_weapons_switch_30s.mp4       # 成片
```

#### 7.4 備援（API／Veo）

- 單次仍多為 8s → 同錨圖產 2～3 鏡 + 溶解接片  
- 或 Veo **Extend** 拉長同一鏡頭（適合氣氛鏡，不適合跳場景）

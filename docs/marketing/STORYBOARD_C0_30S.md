## 角色與世界鎖(每一鏡都要過)

**小白**

- 米白斑駁金屬發條玩具兔。2.2-2.8 頭身。立耳(金屬件, 內耳鏽紅)。
- 青綠玻璃眼、胸口青綠核心。背後**上背部**黃銅發條鑰匙 -- 用四分之三側背, 鑰匙必須破出剪影。
- 武器: **一把**鏽蝕單手長劍, 比身子還長。禁止雙劍。
- 禁止絨毛、布偶、垂耳、瓷娃娃、空白眼、真人比例機甲。

**敵(C0 教學戰)**

- 殘破鐵皮加生鏽齒輪拼成的玩具狼。眼珠過熱**赤紅**。
- 打贏 = 體內發條**脫扣彈開**、紅光熄。牠倒在積木旁, 仍是一隻被遺忘的舊玩具。禁止流血、禁止殺死、禁止魔獸。

**場景**

- 閣樓停擺。月光、木箱、積木、靜止玩具。齒輪只點綴, 不大過畫面。
- 玩具堆邊緣黎明。停擺鐘擺卡在傾斜角。
- 遠景: 創想界域沙盤加雲海頂端超巨型黃銅**世界大鐘**, 指針**凝結**。

**禁詞(舊 IP)**

葫蘆、翠谷、黑焰、傭兵、麥穗當信物。信物用 **鑰繩**。

**憲章殘留(不改 CANON, 本片不跟)**

`CANON.md` 1.3 仍寫「白絨絨的發條兔」。緒論與 2026-09-07 修訂已改米白金屬。本分鏡跟緒論、C0、美術定調, 不用「絨毛」。

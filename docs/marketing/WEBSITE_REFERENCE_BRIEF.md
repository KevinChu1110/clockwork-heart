# 官網視覺參考簡報（Kevin 2026-09-08 指定四個參考站）

Kevin 指定四個官網當參考標竿，這份文件記錄各站抓到的重點與《發條之心》官網要照哪些方向改。

## 參考站觀察

1. **《燕雲十六聲》**（wherewindsmeetgame.com）—— 武俠開放世界大作，網易 Everstone 出品。
   水墨國風美術，場景與過場服裝講究、視覺沉浸感強，走「史詩感」路線。
2. **《神魔之塔》**（towerofsaviors.com）—— 老牌手遊官網，資訊型入口網站架構：
   公告/遊戲指引/神魔世界(故事/音樂/圖鑑)/社群/規章一應俱全，導覽選單深、內容更新頻繁（幾乎每天有新公告），
   證明「官網＝活的營運陣地」而不是一次性的行銷頁。
3. **《黑神話：悟空》PlayStation 頁**—— 3A 主機遊戲的產品頁規格：大圖/實機影片為主視覺，走精品化包裝。
4. **GTA V / GTA VI（Rockstar Games）**—— 業界公認電影感網站標竿：
   scroll-driven 動態敘事（GSAP ScrollTrigger）、影片隨捲動同步播放、視差分層、pinned 區塊、角色逐一登場，
   整站像在看一部可互動的預告片，而不是靜態排版。

## 對照《發條之心》官網現況，該補的方向

- **動態敘事感**：目前首頁是靜態區塊堆疊，缺 GTA 那種「捲動＝敘事」的節奏。至少 Hero 區與角色介紹區可以做
  視差／淡入捲動效果（不需要 WebGL 等級，CSS scroll-timeline 或輕量 GSAP 即可）。
- **官網要「活」，不是一次性長圖**：參考神魔之塔——之後粉專發文/版本更新應該同步在官網開一個「公告/更新日誌」
  欄目，讓官網變成持續更新的陣地，不是產完素材就晾著。
- **精品感包裝**：參考黑神話悟空與燕雲——實機截圖/影片要挑「這張真的能打」的，不夠精緻寧可先不放（已經是
  team 現行規則），角色展示區塊可以做成一次一位主角的沉浸式呈現，而不是縮圖網格。
- **配色統一與情緒感**：這四站沒有一個是「配色打架」的，我們官網現有的青綠色 CTA 按鈕、留白斷層問題（阿宏
  t_c0414139 正在修）跟這個標準比對，落差就是問題所在。

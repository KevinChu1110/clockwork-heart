# 衣櫥：穿著中的部件該出現在哪個分頁（設計決定草案 · Refs #62）

> **狀態：設計提案，等 KC 確認。** 只有文件，沒改程式。規則落地由程式端在 PR #19（`w9/wardrobe-toy-families`）上做。
> 家族分組規格見 PR #38 的 `docs/TOY_FAMILIES.md`（#34），本文件只處理「穿著中的件」怎麼顯示。

## 1. 現象與原因

旋轉木馬分頁的外裝列表第一張是「胡桃鉗近衛軍裝 ✓已選用」，但它屬於胡桃鉗兔（#62 截圖）。

**原因不是「穿著中的件會出現在每頁」，而是「本體預設件被當成基本款」**：
- `wardrobe_dialog.gd` 的 `_family_items()`／`_rebuild_cards()` 把 `["none", 本體預設件]` 當 `base_ids` 傳給 `ToyFamily.family_of_item()`，回傳 `""`（基本款）。`_family_visible()` 對 `""` 一律回 true，所以**每個分頁都列**。
- 兔子的預設外裝剛好就是胡桃鉗近衛軍裝，新存檔一定穿著它，所以看起來像「穿著中的件到處出現」。換穿別的家族的件（例：晨曦行者武道短褂）就只會出現在自己的分頁。
- **同一個檔案自己前後不一致**：開衣櫥時決定停在哪個分頁，`base_ids` 只給 `["none"]`，所以預設外裝被算成胡桃鉗兔、衣櫥會開在胡桃鉗兔頁；但列卡片時又把它當基本款。
- 七個槽位都有同樣的規則：頭部（雙聯長立金屬耳）、鑰匙（雙孔古銅）、武器（晨曦發條單手長劍）、光學核心、隨身奇玩、塗裝（原廠象牙白）的預設件都在每一頁出現（TOY_FAMILIES.md §5 表）。

## 2. 選項

### A. 只出現在自己的家族分頁（建議）

- 「基本款」只剩 `none`（無外裝／空槽）。本體預設件照原廠件規則歸本體家族（兔子 → 胡桃鉗兔），跟開衣櫥時的判斷一致。
- 穿著中的件只在它自己的家族分頁出現（帶「✓已選用」）。
- 開衣櫥時自動停在穿著中外裝所屬的分頁（程式已經這樣做）。
- 某分頁某槽位沒有任何件時，顯示空狀態「這個家族還沒有○○」，不要留一片空白（件數不足另見 #30）。
- **優點**：分頁＝家族，一眼知道自己在哪；規則簡單，跟開衣櫥的判斷一致；不用新 UI。
- **缺點**：切到別的家族分頁時，看不到「我現在穿什麼」的卡片——但左邊的紙娃娃預覽一直顯示穿著中的樣子，名牌也會顯示家族（PR #67／#60）。頭部、鑰匙這種沒有 `none` 的槽，在其他家族分頁可能整列是空的（要靠空狀態文字）。

### B. 每個分頁最前面加一個固定的「穿著中」位

- 每個槽位列表最前面固定放一張「穿著中」卡，外框和一般卡不同，角標寫它的家族（例：「穿著中 · 胡桃鉗兔」）。真正的卡片只在自己的家族分頁。
- **優點**：任何分頁都看得到目前穿什麼，也看得到它屬於哪個家族；做比較（穿著中 vs 這頁的件）很直覺。
- **缺點**：要做新卡片樣式、七個槽位都要；自己家族分頁裡會出現兩張同一件（固定位＋本來的卡），要決定隱藏哪張；在家族分頁件數少（#30）時，固定位會佔掉最顯眼的格子，讓「這頁只有一兩件」更明顯。

### C. 維持現況，只加家族角標

- 預設件照舊每頁都列，但卡片角標寫上它真正的家族。
- **優點**：改動最小。
- **缺點**：沒解決 #62 的核心（玩家還是會以為胡桃鉗近衛軍裝屬於旋轉木馬頁）；每頁件數被灌水，跟 #30 的「件數太少」問題混在一起看不清楚。

## 3. 設計建議

**A**：基本款只保留 `none`，本體預設件歸本體家族；穿著中的件只在自己的家族分頁出現；沒件時顯示空狀態。

理由：
1. 衣櫥分頁的意義就是「家族」，A 讓每張卡只屬於一頁，跟 TOY_FAMILIES.md 的歸類規則（原廠件歸本體家族）一致，也修掉同一檔案內前後不一致的判斷。
2. 「我現在穿什麼」已經由紙娃娃預覽和名牌負責，不需要再多一張固定卡。
3. B 的固定位可以留作日後加強；若 KC 實測後覺得切頁時找不到自己穿的東西，再補 B，不衝突。

## 4. 待 KC 確認

1. 選 A／B／C？
2. 若選 A：預設件（胡桃鉗近衛軍裝、原廠象牙白、雙孔古銅鑰匙、晨曦發條單手長劍…）一律歸胡桃鉗兔，可以嗎？（TOY_FAMILIES.md Q1 選 A 時兩邊一致。）
3. 頭部、鑰匙等沒有 `none` 的槽，在空的家族分頁要顯示空狀態文字，還是乾脆把預設件當「基本款」保留在每頁（只對這些槽例外）？設計傾向空狀態，例外越少越好。

## 5. 給程式的落地方向（確認後）

- `wardrobe_dialog.gd`：`_family_items()` 與 `_rebuild_cards()` 的 `base_ids` 改成只有 `["none"]`（與開衣櫥時一致）。
- 空槽位顯示空狀態（五語）。
- 測試：預設外裝只出現在胡桃鉗兔頁；換穿旋轉木馬外裝後，胡桃鉗兔頁不再顯示「✓已選用」；`none` 每頁都在。

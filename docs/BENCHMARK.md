> **狀態：草案。對標名單和每一條標有「待 KC 決定」的門檻都要 KC 拍板才算數。**
> 對應 issue：#55。本文件只放研究結論、差距和審核清單，**不改任何數值、規則或程式**；經濟和戰鬥的建議一律寫成選項給 KC 選。

## 寫法規則

- **只用公開資料**：商店頁、官方客服公告、業界媒體、法規原文。每一個數字都附連結；查不到官方來源的寫「未查證」或「社群觀察」。
- **不抄素材、不抄文案**：只描述對方「怎麼做」，不搬圖、不搬字。
- **「我們現在」一律附檔案或 PR**：以 `main` 為準；還在 PR 上的東西會寫 PR 編號，並註明尚未合併。
- **嚴重度**：
  - **S0 阻擋**：違法、或會被商店退件。上架前一定要解決。
  - **S1 高**：玩家第一天就會感覺到，直接傷留存。
  - **S2 中**：中期（第 3–14 天）會感覺到。
  - **S3 低**：加分項，或要等內容量起來才看得出來。

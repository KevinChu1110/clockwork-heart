## 0. 執行摘要與邊界宣告

1. **提案定位**：本文件為《發條之心》既有 7 大紙娃娃部件槽位系統（`mob-paperdoll`）在前十六族（兔／狐／獅／豬／猴／虎／鶴／熊／企鵝／龜／象／蛙／熊貓／鹿／犬／梟）規格完備後的**第 17 種動物擴充素體規格**。
2. **經典玩具起源與古典機械夜行貓工藝**：
   - 本提案選定全球古典機械玩具史與鐘錶微型自動人偶名作——**「古典發條夜行潛行貓（Victorian Clockwork Prowling Cat / Swiss Automata Feline）」**（直接承接 `docs/world/regions/R04_BRASS_METROPOLIS.md` 第 20 行與第 239 行核心地標「摩天齒輪工坊群」之高空屋脊、蒸氣管道與暗夜齒輪穿梭設定）；
   - 作為全遊戲 17 大種族中**首款也是唯一的靜音步態足墊、雙聯夜視裂隙目鏡與多節同軸平衡鋼索尾素體（Silenced Footstep, Slit-Optic & Segmented Gyro-Tail Chassis）**，在材質工藝（冷軋曜黑碳化鋼板件、沖壓薄黃銅折角共鳴拾音耳、吸震耐磨高彈性工程矽膠足墊、六根超細鎢鋼微振彈簧鬚）、幾何辨識（圓滾滾 2.2 頭身靈動身軀、反手單持發條袖刃、背部新月夜行雙環發條鑰匙、九節平衡鋼索尾）與戰鬥身法（極致靜音、影遁瞬移、弱點死線背刺）上，與前十六族形成 100% 徹底差異化之視覺辨識度與操作手感。

1. **100% 零真毛皮、零貓肉、零肉爪、零肉墊、零流血**：
   - 絕對禁止任何生物貓科皮毛、真皮肉墊、肉質舌頭、真鬍鬚或有機軟組織。
   - **軀體外殼轉譯**：全數轉譯為**「冷軋曜黑碳化鋼板件（Cold-Rolled Obsidian Steel Plates）」**。板件邊緣帶有微細冷鉚釘接縫與拋光金屬倒角，表面塗刷消光耐磨曜黑保護漆，在光線下呈現細膩的鋼鐵微紋理。
   - **面部與耳部轉譯**：拒絕生物貓臉！面龐轉譯為一體成型象牙米白琺瑯面頰板（#FFFDF8），鼻尖為金色黃銅沖壓微型三角卡扣；雙耳為**「沖壓薄黃銅折角共鳴拾音耳（Stamped Brass Resonant Acoustic Ears）」**，內耳刻有精密收音螺線紋理，基座安裝雙軸微型步進鉸鏈，可隨環境聲波多向獨立偏轉。
   - **貓鬚微調感測器**：左右兩頰各安裝三根（共六根）**「超細鎢鋼微振彈簧鬚（Tungsten Micro-Spring Whiskers）」**，隨角色走位與氣流微幅顫動，用於感知狹窄管道間隙。
   - **面部光學核心**：雙眼為**「雙聯夜視裂隙光學目鏡（Slit-Aperture Night-Optic Domes）」**，直徑各 24px。鏡片為高透祖母綠光學石英晶體，中心嵌有一道可隨光線強弱收縮的縱向金屬光圈裂隙（Slit Aperture），施法或鎖定弱點時綻放出純淨的薄荷螢光（#4ED86A）。
   - **足部與靜音步態**：四肢端點配備**「吸震軟矽膠靜音步態足墊（Sound-Damping Silicone Paw-Pads）」**，採用黑色高彈性工業工程矽膠模壓成型（零生物肉體！），著地無聲；足尖內藏三指**「高碳鎢鋼精密伸縮爪（Retractable Tungsten Claws）」**，抓地或攀爬時藉由內部微型扭簧瞬間彈出，伴隨金屬卡扣清脆響聲。
   - **尾部動態平衡機構**：尾巴轉譯為**「九節同軸偏心輪平衡發條鋼索尾（Segmented Gyro-Tail）」**。由九節空心沖壓黃銅微型轉子穿套在超柔韌彈簧鋼索上，奔跑、翻滾與滯空時自動甩動以平衡身體力矩。

## 七、 包體 / Token 成本評估（Bundle & Token Cost Assessment）

### 7.1 包體增量與快取預算評估（Bundle Budget）

依據專案核心憲章 `docs/BUNDLE.md` 與 `docs/PRODUCT_LOCK_0.20.md` §5.2 規範進行精確成本測算：

1. **單族完整美術資產清單與容量測算**：
   - 官方高解析度 2D 立牌（400×840 px，WebP/TinyPNG 最佳化）：~230 KB；
   - 戰鬥 6 姿態序列幀切片（128×128 px × 6 幅）：~125 KB；
   - 紙娃娃 7 大模組化槽位首發切片（Chassis / Head / Key / Costume / Face / Weapon / Curio）：~175 KB；
   - UI 縮圖與頭像（HUD 64×64 / Icon 48×48）：~25 KB；
   - **單一素體全套 2D 資產總淨增量**：約 **550 KB ~ 720 KB（< 0.8 MB）**。
2. **首包影響與分包策略（Packaging Tier）**：
   - 幽影貓素體切片封裝於可選之外觀擴充包（Expansion Assets Tier）；
   - 核心首包（Core Bundle）僅需載入基礎資料庫定義（JSON < 2 KB），在玩家未解鎖或未下載該外觀前，客戶端以預設通用預覽佔位渲染，零首包膨脹風險；
   - 據實核對現狀：`PRODUCT_LOCK_0.20.md` §5.2 明載當前專案 Web 目錄為 135 MB，距離目標 50~80 MB 尚在收斂推進中，本提案嚴格保證不增加額外首包負擔。

### 7.2 執行期記憶體與 Token 成本評估（Runtime & Token Cost）

1. **客戶端記憶體與 DrawCall 負載**：
   - 幽影貓 7 大槽位切片完全複用既有的 2D 紙娃娃 CanvasItem 著色器（`sprite_db.gd`），不新增額外材質 Pass；
   - 單一角色待機狀態佔用 VRAM 約 1.1 MB，符合行動裝置低階 2GB RAM 設備同屏 10 人流暢 60 FPS 規範。
2. **LLM 描述與資料結構 Token 預算**：
   - 機器讀取規格配置段落（JSON）嚴格控制在 310 ~ 350 tokens 之間；

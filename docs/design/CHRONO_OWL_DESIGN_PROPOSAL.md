## 0. 執行摘要與邊界宣告

## 一、 職業與武器定位（Class & Weapon Prototype）

### 1.1 既有十五族武器與職業光譜全盤點

盤點現有首發五族與前十款擴充族的原生經典武器與職業分佈如下（嚴格對齊 `review.md` 23f-1 之正式中文名稱）：

- **白金兔（Clockwork Rabbit）**：騎士 (Knight) —— 單手長劍（`sword`），平衡攻防，中近距離。
- **烈鬃獅（Gilded Lion）**：騎士 (Knight) —— 皇家長槍（`spear`），中距控場，格擋迎擊。
- **靈尾狐（Astral Fox）**：法師 (Mage) —— 秘術法杖（`magic`），遠程法術，技能爆發。
- **鋼牙豕（Forge Boar）**：戰士 (Viking) —— 鍛爐巨鎚（`hammer`），高防厚重，部位破壞。
- **靈爪猴（Spring Macaque）**：武術家 (Monk) —— 機關靈爪（`claw`），彈簧伸縮臂，近身連打破勢。
- **烈焰虎（Ember Tiger）**：忍者 (Ninja) —— 齒輪雙斬刃（`dagger`），伏擊撕裂，近戰極限暴擊。
- **雲嵐鶴（Cloud Crane）**：遊俠 (Ranger) —— 風弦羽翼機關弓（`bow`），超視距狙擊，遠程精準破甲。
- **玄軸熊（Iron Bear）**：戰士 (Viking) —— 玄軸偏心重力錘（`hammer` 變體），磐石壁壘，大範圍震波。
- **蒸氣企鵝（Steam Penguin）**：遊俠 (Ranger) —— 蒸氣雙管導航火槍（`gun`），直線高壓蒸氣爆發，精準點射。
- **玄機龜（Xuanji Tortoise）**：法師 (Mage) —— 玄機八卦發條星盤 / 磐甲浮空護體靈晶（`crystal`），護盾織刃，高防反震。
- **鋼岳象（Colossus Elephant）**：戰士 (Viking) —— 巨輪開山重斧（`axe`），質量重力斬劈，單發物理最高傷害。
- **碧簧蛙（Spring-Leg Frog）**：忍者 (Ninja) —— 碧葉旋刃機關鏢（`dart`），高速牽制，多段飛鏢射殺。
- **瓷韻熊貓（Porcelain Panda）**：武術家 (Monk) —— 乾坤太極機關拳套（`fist`），貼身寸勁連打破勢，動靜化勁。
- **翠角鹿（Emerald Fawn）**：遊俠 (Ranger) —— 翠木角尺複合機關弓（`bow`），停拍看破，機動連發射擊。
- **星軌犬（Orbit Hound）**：騎士 (Knight) —— 星軌雷達天線槍 / 光子信標穿刺長槍（`spear`），中距失重滑行，磁軌迎擊控場。

在《發條之心》現有 `game/data/tables/weapon_classes.json` 明定的 6 大職業（`knight`、`viking`、`ninja`、`monk`、`mage`、`ranger`）中：
- 騎士（Knight）已有 3 族（兔、獅、犬）；
- 戰士（Viking）已有 3 族（豕、熊、象）；
- 遊俠（Ranger）已有 3 族（鶴、企鵝、鹿）；
- 忍者（Ninja）已有 2 族（虎、蛙）；
- 武術家（Monk）已有 2 族（猴、熊貓）；
- **法師（Mage）目前僅有 2 族（狐、龜）！** 且其中掛載於 **`magic`（杖 / 法師·杖）** 系統的僅有第三族靈尾狐單一素體！

第十六族靈鐘鴞正式選定掛載於 **`mage`（法師）** 職業體系，原生武器對齊 **`magic`（杖 / 法師·杖）**。依據 `review.md` 23f-1 規定，職業正式名稱嚴格對齊為單一正式名：**`法師 (Mage)`**。

### 1.2 靈鐘鴞武器選擇：【渾天星儀擒縱法杖 / 天文星曆權杖（Armillary Escapement Scepter / Celestial Orrery Wand）】

靈鐘鴞原生專屬武器定名為：**【渾天星儀擒縱法杖 / 天文星曆權杖（Armillary Escapement Scepter / Celestial Orrery Wand）】**。  
該武器底層完全掛載於 `weapon_classes.json` 的 `magic`（法師·杖）類別，享有 `magic` 既有的「把星屑當墨」之標籤宣言（Tagline: \"把星屑當墨\"）、極致的技能爆發與大範圍星象彈道特性（`atk: 1, def: -1, hp: -2, crit: 2.5, speed: 0`），完美呼應 R02 晨曦小鎮懸吊齒輪鐘樓「星象校準、擒縱導能」之核心世界觀！遵循 `0-MKT7` 單持規範，右手單持以黃銅同心環與石英星盤組裝的天文權杖，左翼自然收束平舉引導星象微光，絕無雙持。

1. **打擊型態差異（靈動穿梭連射 vs 陣地護盾反傷 vs 刻度引導與範圍星爆）**：
   - **靈尾狐（狐·杖）**：依託身法高速後撤，依靠魔杖連續點射散彈狐火，偏向「高機動遠程遊擊、技能急速回轉」。
   - **玄機龜（龜·晶）**：原地展開八卦結晶護罩，依靠吸收敵方傷害轉化為反震光刃，偏向「堅如磐石、穩紮穩打」。
   - **靈鐘鴞（鴞·杖）**：懸停或踏穩陣腳，法杖頂部渾天三環展開，在地面投影出同心圓齒輪鐘面刻度法陣；以「秒針跳動節奏（2 秒一拍）」引導天降星屑延遲爆裂，兼具精準破甲與大範圍清場，偏向「時鐘刻度控場、計算型星象法術」。
2. **力學核心與動態性格（靈狐飄逸 vs 靈龜沉凝 vs 智鴞冷靜與棘輪旋轉）**：
   - **靈尾狐（狐）**：尾部多節懸浮關節如同星軸天線，性格靈巧狡黠。
   - **玄機龜（龜）**：四足扎地，縮頸液壓抗震，性格敦厚沉著。
   - **靈鐘鴞（鴞）**：圓滾滾 2.2 頭身球形身軀，頭頸內置 360 度自鎖棘輪轉向環；待機與施法時頭部不時發出「喀喀喀」清脆棘輪聲偏轉對焦；鐘面目鏡金屬指針微動，展現天文鐘匠與守夜學者的淵博冷靜。
3. **材質與外觀語言（流線合金 vs 鑄造青銅 vs 沖壓黃銅疊片與石英鐘面）**：
   - 靈尾狐通體為高光珍珠白與淺紫金屬板件；
   - 玄機龜通體為厚重的古青銅氧化綠銹與八卦雕紋；
   - 靈鐘鴞為全遊戲**首款也是唯一的鐘面光學與疊片金屬羽翼素體**：採用高剛性沖壓黃銅疊片羽翼板件（Stamped Brass Feather Lamellae），外披深邃午夜曜藍烤漆（#1F1A3A），腹部為象牙米白琺瑯面頰板件（#FFFDF8），胸前高透石英視窗透出跳動的擒縱擺輪，雙目為同心圓刻度石英鐘面，背部插裝三環日月星象發條鑰匙，極具十九世紀精密鐘錶玩具之美。

## 二、 外觀定調與機械美學（Aesthetic & Mechanical Canon）

### 2.1 嚴守《世界憲章》（CANON.md）鐵律

1. **100% 零真羽毛、零鳥肉、零軟組織、零流血**：
   - 絕對禁止任何生物禽鳥絨毛、真皮鳥喙、肉質舌頭、肉爪或有機血肉組織。
   - **鴞身羽翼板件轉譯**：全數轉譯為**「沖壓黃銅疊片羽翼板件（Stamped Brass Feather Lamellae）」**。雙翼由 12 片大小遞減的拋光黃銅片衝壓而成，邊緣帶有微細沖壓齒牙與防刮卷邊，關節處由精密銅質半圓頭鉚釘鉸接，開合時發出如精緻刀剪般的金屬摩擦脆響。
   - **頭部與頸部轉譯**：拒絕生物鳥首！轉譯為**「沖壓半球黃銅頭蓋骨（Stamped Brass Cranium Shell）」**搭配**「360 度自鎖棘輪轉向頸環（360-Degree Ratchet Swivel Neck Ring）」**。頭部可在水平面內進行 360 度無死角轉向，轉動時帶有清脆的棘輪自鎖卡嗒聲；頭頂上方聳立一對沖壓青銅翎管微波天線羽（Brass Plume Antennas），作為星象微波訊號接收器。
   - **面部光學核心**：面龐採用一體成型象牙米白琺瑯面頰板（#FFFDF8），鼻部為短小精巧的金色黃銅沖壓金字塔三角短喙；雙眼為**「雙聯同心圓刻度石英鐘面目鏡（Concentric Clockface Lens Domes）」**，直徑各 28px，內部刻有 12 格微縮天文刻度，一根極細的發光金黃秒針在鏡內規律跳動，鏡片隨施法深度具備物理伸縮調焦感。

## 七、 包體 / Token 成本評估（Bundle & Token Cost Assessment）

### 7.1 包體增量與快取預算評估（Bundle Budget）

依據專案核心憲章 `docs/BUNDLE.md` 與 `docs/PRODUCT_LOCK_0.20.md` §5.2 規範進行精確成本測算：

1. **單族完整美術資產清單與容量測算**：
   - 官方高解析度 2D 立牌（400×840 px，WebP/TinyPNG 最佳化）：~240 KB；
   - 戰鬥 6 姿態序列幀切片（128×128 px × 6 幅）：~130 KB；
   - 紙娃娃 7 大模組化槽位首發切片（Chassis / Head / Key / Costume / Face / Weapon / Curio）：~180 KB；
   - UI 縮圖與頭像（HUD 64×64 / Icon 48×48）：~30 KB；
   - **單一素體全套 2D 資產總淨增量**：約 **580 KB ~ 750 KB（< 0.8 MB）**。
2. **首包影響與分包策略（Packaging Tier）**：
   - 靈鐘鴞素體切片封裝於可選之外觀擴充包（Expansion Assets Tier）；
   - 核心首包（Core Bundle）僅需載入基礎資料庫定義（JSON < 2 KB），在玩家未解鎖或未下載該外觀前，客戶端以預設通用預覽佔位渲染，零首包膨脹風險；
   - 據實核對現狀：`PRODUCT_LOCK_0.20.md` §5.2 明載當前專案 Web 目錄為 135 MB，距離目標 50~80 MB 尚在收斂推進中，本提案嚴格保證不增加額外首包負擔。

### 7.2 執行期記憶體與 Token 成本評估（Runtime & Token Cost）

1. **客戶端記憶體與 DrawCall 負載**：
   - 靈鐘鴞 7 大槽位切片完全複用既有的 2D 紙娃娃 CanvasItem 著色器（`sprite_db.gd`），不新增額外材質 Pass；
   - 單一角色待機狀態佔用 VRAM 約 1.2 MB，符合行動裝置低階 2GB RAM 設備同屏 10 人流暢 60 FPS 規範。
2. **LLM 描述與資料結構 Token 預算**：
   - 機器讀取規格配置段落（JSON）嚴格控制在 320 ~ 360 tokens 之間；
   - 欄位命名嚴格遵循既有 `paperdoll_slots.json` 規範，避免冗餘深層巢狀結構，大幅降低後續 Agent 在解析、檢索與代碼生成時的 Prompt 上下文開銷。

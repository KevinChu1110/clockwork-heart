## 0. 執行摘要與邊界宣告

1. **提案定位：延續第六巡（第 31~36 族）第四順位「武術家 (Monk)」擴充，達成武術家 3 爪 3 拳完全對稱平衡**：  
   本文件為《發條之心》既有 7 大紙娃娃部件槽位系統（`mob-paperdoll`）正式制定的**第三十四種動物擴充素體規格**。  
   依據 6 大職業標準循環（`knight` -> `viking` -> `ninja` -> `monk` -> `mage` -> `ranger`），在第 31 族破浪旗魚完成第六巡第一順位騎士（達成 3 劍 3 槍）、第 32 族重角犀牛完成第六巡第二順位戰士（達成 3 鎚 3 斧）、第 33 族星翼蝙蝠完成第六巡第三順位忍者（達成 3 匕 3 鏢）之後，本提案精準掛載於第四順位的 **武術家 (Monk)**，原生武器對齊 **拳（`fist` / 武鬥·拳）** 體系。

## 四、 六大戰鬥動作姿態意象拆解（Six Combat Poses Breakdown）

針對既有戰鬥引擎之六大標準動作姿態（`attack` / `hit` / `idle` / `recover` / `skill` / `telegraph`），制定符合 2.2 頭身 Q 版發條玩具力學之意象規範：

1. **待機姿態（`idle`）**：  
   鋼臂巨猩雙腿微蹲，底盤扎實，左臂微曲握拳護於胸前，右臂重裝拳套垂於身體右前方；身軀隨內部蒸氣節奏進行均勻的上下微幅呼吸起伏，背部雙煙囪每隔 1.8 秒輕吐一圈白色蒸氣，雙眼壓力表指針保持在綠色安全區。

   身軀重心後移微縮，右臂重裝拳套向後大幅拉開蓄勢，拳套腕部紫銅氣筒劇烈增壓，指針瞬時飆升至紅色危險區；背部雙排氣煙囪蓋猛烈掀起，向後噴射出滾滾熾白高壓蒸氣，地面金屬磚被震動震顫。
3. **普通攻擊（`attack`）**：  
   借由腰部巨大發條彈力向前猛然踏步，右臂如巨型鍛壓衝床般迅猛向前打出一記直拳；拳峰滑動鎢鋼衝頭在命中瞬間藉助氣壓向前彈射 4px，發出沉悶而震撼人心的「鏗——砰！！」金屬鍛打巨響，將敵人架勢條瞬間打爆。
4. **技能爆發（`skill`）**：  
   鋼臂巨猩仰天短促咆哮（雙手握拳猛烈捶打胸前米白鍋爐鋼板兩下，發出清脆鑼鼓聲），背部過熱洩壓窗口全面開啟；隨後全身騰空跳躍而起，右臂高舉重拳，以泰山壓頂之勢向地面目標轟出一記「超載過熱崩山重捶」，衝擊波化為全屏擴散的環形金色齒輪蒸氣陣，引發大範圍破勢眩暈！

   遭受攻擊時，鋼臂巨猩本能地將雙臂在面前交叉收攏，形成堅不可摧的厚重鎢鋼前臂護盾（Peek-a-boo Guard）；身軀重心壓低僅向後平移滑動半步，足底菱形紋掌板在金屬地面擦出耀眼的金色火星。
6. **後搖恢復（`recover`）**：  
   雙臂重新沉穩分開，腰際與背部煙囪噴出一股濁白的洩壓蒸氣，眼眸壓力表指針自高壓紅區迅速回落至中段，右臂重拳回防胸前，身軀重新回正進入穩若磐石的警戒待機。

## 五、 PRODUCT_LOCK 審查問卷（§9 准入門檻六問六答）

### Q1：它掛在哪個核心循環的哪一環？

### Q6：為了做它，要放棄什麼？（「不用放棄什麼」一律退件）

1. **放棄過度昂貴的即時全局高溫熱浪擾動與全屏粒子煙霧模擬著色器**：放棄在行動端即時運算昂貴的熱空氣折射效果，改以美術預渲染之多巴胺蒸氣色票、精緻序列幀蒸氣圈與排氣火花切片呈現，確保低階手機流暢 60 FPS；

## 0. 執行摘要與邊界宣告

1. **提案定位：接棒第五巡（第 25~30 族）第五順位「法師 (Mage)」擴充**：  
   本文件為《發條之心》既有 7 大紙娃娃部件槽位系統（`mob-paperdoll`）在第二十五種動物巡林松鼠（騎士·劍）、第二十六種動物熔火蜥蜴（戰士·鎚）、第二十七種動物竹影青蛇（忍者·匕）與第二十八種動物疾影神隼（武術家·爪）相繼出陣後，正式制定的**第二十九種動物擴充素體規格**。  
   依據 6 大職業標準循環（`knight` -> `viking` -> `ninja` -> `monk` -> `mage` -> `ranger`），本提案精準掛載於第五順位的 **法師 (Mage)**，原生武器對齊 **法杖（`magic` / 法師·杖）** 體系，象徵五巡星穹奧術法師正式降臨！
2. **經典玩具起源與古典機械發條游絲靈羊工藝**：  
   - 本提案選定全球古典機械玩具史與鐘錶調速微雕之永恆經典——**「古典雙螺旋游絲機械盤角羊發條自動偶（Vintage Swiss Clockwork Spiral-Horn Ram Automaton / Astrolabe Celestial Ram）」**；  
   - 完美承接世界觀無可撼動的官方設定法源：`docs/world/regions/R07_STARFALL_ORBIT.md` 第 1 行、第 4 行與 `docs/world/ATLAS.md` 第 14 行、第 115 行明載的高軌頂層界域「**R07 星穹軌道·外星基地**」之失重星空沙盤、聚合物模組與群星調諧設定；  
   - 作為全遊戲首款且唯一具備**「雙螺旋超導磷青銅游絲盤角、多層弧面高光琺瑯雲紋防護甲片、失重微漂星軌引力法袍、星光琥珀金色點陣 LED 晶片目鏡、星盤三叉星芒發條鑰匙與懸浮反重力星環儀」之星穹天體奧術法師素體（Dual Phosphor-Bronze Balance Spring Horns, Concentric Enamel Lamellae, Anti-Gravity Astro-Robe, Pulsar Amber LED Optics, Astrolabe Tri-Star Key & Floating Gravitational Orbit Rings）**。

   在全遊戲 9 大界域中，高軌頂層科技沙盤界域 `R07 星穹軌道·外星基地` 長年僅具備星軌犬（騎士·槍）與星巡浣熊（遊俠·銃），整體生態嚴重缺乏調諧無線磁通脈衝與掌控天穹星圖天象的法系領袖。星盤靈羊的加入，使 R07 正式形成「星軌犬（磁軌穿刺迎擊）× 星巡浣熊（脈衝光銃點射）× 星盤靈羊（星軌游絲共鳴轟擊）」之星穹遠征鐵三角陣容！

### Q2：它服務 §1.6 哪一根體驗支柱？第幾優先？
**答**：服務 **第一支柱「覺醒玩具的冒險史詩與極致反差萌」（P0 最高優先）** 與 **第四支柱「零數值壓迫的個性化外觀審美（P1 次高優先）」**。以溫柔可愛的象牙白小羊外貌，駕馭宇宙引力與星穹天體奧術，完美體現「弱小玩具迎戰龐大世界」的極致反差萌。

### Q3：玩家在手機上用單手拇指能不能操作它？
**答**：**能，100% 完美支援**。所有動作反饋、施法彈道與法杖單持輪廓均針對手機螢幕（橫屏雙拇指操作與單拇指點擊）進行視覺放大與高飽和度最佳化，0.5 秒內即可清晰辨識動作前搖，絕無遮擋 UI 或技能鍵之疑慮。

### Q4：它需不需要伺服器才能運作？（需要就違反 §6）
**答**：**不需要，100% 純客戶端本機運作**。所有素體規格、切片圖層、戰鬥姿態與 JSON 資料表均儲存於本機客戶端，支援純單機離線遊玩與離線換裝，零伺服器依賴。

### Q5：它會不會讓首包超過 §5.2 的 50～80 MB？
**答**：**不會**。全套 7 大切片、戰鬥姿態與官方展台立繪經過 TinyPNG / WebP 高保真壓縮後，總增量僅約 ≤ 0.50 MB，且本階段為純企劃規格文件（0 KB 程式碼二進位增量），絕不增加首包負擔。

### Q6：為了做它，要放棄什麼？（「不用放棄什麼」一律退件）

## 一、 職業與武器定位（Class & Weapon Prototype）

### 1.1 既有八族武器與職業光譜盤點
盤點現有首發五族、擴充第六族烈焰虎、第七族雲嵐鶴與第八族玄軸熊的原生經典武器與職業分佈如下：
- **白金兔（Clockwork Rabbit）**：劍士（Knight）—— 單手長劍（`sword`），平衡攻防，中近距離。
- **烈鬃獅（Gilded Lion）**：騎士（Knight）—— 皇家長槍（`spear`），中距控場，格擋迎擊。
- **靈尾狐（Astral Fox）**：法師（Mage）—— 秘術法杖（`magic`），遠程法術，技能爆發。
- **鋼牙豕（Forge Boar）**：戰士（Viking）—— 鍛爐巨鎚（`hammer`），高防厚重，部位破壞。
- **靈爪猴（Spring Macaque）**：武術家（Monk）—— 機關靈爪（`claw`），彈簧伸縮臂，近身連打破勢。
- **烈焰虎（Ember Tiger）**：忍者（Ninja）—— 齒輪雙斬刃（`dagger`），伏擊撕裂，極限暴擊。
- **雲嵐鶴（The Cloud Crane）**：遊俠（Ranger）—— 風弦羽翼機關弓（`bow`），超視距狙擊，遠程精準暴擊。
- **玄軸熊（The Iron Bear）**：戰士（Viking）—— 玄軸偏心重力錘（`hammer` 變體），磐石壁壘，大範圍震波。

在《發條之心》現有 `game/data/tables/weapon_classes.json` 明定的 6 大職業（`knight`、`viking`、`ninja`、`monk`、`mage`、`ranger`）中：
**`ranger`（遊俠）底層下轄兩套對等武器系統：`bow`（弓）與 `gun`（火槍）。第七族雲嵐鶴已佔用 `bow`，而 `gun`（火槍 / 遊俠·銃）在全 8 族中尚無任何專屬動物素體代表！**

### 1.2 蒸氣企鵝武器選擇：【蒸氣雙管導航火槍 / 淵海發條水銃（Steam Twin Harpoon-Gun / Nav-Gun）】
第九族蒸氣企鵝正式選用 **`ranger`（遊俠）** 體系，完全對齊 `weapon_classes.json` 中的 **`gun`（遊俠·銃，`firearm`）** 系統。依據 `review.md` 23f-1 規定，職業正式名稱嚴格對齊為單一正式名：**`遊俠 (Ranger)`**。

蒸氣企鵝原生專屬武器定名為：**【蒸氣雙管導航火槍 / 淵海發條水銃（Steam Twin Harpoon-Gun / Abyssal Nav-Gun）】**。  
該武器底層完全掛載於 `weapon_classes.json` 的 `gun`（遊俠·銃）類別，享有 `gun` 既有的極致單發爆發（`atk: 5`，全武器最高）、高暴擊（`crit: 4.0`）與「一響定生死」的遠程致命點射手感；同時深度咬合 `docs/world/regions/R05_CRYSTAL_OCEAN.md` 第四章明載之特產武器「發條雙管水銃（Clockwork Twin Harpoon-Gun）」，具備深水追獵與部位牽引之戰術機制。

### 1.3 遠程遊俠雙雄差異化定位：與雲嵐鶴（機關弓）絕不撞型之三大論證

雖然蒸氣企鵝與雲嵐鶴同屬 `ranger`（遊俠）遠程輸出光譜，但在**彈道力學**、**戰術風格**與**造型機械語言**三大維度進行 100% 徹底差異化切割，確保玩家在手機小螢幕上於 0.5 秒內清晰辨識：

```
┌────────────────────────────────────────────────────────────────────────┐
│                  遠程遊俠體系差異化對照表（鶴 vs 企鵝）                │
├───────────────────┬──────────────────────────┬─────────────────────────┤
│ 維度              │ 雲嵐鶴（Cloud Crane 機關弓）│ 蒸氣企鵝（Steam Penguin 水銃）│
├───────────────────┼──────────────────────────┼─────────────────────────┤
│ ① 力學核心與彈道  │ 拋物線風弦穿透／蓄力貫穿  │ 直線高壓蒸氣爆發／雙管齊射│
│                   │ 輕靈箭羽、多段風刃割裂   │ 重銃水錘衝擊、部位牽引  │
├───────────────────┼──────────────────────────┼─────────────────────────┤
│ ② 角色性格與戰術  │ 空靈獨立／超視距風箏拉扯 │ 穩重憨厚／低重心滑步點射│

├───────────────────┼──────────────────────────┼─────────────────────────┤
│ ③ 機械結構與外觀  │ 輕量折疊合金翼片弓臂     │ 鍍鈦耐壓雙管重銃與氣壓筒│
│                   │ 發條滑輪、高張力金屬風弦 │ 背部微型蒸氣鍋爐、雙聯閥門│
└───────────────────┴──────────────────────────┴─────────────────────────┘
```

1. **力學機制差異（拋物線風弦穿透 vs 直線高壓蒸氣爆發）**：
   - **雲嵐鶴（鶴·弓）**：核心意象是「疾風箭羽」。箭矢飛行軌跡可隨風弦張力調節，講求超視距外的弧線弱點貫穿與多段連續風刃割裂。
   - **蒸氣企鵝（企鵝·銃）**：核心意象是「高壓蒸氣水錘」。雙管重銃由背部微型發條蒸氣鍋爐輸送高壓動能，擊發時伴隨短促清脆的蒸氣排氣鳴響與高初速直線直射，具備極強的單發破甲穿透與命中震退反饋。
2. **戰術性格與手感節奏（風箏拉扯神射手 vs 陣地滑行重火槍手）**：
   - **雲嵐鶴（鶴）**：偏向「極致靈動的超遠距游擊」。利用輕盈的長腿與折疊翼滑行拉開身位，於安全距離外維持高頻連射。
   - **蒸氣企鵝（企鵝）**：偏向「低重心穩健架槍的陣地重火手」。2.2 頭身圓厚底盤與金屬展開式腳蹼提供極佳的後坐力穩定性，步態踏實，出招伴隨鍋爐洩壓節奏，展現「不急不躁、一發入魂」的沉著狙擊手感。
3. **外觀機械造型差異（輕巧滑輪折疊弓 vs 工業蒸氣雙管重銃）**：
   - **雲嵐鶴（鶴）**：武器為流線扇形金屬羽翼弓臂，內建發條棘輪與微型滑輪絞盤，收攏如扇，展開如翼。
   - **蒸氣企鵝（企鵝）**：武器為深海耐壓鍍鈦打造的雙聯並列重銃，槍身下方外露金屬氣壓導管與微型壓力指針表，槍托帶有橡膠防滑緩衝襯板，機械感十足。

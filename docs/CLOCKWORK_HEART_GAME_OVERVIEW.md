## 壹、 玩法與系統設計（Gameplay & Systems）

### 1. 核心遊戲循環（Core Loop）
遊戲圍繞「上鍊 → 出征探索 → 部位破壞 → 拆解校準 → 裝備換裝」的閉環運作：
- **發條能量（Clockwork Energy）**：上限 15 點，每次推關或探索消耗。每日定時「誰需要上發條？」登入循環，不設斷簽懲罰，強調輕負擔。
- **四區出征與推關**：九大區域（R01 發條新村、R02 木偶集市、R03 翡翠深林、R04 黃銅巨輪城、R05 琉璃海淵、R06 鍛造火山、R07 星穹軌道、R08 齒輪塚、R09 竹影道場）。
- **部位破壞（Part Break）**：對抗「停擺巨偶（Stalled Colossus）」BOSS 時，玩家鎖定不同部位（核心反應爐、機械巨臂、動力履帶等）。擊破特定部位將 100% 決定掉落對應部位的機芯。

### 2. 戰鬥系統（Combat Ergonomics）
- **雙拇指操作與扇形輪盤**：全面拋棄 PC 式 1-8 快捷欄，改採右下角拇指人因扇形輪盤（普攻、位移突進、蓄力絕技、核心格擋）。
- **發條格擋（Clockwork Parry）**：非無腦站樁，敵方攻擊前搖紅光閃爍時點擊格擋，觸發金屬火花彈刀並反饋發條動能。
- **連擊跳字與傷害階層**：多巴胺暴擊數字跳動，支援屬性過載受傷加深與流暢硬直打擊感。

### 3. 機芯校準與裝備數值（Progression & Balance）
- **五槽機芯系統**：替換舊版複雜主星，收斂為「主發條、傳動齒輪、平衡擺輪、擒縱叉、發條發電機」五大核心槽位。
- **八色階數值階梯**：白(基礎) → 綠(優秀) → 藍(精良) → 紫(史詩) → 金(傳奇) → 橘(神工) → 紅(極限) → 彩(超載)。
- **萬次校準驗證**：具備 7 次保底機制與副詞條隨機生成，多餘或淘汰機芯可至天宮鐵匠鋪一鍵拆解為鐵屑回收。

### 4. 2026 手遊爆點革新提案（Pending Polish）
- **爆點一：【發條超載爆裂（Overwind Burst）】**：戰鬥蓄滿轉數瞬間觸發全螢幕暗角＋齒輪火花噴射，角色狂暴多段大招。
- **爆點二：【發條放置金幣庫（Idle Clockwork Vault）】**：大廳主角發條鑰匙隨時間自動轉動積累資源，手指點擊「匡啷！」噴出滿屏金幣。
- **爆點三：【破壞特寫與金箱頓挫（Break-Cam Slow-Mo）】**：BOSS 部位破壞瞬間鏡頭微推慢動作，金屬碎片飛散，直接掉落發光寶箱開箱反饋。

## 貳、 視覺與美術方向（Art Direction & Visuals）

### 1. 世界觀憲章與視覺鐵則
- **世界觀憲章（CANON）**：覺醒的玩具，**嚴禁任何活體毛皮、羽毛、皮革**。所有角色皆為米白金屬、鍛造黃銅、胡桃鉗近衛軍塗裝與鉚釘板件。
- **核心抽卡與外觀槽位**：背上的「發條鑰匙（Winding Key）」為精神象徵與視覺靈魂，必備發條轉動待機動態。
- **頭身比例**：統一採用 2.0 ~ 2.5 頭身 Q 版矮萌微縮模型質感。

### 2. UI/UX 現代手遊規範
- **色盤規範**：以「黑曜石底色＋古典黃金齒輪光暈」為神殿骨架，搭配「多巴胺鮮亮高飽和色盤」（奶油白 `#FFFDF8`、金黃 `#FFD028`、暖橘 `#FFA010`、天藍 `#38A0FF`、深藍紫描邊 `#1F1A3A`），徹底掃除傳統暗沉泥土灰黑 PPT 感。
- **完全去 Emoji 化**：100% 清除系統 Emoji，按鈕與標籤全數採用自訂向量繪製與多巴胺立體厚底（5~6px Bottom Border）。
- **字體標準**：全遊戲採用「粉圓體 (Open Huninn)」圓滾胖胖字，淘汰生硬冰冷黑體。

### 3. 角色與紙娃娃渲染（Paperdoll Pipeline）
- **512 高清即時合成**：拆分七大槽位（底盤 chassis、頭部 head_unit、眼部核心 optic_core、服裝 costume、背飾 curio、武器 weapon、發條鑰匙 winding_key）。
- **動態著色器（Shaders）**：
  - **邊緣輪廓光（RimLight Shader）**：在角色外圍鍍上一層金色微光高光，解決背景融色問題。
  - **雙層接地陰影（Dual Floor Shadow）**：上層深黑接觸硬影、下層漫反射半透明軟影，使角色紮實踩在地面。
- **六大戰鬥姿態**：每族獨立配備 `idle`（待機呼吸）、`telegraph`（預警）、`attack`（揮擊）、`skill`（絕技）、`hit`（受擊）、`recover`（受創恢復）各幀。

### 4. 正在執行的美術修正
- **背景徹底高清重繪**：替換目前拉伸模糊的 `sky_kingdom_bg.png`，產出三層獨立視差的通透手繪天宮浮島。
- **角色站位與 Icon 降高置中**：中央日晷展台下移 40px，讓角色落在黃金分割點；縮小頭頂光環與名牌釋放上方空間；左上角色頭像追加安全留白，右側裝備 Icon 放大置中。

# C0-S01 · 預言與今夜（場景卡正文）

> 場景卡：C0-S01

世界的大鐘停止走時，已經是不知多少年前的事了。

在無比久遠的歲月之前，創想界域的中央聳立著那座通天的宏偉機關。無數齒輪日夜咬合，金屬指針撥動著晨昏與季候，清脆如泉水般的滴答聲會透過浮空島的雲海，平穩傳遍每一片積木大陸。那時候，每一個玩具的心口都有充足的動能，發條順暢旋轉，軸承塗滿清亮的潤滑油，誰也不必擔心明天醒來時關節會被黑鏽咬死。

然而，大鐘終究停了。

巨型指針如同折斷的巨劍，凝滯在天際的深灰雲層裡。天地間那種讓人心安的脈動戛然而止，取而代之的，是綿延無盡的死寂。沒有了走時的牽引，界域邊緣的動能如潮水退去。無數玩具在經年累月的塵埃裡，發條漸漸鬆脫，關節生出斑駁的鏽色，最後緩緩垂下鐵皮頭顱，閉上了失去光芒的玻璃眼睛。

發條新村就縮在巨型閣樓的一角。這裡是由無數廢棄木箱、積木殘件與老舊硬紙盒搭成的小天地。村子裡的玩具們都是些微末的小東西，每天忙碌著擦拭齒輪、找尋僅存的備用墊圈，或者排隊在老舊的上鍊台前，為彼此緊一緊發條。

沒有誰有心思去思考世界大鐘為什麼停擺。比起遙遠蒼穹上的神話，大家更在乎明天天窗透進的第一道晨光，以及自己的發條還能撐過幾個鐘頭。

古老的預言就刻在村口一塊歪斜的積木底座上。字跡早已被磨損得模糊不清，偶爾有識字的老玩具借著天光讀出來：

「當災厄再臨，封印崩解之時——唯有心中不慕強權的至弱之物，能不被黑焰蒙蔽，走到塔的盡頭。」

沒有玩具拿它當真。

在玩具的世界裡，力氣與鋼板才是硬道理。那些巡邏的發條衛兵身披三層厚鐵皮，胸膛裡裝著高密度的合金發條，每走一步都伴隨著沉重鏗鏘的氣勢；更不用說那些在傳說裡守衛一方界域的聖獸泰坦，光是金屬巨足就能踏平半個積木城鎮。誰會相信什麼「至弱之物」？

小傢伙們甚至常拿這句話來取笑。每次村裡舉行搬運積木的勞動，大家看見小白那副搖搖晃晃的身影，總會忍不住打趣：

「喂，小白！預言裡說的至弱之物，該不會就是你吧？」

「牠背後的發條鑰匙，每次轉不到十圈就卡殼啦！」

小白是一隻米白色的金屬兔子。身高只有兩個半頭身，外殼是薄薄的鐵皮，漆面多處泛著擦傷後的啞光。牠背後插著一枚小小的黃銅發條鑰匙，體內的微型雙子擒縱輪向來走得慢吞吞的。牠膽子小得很，平日在走道上碰見笨重的發條衛兵都要低著頭貼著牆根繞著走，遇到粗暴的鐵皮玩偶嘲弄，也只會默默抱緊懷裡的空機油罐，金屬長耳軟趴趴地耷拉在兩側。

大人們笑完，便轉身去旋緊各自的發條。玩笑只是漫長寂靜歲月裡的一點消遣。誰也沒有想到，命運的齒輪往往是在最不起眼的角落，悄悄咬上了第一顆齒印。

直到今夜。

深夜的閣樓萬籟俱寂，唯有穿堂風吹動破舊布簾的微弱呼嘯。小白蜷縮在老木箱底層的棉花堆邊，體內的發條早已走到盡頭，整具機械身軀沉浸在一種近乎凝固的冰冷中。沒有動能，意識像被浸泡在濃稠的黑水裡，動彈不得。

突然間，一聲極其清脆、極其突兀的機械響動，在死寂的黑暗深處炸開。

「喀嗒。」

那是金屬卡榫彈開的聲音。

緊接著，小白背後那枚冰冷的小發條鑰匙，竟在沒有任何外力碰觸的情況下，自己動了起來！

「吱——吱——喀嗒！」

發條鑰匙開始自行旋轉。一圈、兩圈、三圈……緊固的彈簧片在鐵皮胸膛內層層盤繞，積蓄起沉睡已久的澎湃張力。齒輪急促咬合的聲音清晰得如同雷鳴，在空曠的胸腔裡瘋狂激盪。直到整整十五圈滿格，發條才發出一聲清脆的鎖定悶響。

「嗡。」

原本冰涼晦暗的雙眼眼眶中，兩枚澄澈的青綠色玻璃珠，驟然泛起了水波般的微光。

動能如清泉般灌入四肢百骸。小小的金屬腳掌微顫了一下，螺栓與關節重新獲得了屈伸的力量。小白困惑地眨了眨眼，長耳內的細銅絲天線猛地豎了起來。

動起來吧，小傢伙。

冥冥中彷彿有一道冷靜而悠遠的意念掠過齒輪。

還沒等小白從這難以置信的奇蹟中回過神來，腳下的木地板突然劇烈顛簸起來。遠方傳來一陣沉悶的撞擊聲，彷彿有某種無比龐大且暴虐的重物，正自閣樓頂端狠狠踏下。

緊接著，空氣中的溫度急劇升高。原本乾燥微甜的木料香氣被一股刺鼻的灼焦氣味撕裂。

在木箱縫隙外，遠方的夜空被撕開了一道暗紫色的裂口。那不是晨曦，也不是普通的燭火，而是一團帶著冷冽惡意與吞噬慾望的漆黑烈焰——黑焰。

積木堆在火光中崩塌，發條新村的平靜在今夜化為齏粉。

預言中的黑夜，毫無預兆地砸了下來。

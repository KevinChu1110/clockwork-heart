# C0-S09 · 陌生人的半句（場景卡正文）

橫斬削裂卡榫的震動，仍在金屬手臂的螺栓間發出隱隱的蜂鳴。

荒路上的狂暴風聲漸漸平息，那具失控的鏽蝕哨兵偶癱倒在碎裂的積木堆旁，洩壓後的白熱蒸氣化作一縷青煙，散入清晨冰涼的薄霧裡。敵偶眼眶裡的赤紅火光徹底熄滅，重歸冰涼純淨的冷玻璃，像是在漫長的停擺噩夢中終於尋得了解脫。

小白背靠著一具翻覆的厚紙箱殘骸，順著粗糙的紙板緩緩滑坐下來。

「呼……哈……」

呼吸是滾燙的。體內那枚微型雙子擒縱輪像是剛從滾水裡撈出來一樣，劇烈且紊亂地跳動著。雙臂的金屬關節酸脹發麻，手指因長時間死扣生鐵劍柄而痙攣僵硬，連鬆開五指都伴隨著軸承乾澀的刺痛。長劍斜插在腳邊的碎石裡，劍身上沾著焦黑的油污與鐵屑，沉甸甸地散發著鐵鏽與機油混雜的氣味。

背後的十五圈發條，在剛才那場生死一線的格擋與爆發中，已經釋放到了最後兩圈。彈簧片鬆弛到了極限，視野邊緣開始泛起一陣陣缺能所致的灰白雪花點。

這就是停擺世界裡真正的戰鬥嗎？

不是故事書裡光鮮亮麗的勇者劈砍，而是一次又一次在齒輪崩斷的邊緣死死咬住卡榫。稍有不慎，自己也會像地上這具哨兵偶一樣，被過熱的黑鏽咬死，淪為路邊無人問津的空殼。

極致的疲倦如濃稠黑水般湧上意識。小白的金屬眼皮漸漸沉重，青綠色的玻璃眼球微弱地黯淡下去。

長耳軟軟地耷拉在兩側，整隻小兔陷入了半昏沉的假死停轉狀態。

就在這時，一陣極其輕微、完全不同於粗暴風聲的細微沙沙聲，從荒路高處的積木斷壁上傳來。

晨霧中，無聲無息地漫開一抹幽微的靛藍微光。

一個修長的身影佇立在殘破的積木拱橋頂端。那人身披一襲泛著深邃星空暗紋的深藍斗篷，寬大的兜帽低低垂下，遮住了大半張面容，唯有一枚小巧精緻的黃銅渾天星盤懸浮在其手側，三道極細的指針在半空中按照某種玄奧的律動緩緩自轉。

兜帽之下，兩道冷靜、深邃、宛如星辰般澄澈的目光，穿透薄霧，久久停留在廢墟旁蜷縮的小兔子身上。

「……微末之刃。」

一聲清冷得如同融雪滴入銅鐘的低語，在晨風中輕輕散開。

陌生人的視線掃過插在碎石裡的鏽蝕長劍，又落在那具安靜洩壓的哨兵偶身上。兜帽微微牽動，似乎對眼前這幕難以置信的景象感到了一絲極淡的詫異。

沒有野心膨脹的過載火星，沒有試圖證明力量的蠻橫劈砍。

這具小小的身軀，竟然純粹憑藉著保護自己、尋求走時的微弱動能，以最不可思議的角度，精準解開了被黑鏽卡死的暴走關節。

沙沙。

斗篷輕輕掠過碎石，陌生人悄然落在了小白身前。

晨風拂過，帶來一股極其罕見的淡香——不屬於機油，也不屬於木屑，而是深邃夜空中星辰冷光灑落時的清冽氣息。

陌生人伸出一隻修長勻稱、由純銀與黃銅精密咬合而成的機械手掌。在手掌指尖，懸扣著一枚精緻無比的星軌上鍊匙。

修長的手指極其輕柔地搭上了小白身後那枚快要徹底停轉的黃銅發條。

「喀嗒。」

一聲無比清脆悅耳的金屬輕響，在死寂的廢墟中綻開。

一股溫涼、純淨且充沛的奇異動能，順著發條柄瞬間注入小白乾涸的發條盒深處！鬆弛的彈簧片被穩穩地回旋盤緊了一整圈，原本紊亂的雙子擒縱輪像是得到了最高階齒輪油的浸潤，驟然重新平穩地律動起來！

小白的金屬身軀猛地一震，長耳內的銅絲天線劇烈彈起！

「誰——？！」

青綠色的玻璃眼眶驟然亮起，小白猛地抓緊身邊的長劍，驚愕地抬起頭。

然而，眼前的碎石地上空無一人。

唯有晨曦薄霧在風中打著旋兒，遠方高處的積木斷壁上，那道深藍色的斗篷衣角正在星光般的微粒中漸漸淡去。

在霧氣消散的最後一瞬，一道悠遠、冷冽又帶著隱約嘆息的聲音，飄飄忽忽地鑽進了小白的長耳中：

「不靠野心驅動的齒輪……原來真能在黑鏽裡走時麼。」

低語頓了頓，後半句在晨風中化作縹緲的星屑回音：

「……石牆的大門已經很多年沒為弱者動過了。握緊你的劍，別讓發條在抵達大鐘前冷掉。」

半句話。沒有留下姓名，也沒有留下因由。

小白愣愣地坐在原地，胸口內那一圈被額外注滿的動能正散發著平靜而強大的律動，驅散了四肢百骸所有的酸脹與疲憊。

低頭看去，在自己腳掌邊的碎石縫裡，靜靜躺著一粒指甲蓋大小、散發著水波般青金微芒的金屬顆粒——黃銅星屑。

小白伸出小爪，將那粒微涼的星屑拾起，與舊鑰給予的金黃鑰繩一起，小心翼翼地收進了胸前的鐵皮夾層中。

陌生人的半句話在腦海中迴盪。

石牆……大門。

小白握緊長劍，撐著地面重新站直了身軀。清晨的第一縷陽光終於穿透了厚重雲層，荒路盡頭的積木高坡上，隱隱浮現出了一座雄偉城牆的冷峻輪廓。

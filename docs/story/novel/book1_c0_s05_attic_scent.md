# C0-S05 · 舊閣樓的氣味（場景卡正文）

生鏽長劍壓在金屬肩膀上，沉重得讓人每走一步都牽扯著發條彈簧的哀鳴。

小白雙手緊扣著粗糙的劍柄，長長的冰冷劍尖拖在滿是裂紋的硬木地板上，伴隨著碎石與積木屑，劃出一道持續不斷的尖銳刮痕。空氣裡滿是熱浪翻滾的焦灼，身後整座發條新村像是被扔進了熔爐，橙紅與暗紫交織的黑焰肆虐狂舞，將老舊貨箱、積木走道與玩具小屋一寸寸嚼碎吞噬。

通道前方，是閣樓邊緣一處坍塌震裂的豁口。穿堂風夾雜著外頭黎明的微涼晨霜，正從裂縫中凶猛地灌進來，與炙熱的火場正面衝撞，捲起一團團旋轉升騰的灰霧。

「等等……小白！」

身後傳來急促而凌亂的腳步聲，伴隨著金屬軸承過熱乾磨的嘶啞聲響。

小白停下腳步，艱難地轉過身。

舊鑰跌跌撞撞地追到了通道盡頭。她的布衣半邊已被黑焰撩得焦黑捲曲，金屬面頰上滿是黑灰與滾燙的油漬，胸口那組原本用來調節雜貨箱發條的擒縱卡榫，正劇烈地上下顫動，發出隨時可能崩解的刺耳喀啦聲。她手裡那盒視若性命的備用齒輪早就在火海中遺落殆盡，兩手空空，唯有右掌心裡死死攥著一樣東西。

看著這隻身高才到自己腰間、卻頑固地將一把比自身還長的鏽蝕長劍扛在肩上的米白色小兔子，舊鑰眼眶裡的黃銅鏡片猛地收縮了一下。

她沒有再責備小白的逞強。在這片即將化為灰燼的故鄉面前，任何多餘的斥責都顯得蒼白無力。

舊鑰疾步上前，單膝跪在滿是碎木屑的地面上。她伸出滾燙的金屬雙手，輕輕拉開了小白胸膛前那道薄薄的鐵皮夾層。

「拿著。」

她將手心裡緊握的那樣物事，小心翼翼地塞進了小白胸口的夾層深處。

那是用曬乾的纖維與細黃銅絲精細編織而成的鑰繩。長度只有兩寸，表面微微泛著陳舊而溫暖的金黃色澤，邊緣已經有些磨損起毛。沒有任何流光溢彩的魔法符文，也沒有精密齒輪那種鋒芒畢露的咬合力，拿在手裡輕得幾乎感受不到分量。

小白低下頭，綠色玻璃眼眸倒映著這截微小的金黃物件。

「不是什麼神奇零件。」舊鑰替牠將鐵皮夾層輕輕合攏，拍了拍上面的灰塵，聲音沙啞卻無比溫柔，「——是舊閣樓的氣味。」

舊閣樓的氣味。

小白微微抽動了一下鼻尖的金屬氣孔。

真的，在刺鼻灼熱的濃煙與焦炭味裡，胸口那截金黃鑰繩散發出一股熟悉而安心的氣息。那是存放了無數個春秋冬夏的老木箱散發出的乾燥木料清香；是老式機油沈澱多年後特有的、帶著一絲微甘的潤滑油氣味；是發條新村裡玩具們挨挨擠擠坐在一起、互相用棉布擦拭金屬身軀時留下的微溫。

那是「家」的味道。

也是發條新村所有微末玩具共同的執念——哪怕世界大鐘停擺，哪怕身軀終會生鏽，只要發條還在，總有一天世界會重新走時。

「記住走出去的路！」

舊鑰雙手扶著小白的肩膀，將牠朝向豁口外的晨光用力推了半步。

轟隆！

頭頂上方支撐天花板的最後一根積木巨梁終於不堪重負，在一聲巨響中斷裂砸落，橫亙在兩人之間，爆開一堵數尺高的烈火殘垣。火舌貪婪地吞噬著最後的退路，將舊鑰的身影隔絕在滾滾黑煙的另一端。

在烈焰與濃煙的縫隙裡，舊鑰站在燃燒的廢墟深處，遠遠地朝著小白揮了揮那隻沾滿黑灰的手臂。

火光映著她破損的臉龐，她用盡最後的力氣，朝著即將踏出門扉的小傢伙喊道：

「別回頭！朝著能望見世界大鐘的地方走！」

「……我會在這裡，等世界重新走時的那天！」

小白的手掌死死按在胸口的鐵皮夾層上。隔著薄薄的金屬板，金黃鑰繩彷彿正源源不斷地散發著微熱，溫暖著胸腔裡那枚孤獨運轉的微型雙子擒縱輪。

眼眶裡的青綠玻璃微微發燙。

牠沒有回頭。

不是因為冷漠，更不是因為無情。而是因為牠深深知道，回頭救不回任何咬死的齒輪，只會讓舊鑰用命換來的生機化為泡影。

小白咬緊牙關，托緊肩上沉重冰涼的鏽蝕長劍，邁開被灰塵磨損的金屬小腿，毅然跨過了積木通道的斷裂豁口。

身後，古老閣樓轟然陷落，沉寂的黑夜在烈火中終結。

前方，荒涼遼闊的世界正迎著破曉的冷霜，向這隻渺小的發條兔子敞開漫長的征途。

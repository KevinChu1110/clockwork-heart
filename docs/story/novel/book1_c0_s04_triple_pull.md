# C0-S04 · 鏽劍三振（場景卡正文）

崩塌的木梁掀起漫天灰塵，嗆得連呼吸都帶著滾燙的焦味。

身後的退路已經被傾倒的積木堆化作一堵燃燒的火牆。熾熱的風穿透縫隙，吹得木屑四處翻滾。小白抹了一把眼眶上的黑灰，低頭尋路，眼角餘光卻在殘破的地縫深處，捕捉到了一抹暗啞的金屬冷光。

那是半截埋在積木碎屑與厚灰中的長劍。

小白停下腳步。

這不是什麼陳列在櫥窗裡的華麗佩劍，也沒有發條衛兵長槍上那種鋥亮的鍍層。整把劍通體被深褐色的粗糙鏽斑覆蓋，刃口多處捲曲，十字護手佈滿了磕碰凹痕，握柄防滑合金片早已磨蝕脫落，露出冰冷粗糙的生鐵。更重要的是——它太長了，比小白只有兩個半頭身高的身軀還要長出一大截。

它孤零零卡在硬木地板接縫裡，像是逃亡玩具隨手丟棄的廢鐵，又像是無數次被世界遺忘後沉澱的殘骸。

小白蹲下身，伸出兩隻小機械爪，握住了粗糙的劍柄。

掌心貼上握柄的剎那，一股刺骨的冰涼透過鐵皮傳來，與四周滾燙的火場形成殘酷對比。生鏽的金屬毛刺扎在指節上，帶來清晰的刺痛。

太沉了。

僅僅是感受著那份下墜的分量，小白就隱隱覺得，這根本不是自己這種發條小玩具該碰的東西。

但牠還是吸了一口氣，雙足扣住地板，開始了第一次拔劍。

雙臂發力，齒輪全力後旋！

「喀啦……」

劍身紋絲不動。

木縫裡的鏽蝕彷彿與地基融為一體，對這隻小兔子的拉扯報以徹底的輕蔑。小白用力過猛，金屬腳底猛地一滑，整隻兔子重心全失，「噗通」一聲仰面朝天摔倒在地。

尾部的發條鑰匙重重磕在木板上，震得胸膛裡的齒輪一陣痙攣。一屁股坐進厚灰裡，揚起的塵土撲了牠滿頭滿臉。一聲沉悶鈍響，在火場中顯得格外渺小。

這像極了世界的冷酷嘲弄：你只是一隻發條小兔，連積木都抱不穩，憑什麼拔起戰士的劍？

小白坐在灰堆裡呆了兩秒。

遠方的黑焰又轟碎了一架貨櫃。牠看著沾滿黑灰的小爪子，玻璃眼眶裡的青綠光芒微不可察地閃爍了兩下。

牠沒有放棄。牠爬了起來，拍掉膝蓋上的灰，再次跨步上前。

這是第二次拔劍。

小白咬緊鐵皮卡榫，將金屬後足卡進積木凹槽。胸膛內微型雙子擒縱輪瘋狂運轉，背後的發條鑰匙發出「吱呀」的尖銳哀鳴！

「給我……動啊！」

牠雙手扣緊劍柄，將全部體重化作後仰槓桿，發條彈簧瞬間緊繃到極限！

「嘎——吱——！」

刺耳的金屬摩擦聲響起。原本焊死般的長劍，竟然真的被生生拔出了一寸，暗紅鐵鏽簌簌崩落。

然而，拔出瞬間釋放的反作用力，直接拽著牠整個人向前狠狠栽去！

「砰！」

小白整隻兔摔趴在劍前，下巴磕在積木稜角上，米白面漆被磕掉一塊，露出底下暗灰色的生鐵。關節螺栓被震得晃動，痛覺像電火花般亂竄。長劍依然斜插在木縫裡，冷冷俯瞰著這隻狼狽喘息的兔子。

四周火勢漸大，熱浪如毒蛇般吐著信子。

趴在灰塵裡的小白，聽著胸膛裡劇烈的齒輪撞擊聲。

為什麼要拔這把劍？

牠不是為了當什麼英雄，牠不懂界域封印，更不想應驗什麼「至弱之物」的預言。牠只是一隻發條只有十五圈的渺小玩具。

可是，身後已無退路。

發條新村在燃燒，舊鑰在拼命爭取時間。如果連一把生鏽的鐵劍都不敢拔起，走出這扇門後，這具身軀又能走到哪裡？

總得有玩具……站起來一下。哪怕站得很醜，哪怕站得滿身塵泥。

小白撐著發軟的手甲，重新站直了身子。

第三次。

牠上前握緊生鐵握柄，後足微型彈簧收縮到極限，胸膛內的擒縱輪爆發出全部動能！

「哈——！」

金屬後足猛烈蹬地，所有力量化作純粹的拔躍！

「崩！！」

清脆剛猛的木石崩裂聲驟然炸響！長劍脫離木板的剎那，小白甚至因為巨大慣性微微離地騰空！

緊接著，一人一劍砸回了積木灰堆。煙塵四散揚起，狂亂的耳鳴中，只剩下自己體內齒輪急促頑強的滴答喘息。

小白緩緩睜開眼。

煙霧漸散。沉重、粗糙、帶著厚厚斑駁鏽跡的長劍，結結實實地斜搭在牠的肩膀上。長長的刃尖垂落在木板上，在灰塵中拉出一道深深的白痕。

雙手發麻，螺栓發燙，小小的掌心幾乎握不穩粗硬的劍柄。

但它被拔出來了。沉甸甸地、蠻橫不講理地，握在一隻最弱小的玩具手中。

通道盡頭的舊鑰看見了這一幕，眼底閃過難以置信的驚愕，隨後擦了把臉上的黑灰，朝著這邊用力喊道：

「別逞能——！你連發條都才剛轉動……算了！帶上它防身！快走！」

小白雙手握緊長劍，感受著肩膀上那份真實的重量。那是第一件行李，也是一隻微末小兔對這個龐大世界最初的回答。

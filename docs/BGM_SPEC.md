# BGM 規格單 · 八個 cue（重新作曲用）

> 上位文件：[CLOCKWORK_ART_MUSIC_BRIEF.md](CLOCKWORK_ART_MUSIC_BRIEF.md) §5（衝突時以 brief 為準）。
> 對應 issue #31。程式端（AudioManager 八 cue、`resolve_bgm_cue()`）見 PR #16，本文件**不改程式介面**。

## 0. 共通規則（每首都適用）

| 項目 | 規格 |
|------|------|
| 風格 | 發條八音盒＋輕管弦。**不是**動作遊戲戰鼓連打；不要電吉他、不要人聲／合唱 |
| 檔名 | 只准 `title`／`village`／`town`／`road`／`forest`／`battle`／`boss`／`ending`，放 `game/assets/audio/bgm/`，`snake_case` 英文 |
| 遊戲用格式 | `<cue>.mp3`（libmp3lame VBR `-q:a 3`，48 kHz 立體聲）。之後若換 `.ogg`，要同時刪掉同名 `.mp3`（AudioManager 先挑 ogg） |
| 交稿母帶 | 48 kHz／24-bit WAV，長度**剛好**等於下表（樣本數＝秒數 × 48000），另附 stem（旋律／伴奏／打擊）方便之後混音 |
| 響度 | 整合響度 **−16 LUFS ±0.5**、true peak **≤ −1 dBTP**（ffmpeg `loudnorm=print_format=json` 量測） |
| 音量差 | town 要比 village 小聲：**檔案一樣做 −16 LUFS**，由 `AudioManager.BGM_CUE_GAIN_DB = {"town": -2.0}` 在播放時再壓 2 dB；編曲也要比 village 稀疏 |
| 循環 | 除 ending 外全部循環（`AudioManager.BGM_ONESHOT = ["ending"]`）。循環起點寫在 `game/assets/audio/bgm/loops.json`（秒，從檔頭算），播到檔尾跳回該點 |
| 無縫要求 | 循環區長度＝整數小節；**殘響尾巴要折回循環起點**（tail wrap），檔尾最後一個樣本要能直接接循環起點的樣本，不可以淡出、不可以留靜音、不可以爆音 |
| 速度 | 戰鬥類（battle／boss）70–90 BPM；大廳類（title／village／town）80 BPM 左右 |
| 滴答 | 齒輪滴答是本作的「節奏樂器」：battle 必有、boss 必留、其他曲可輕點綴 |

## 2. 每首細項（給之後真正重作曲的人）

### title · 24 s · 80 BPM 4/4
- **結構**：第 1 小節（0–3 s）發條上鏈：棘輪「喀啦喀啦」3～4 下＋八音盒撥一下弱起；第 2–8 小節（3–24 s）主旋律。
- **配器**：八音盒（主旋律）、鋼片琴／鐘琴點綴、弦樂墊底、撥奏低音；上鏈聲用實錄或合成棘輪。
- **循環**：`loops.json` 寫 `3.0`，循環區 3–24 s（7 小節），上鏈只在第一次出現。
- **重點**：主旋律是全作主題，village／ending 要能引用它的動機。

### village · 45 s 循環 · 80 BPM 3/4
- **結構**：20 小節 ＝ A（8）＋ A'（8）＋ 轉回（4），轉回最後一小節要能接回第 1 小節。
- **配器**：八音盒（伴奏琶音）＋**雙簧管（主旋律）**、撥奏弦樂、木管和聲、很輕的滴答。
- **循環**：整檔循環，起點 0。
- **重點**：大廳最常聽到的一首，旋律要耐聽、不要有高潮爆點；音域避開 SFX（ui／reveal）所在的 2–4 kHz 尖峰。

### town · 40 s · 72 BPM 4/4
- **結構**：12 小節 ＝ 4 ＋ 4 ＋ 4，第 12 小節做回頭句。
- **配器**：**手風琴（主奏）**、撥奏低音、輕吉他或曼陀林刷弦（不可電吉他）、少量鐘琴。
- **音量**：比 village 小聲。母帶同樣 −16 LUFS，程式再 −2 dB；編曲要更稀疏、動態更平。
- **循環**：整檔循環，起點 0。

### road · 30 s · 96 BPM 4/4
- **結構**：12 小節輕快進行，第 9–12 小節做回頭句。
- **配器**：撥奏弦樂、長笛／單簧管、八音盒對位、輕沙鈴＋滴答。**不要合唱、不要人聲**。
- **循環**：整檔循環，起點 0。

### forest · 40 s · 72 BPM 3/4
- **結構**：16 小節 ＝ 8 ＋ 8。
- **配器**：**豎琴（琶音主體）**、長笛、鋼片琴、弦樂長音墊底；不要鼓。
- **循環**：整檔循環，起點 0。
- **重點**：霧／塔地區也用這首，可以稍帶神祕（小調色彩），但不要恐怖。

### battle · 35 s 循環 · 82.29 BPM 4/4
- **結構**：12 小節，固定滴答八分音符貫穿全曲。
- **配器**：**弦樂（跳弓頑固音型）＋齒輪滴答**、撥奏低音、八音盒動機、少量定音鼓重音。**不要電吉他、不要戰鼓連打**。
- **循環**：整檔循環，起點 0。
- **重點**：自動戰鬥看很久，張力要穩不要累；中頻留空給 hit／slash／swap。

### boss · 40 s · 84 BPM 4/4
- **結構**：14 小節 ＝ 2（銅管宣告）＋ 12（主體）；第 14 小節接回第 1 小節。
- **配器**：**銅管＋定音鼓**、低音弦樂、**滴答仍然是節奏骨架**、八音盒動機變形（小調）。
- **循環**：整檔循環，起點 0。
- **重點**：warn（部位將破）與 break 要聽得到，不要整片銅管鋪滿。

### ending · 16 s · 75 BPM 4/4 · 不循環
- **結構**：4 小節八音盒旋律（引用 title 主題）＋ 1 小節收尾和弦自然衰減（最後約 0.5 s 收到靜音）。
- **配器**：**八音盒**為主，可加一點鐘琴與弦樂長音。
- **循環**：不循環（`BGM_ONESHOT`），loops.json 不寫 ending。
- **重點**：勝利結算用，和 victory SFX 會接在一起，開頭不要有重拍撞 SFX。

## 3. 驗收（交稿時每首都要過）

```bash
# 響度與 true peak（整合響度 −16 ±0.5、true peak ≤ −1）
ffmpeg -hide_banner -i game/assets/audio/bgm/village.mp3 -af loudnorm=print_format=json -f null - 2>&1 | tail -12
# BGM 把關測試（清單、可載入、loops.json 合法、地圖對應）
TEST_FILTER=art/test_bgm ./tools/run_tests.sh
```

- 循環接縫：檔尾 50 ms 與循環起點 50 ms 接起來不可有樣本跳變（爆音）；耳朵聽 3 圈以上。
- 換檔後 `.mp3.import` 的 `loop_offset` 要與 `loops.json` 一致（AudioManager 以 loops.json 為準）。

## 4. 佔位版現況（issue #31，免費改善）

> 這是**佔位**：從現有 Suno 佔位曲（`SUNO_SOURCES.json`）裁出段落，只做剪輯、微調速度、交叉淡化、響度，
> 沒有用任何付費生成。重現方式：`python3 tools/cut_bgm_loops.py --out /tmp/bgm_cut`（numpy＋ffmpeg rubberband）。
> 響度與 true peak 是對最終 `.mp3` 跑 `ffmpeg -af loudnorm=print_format=json` 的量測值（2026-10-06）。

| cue | 長度 | 循環 | loop_offset | 整合響度 | true peak | LRA | 取自原曲 | 速度微調 | 佔位實際速度 |
|-----|------|------|-------------|----------|-----------|-----|----------|----------|--------------|
| title | 24.000 s | 是 | 6.727 s | −16.00 LUFS | −4.13 dBTP | 8.1 LU | 0.00–23.70 s（前奏＋7 小節） | −1.3 % | ≈ 98 BPM |
| village | 45.000 s | 是 | 0 | −16.00 LUFS | −4.64 dBTP | 5.0 LU | 36.69–80.32 s（14 小節） | −3.0 % | ≈ 74 BPM |
| town | 40.000 s | 是 | 0 | −16.00 LUFS | −1.79 dBTP | 1.9 LU | 41.63–79.13 s（15 小節） | −6.3 % | ≈ 90 BPM |
| road | 30.000 s | 是 | 0 | −16.00 LUFS | −2.88 dBTP | 2.8 LU | 110.09–139.42 s（11 小節） | −2.2 % | ≈ 87 BPM |
| forest | 40.000 s | 是 | 0 | −15.99 LUFS | −1.91 dBTP | 2.7 LU | 38.01–80.65 s（20 小節） | +6.6 % | ≈ 120 BPM |
| battle | 35.000 s | 是 | 0 | −15.99 LUFS | −1.84 dBTP | 3.8 LU | 181.05–218.45 s（22 小節） | +6.9 % | ≈ 153 BPM（半拍感 ≈ 77） |
| boss | 40.000 s | 是 | 0 | −16.00 LUFS | −2.70 dBTP | 2.4 LU | 206.66–245.81 s（19 小節） | −2.1 % | ≈ 115 BPM（半拍感 ≈ 58） |
| ending | 16.000 s | 否 | — | −16.00 LUFS | −2.34 dBTP | 7.7 LU | 255.84–272.20 s（最後一句到自然收尾） | +2.2 % | ≈ 88 BPM |

做法：
- **挑段落**：節拍追蹤後，對每組「起點小節 → 終點小節」比對前後 2 拍的 chroma／MFCC，挑和聲與音色最接得回去、
  中間沒有斷層的段落；再用人聲分離（demucs，只拿來分析、不進成品）避開有人聲／合唱的地方。
  選中的段落人聲能量相對整體最高 −28 dB（town）、中位數約 −58 dB，等於沒有人聲；road 符合「不要合唱」。
- **對齊長度**：rubberband 調速不變調（±7 % 內），長度剛好等於 brief 秒數。
- **無縫循環**：檔尾 0.35 秒與「循環起點前 0.35 秒」交叉淡化，接縫前後再做樣本級對齊；
  解碼後檢查檔尾 → loop_offset 的樣本跳變，八首都小於曲內 99.9 百分位（沒有爆音）。
  Godot 4.7 的 MP3 解碼吃 LAME gapless 標頭，`get_length()` 剛好是 24.000／45.000…秒，循環不會多出靜音。
- **title**：保留原曲八音盒前奏，疊三圈程式合成的發條棘輪聲（「上鏈」），6.727 秒起進入循環主體。
  loop_offset 取到毫秒並避開 Godot float32 截斷，跳回時樣本完全對齊。
- **town**：檔案一樣 −16 LUFS，靠 `BGM_CUE_GAIN_DB` 在播放時再壓 2 dB，比 village 小聲。
- **ending**：取原曲最後一句和自然收尾，不循環，loops.json 不寫 ending。

## 1. 一句賣點（任選）

1. **今天，誰需要上發條？**
2. 一隻米白烤漆的兔子，背著黃銅鑰匙，走進停擺的玩具世界。
3. 能走到最後的，不是最強的，是**不低頭的心**。
4. 探索 → 戰鬥 → 拆部位：把敵人的齒輪，變成你的下一格發條。

## 2. 商店頁短文（中文）

**標題候選**  
- 發條之心  
- 發條之心：上緊那一格

**副標**  
在停擺的玩具世界裡，一隻不慕強權的機械玩具兔小白，以場景敘事 × 即時戰鬥 × 拆解零件，一格一格把發條重新上緊。

**特色三點**  
- **發條體力**：胸口的青綠之心會說話——轉不動了，就該休息。  
- **拆部位**：打到接縫露出，旋開黃銅齒輪與核心碎片。  
- **每日一件小事**：不是待辦清單，是「今天，誰需要上發條？」

**免責（預覽期）**  
目前為開發中可玩預覽；畫面／音效仍在收斂中。

## 4. 社群貼文草稿

### 貼文 1（神秘預熱）
發條轉了一格。  
米白烤漆、青綠的心、背上那把黃銅鑰匙。  
世界還停著。我們沒有。  
#發條之心 #ClockworkHeart

### 貼文 2（玩法）
這場不是藍條。  
是胸口那圈刻度：探索扣一格、開戰扣兩格、拆零件再扣兩格。  
轉不動了？那就——先停一下。  
（輕度、單機、發條玩具的節奏。）

### 貼文 3（互動問句）
如果只能幫一位夥伴上發條——  
你會選誰？  
回覆我：兔／獅／狐／豬（或你自己養的那一隻）。

### 貼文 4（金句卡）
「一隻拿劍的兔子，格擋了獅子王的必殺。」  
「塔頂才發現：魔王，也曾是至弱者。」  
——《發條之心》
